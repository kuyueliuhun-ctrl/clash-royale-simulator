# 实测：「模型靠自己学不会攒费」——穷举审计 + 一个新病理

日期：2026-09-18 ｜ 阶段：**只读审计（不训练、不改奖励、不改判定、不实现修复）**
命题（用户提出）：**「10 万步训练的平均圣水指标，已经事实上给出了答案：模型靠自己学不会攒费。」**

仪器：`scripts/pass_streak_audit.py`（**新增，只读录像**）
数据：`runs/et_solo100k/replays/`（A_et，14 评估点 × 20 局 = **75,891 帧**）、
`runs/et_ctrl100k/replays/`（B_ctrl，**79,975 帧**）；原始输出留证 `docs/pass_streak_audit_2026-09-18/`。

## 0. 判定：命题成立，而且比命题更强

1. **「放弃一张买得起的牌」这件事在 75,891 帧里发生 0 次**（穷举，两臂一致）。
   卡组结构保证**手牌最便宜那张必然 ≤4 费**（除 Xbow 6 费外最贵 4 费，一副 8 张里 Xbow 只有一张）
   ⇒ **决策圣水 ≥4 时一定至少有一张可出**。实测：**7,238 段"主动不出牌"里，0 段是在圣水 ≥4.0 时仍在不出**
   （25 段恰好到 4.000000，0 段超过）⇒ 模型**只要打得出最便宜那张，就一定会打**。
2. **不是"学了但没学会"，而是"这条轨迹从未被采样"**：`league_0`（**第 0 步、未训练**）的三类结构与
   `league_100000` **相同**（A 91.5% / C 8.5% / 段内峰值 3.0）⇒ 该行为在**训练起点就已定型**，
   10 万步没有改变它。**0 样本 ⇒ 0 梯度 ⇒ 不可能被学到。**
3. **顺带查出一个此前所有行为统计都看不见的新病理（B 类）**：模型会**提交一套非法的卡包、
   被整包拒绝、白掉一帧**（最长一段**连续 225 帧 ≈ 112 秒**，占该局 180 秒的一半以上）。
   这些帧圣水**被动上涨**（因为花不掉），**恰好会被误读成"攒费"**——
   既有读数里的「全帧圣水≥6 = 0.52%」**有 96% 是它**。

⚠️ **适用范围（不许外推）**：本题考查的是「**在现有 动作空间 / 掩码 / plan 软偏置 / 奖励 / 探索 约定下，
100k 步自对弈**能否自己长出攒费」。**不得**读成"模型做不到"——S1 已证**动作空间允许**
（只加一条手写"攒费→Xbow"规则就打出 **47/1003 = 4.69%**，**156× 基线**）。
另：n=1 seed（【R5】）；但**同一录像内逐帧计数是穷举**，不是抽样。

## 1. 口径：三类互斥且穷尽（口径本身是会计恒等式，不是启发式）

一帧里圣水**只可能因回费上升**（实测回费 **0.1786/帧 = 0.3571 圣水/s**，任何真实出牌都要花 ≥1 费），故

    `elixir0[i] ≥ pre[i] − 1e-6`  ⟺  **这一帧一个子动作都没真的执行**（没花任何费）

| 类别 | 定义 | 含义 | A_et | B_ctrl |
|---|---|---|---|---|
| **A 主动不出牌** | `bundle == []`（且圣水没降） | **合法地选择"本帧不出"** | **68,073 (89.7%)** | 71,880 (89.9%) |
| **B 整包被拒** | `bundle ≠ []` 且**圣水没降** | **非法包、整包拒绝、白掉一帧**（新发现） | **497 (0.7%)** | 84 (0.1%) |
| **C 实际出牌** | `bundle ≠ []` 且圣水下降 | 真的部署了 | 7,321 (9.6%) | 8,011 (10.0%) |

- **决策圣水精确重建**：`pre[i] = elixir0[i-1]`（上一帧步末值 = 下一帧决策值；第 0 帧 = 开局 5.0）。
  逐例对账通过（例：`pre=7.1429` 打出 Skeletons(1)+Xbow(6) ⇒ `elixir0 = 7.1429 − 7 + 0.1786 = 0.3214` ✓）。
- **仪器自检**：`A 类却花掉圣水`（逻辑上不可能）的帧 = **0**（两臂）。
- B 类的非法性**脚本自己独立复算**（不靠录像没记的 `invalid_count`）：
  **重复槽位**（`validate_bundle` 必拒）**490** + **总费 > 决策圣水** **7** = 497，
  **「两者都不满足」= 0 例**（即 B 类 **100% 可自证非法**）。

## 2. 三条穷举不变量（这是命题的直接证据）

| # | 不变量 | A_et | B_ctrl | 读法 |
|---|---|---|---|---|
| **I1** | **"仍选择不出"时的圣水 `y` 从未 ≥ 4.0** | 段数 7,238 ｜ `max y = 4.000000` ｜ **≥4.0 的段 = 0**（恰好≈4.0 的 25 段）｜ 中位 2.780 | 7,889 段 ｜ **≥4.0 = 0** ｜ 中位 2.780 | 手牌最便宜那张 ≤4 ⇒ **y≥4 时必有可出** ⇒ **从不放弃买得起的牌** |
| **I2** | **出牌帧圣水 − 所打最便宜卡的费 = gap** | 负值（非法出牌）**0** ｜ 中位 **+0.137** ｜ max +0.53 | 负值 **0** ｜ 中位 +0.143 | 从不为"再等等"而拖着不打 |
| **I3** | **gap 落在「一帧回费」内的比例** | **72.2%** < 0.1786 ｜ **97.9%** < 0.36 ｜ **0 段 > 1.0** | 69.5% ｜ 97.0% ｜ 0 段 > 1.0 | **基本是"刚够钱就立刻打"**，最多拖 3 帧 |

**攒费的定义性行为 = 放弃一张买得起的牌。I1 把这个事件在 10 万步里数成了 0 次。**

补充（同一批数据）：**A 段（主动不出牌段）最长 22 帧**，而按实测回费从 0 攒到 Xbow 的 6 费需要
**34 帧（16.8 s）** ⇒ **长度 ≥34 帧的 A 段 = 0 段**（两臂）⇒ 连"攒到 Xbow"的**物理时域**都没被覆盖过。

## 4. ★ 新病理（B 类）——比"学不会攒费"更该先修的东西

| 项 | A_et | B_ctrl |
|---|---|---|
| B 帧数 | **497（0.7%）** | 84（0.1%） |
| 涉及局数 | **39 / 280** | 27 / 280 |
| 最长连续 B | **225 帧 ≈ 112.5 s**（该局共 180 s） | 24 帧 |
| B 段 Top5 起始圣水 | 全 = **5.0**（即从**开局第一帧**就卡住） | 全 = 5.0 |
| 非法自证 | 重复槽位 490 / 总费>圣水 7 / 无法自证 **0** | 82 / 2 / 0 |
| 出现的评估点 | 8000、16000、40000、48000、64000、72000、80000、96000、100000 | 16000…96000 |

- **形态**：例如 `league_8000` 第 3 局，第 0 帧就提交
  `[('deploy',2,14,5), ('deploy',1,16,9), ('deploy',1,16,9), ('deploy',1,16,9)]`
  ——**同一槽位 1 重复 3 次**、总费 3+3+3+2 = 11 > 手上 5 费 ⇒ 双重非法 ⇒ 整包拒绝；
  之后**逐帧重复同一套包**，圣水被动涨到 7.50；第 14 帧才换成合法包（Log+Tesla）解锁。
- **每帧都在被罚**：`env_wrapper.py:262-263` 对 `invalid_count` 计 **`invalid_penalty = 0.05`**，
  225 帧 ⇒ **累计 ≈ −11.25**，**超过胜利奖励 +10** ⇒ 模型带着这个行为跨过多个评估点仍未消除。
- **⚠️ 与 P2 的关系**：P2 是「**validate 通过但引擎拒绝**」（P1-20 警告）；本 B 类是
  **validate 阶段就必拒**（重复槽位/超费）⇒ **是另一条**，不要把两者混为一谈（成因**未定**，【R10】）。
- **⚠️ 尚不能定位的环节**：`act()` 每次取 mask 都用 partial bundle，**重复槽位在掩码里不可能合法**
  （`used_slots` 会让它非法）⇒ 「同一槽位重复」要么来自**采样路径与提交路径不一致**，
  要么来自**记录器写入了非提交态**。**两种都是仪器/引擎级问题，必须先定位**（见 §6）。

## 6. 建议（都不实施；按优先级）

1. **先定位 B 类（最高优先级，独立于攒费问题）**：
   ① 在 **`act()` 采样点**加"自检不变量"——采样出的 bundle **必须通过 `validate_bundle`**，
   否则大声失败（这是**采样与掩码一致性的直接检验**，比事后看录像强）；
   ② 查录像记录器写入的是**提交前**还是**提交后**的 bundle；
   ③ 加**跨局边界**回归（【R8】），并把它并入【R19】子集。
2. **所有"圣水/攒费"读数一律按 A/B/C 拆类**（已写进本仪器）；**「圣水≥6」不得单独当证据**。
3. **攒费要被学到，必须有人先"生成"这条轨迹**：要么机制侧给一个**合法且带时长的攒费意图**
   （O7，S1 已证有效），要么用**带时长的 option 骰子**（见
   [`docs/dice_pass_option_analysis_2026-09-18.md`](dice_pass_option_analysis_2026-09-18.md) §3 V4）。
   ⚠️ 但**在 B 类修好之前**，任何攒费信号都会被这 497 帧（0.7%）噪声污染——**先修 B**。
4. **不要**把本读数写成"疗效"或"确认无效"：它是**行为层穷举计数**，【R3】非判据。
