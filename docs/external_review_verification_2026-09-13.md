## 6. 这些发现与**同晚**的 POMDP 天花板检验的关系（重要）

同一晚我们跑完了 `docs/pomdp_ceiling_verdict_2026-09-13.md`（判定 **P0 灰区**），
三个估计器变体给出**互相矛盾**的结论：

|---|---|---|
| V1 目标=整局回报、池化选择 | −0.50 / −0.58 / −0.54 | P2 |
| V2 目标=整局回报、within 选择 | −0.19 / −0.23 / −0.21 | P2 |
| **V3 目标=局内中心化回报** | **+0.182 / +0.186 / +0.197** | **P3（H-LEARN）** |

外加两条独立证据：**G5 阳性对照通过**（同一条流水线在"必然含局内信号"的靶子上拿到 MLP **+0.2804**、Ridge **+0.5753**）；**时钟基线 ≈ 0**（只用"局内第几帧"的基线 test **+0.0127**、profile 方差只占局内方差 **2.47%**）。

**对报告的意义**：
- 若 V3 的读数最终成立（P3），则报告的第二份因果链——
  "**critic 死 ⇒ 无法把未来那一波折现回现在 ⇒ 组合进攻/攒费学不到**"——**得到支持**：
  信息在输入里，死的是 critic。
- 若 V1/V2 的读数最终成立（P2），则该链条**有洞**：连 oracle 隐藏量都解释不了局内回报，
  那么"修好 critic 就能学会等待"这个预期**也不成立**。
- ⇒ **报告最关键的实践建议（"先修 value 通路的吸收态"）的成立与否，正好压在这个未决问题上。**
  这也是为什么我把 §0 的判决停在 P0 而不是选一边。

## 7. 净收益清单

**应当吸收的**
1. **回放级行为取证**（逐卡计数、部署瞬间圣水、胜条件卡使用率）——文档里没有，
   而且它给出的三条硬数字（**Xbow 0 / 廉价牌 98.4% / 部署时圣水中位 0.29**）
   比报告自己强调的"0 次跟进""圣水从未 ≥6"更可靠。**建议固化成只读脚本**。
2. **问题层次的重述**（"连局部最优都做不到"）——用户提出、报告落实为取证。
   我们的 O3 只写了"不会攒费/单边堆牌"，**缺"组合进攻从未出现"这一层**。
3. **5 处文档内部不一致**——全部属实，本来就该修（AGENTS 的预算纪律要求"只增不改"，
   但**计数错误与已作废数字的存活**不属于"保留历史"，属于缺陷）。

**不应吸收的**
1. 把 `fprime`/`gfix` 两点当作"常数 critic 仍报强 EV"的证据——**这两点不满足前提**。
2. "0 次后排跟进""圣水从未 ≥6"这类**按报告口径复算不出来**的数字。
3. "1σ≈0.078 ⇒ 无统计差别"的过强表述。
4. "文档自相矛盾"的说法——应改为"一处过时摘要未回填 + 三处标注时序的自我推翻"。

**报告没做而我们该做的**
- 它自己在结尾提议的"**用手写专家 `BeliefPlanner` 当教师/对手量化差距**"——

  判据是"攒满 ≈10 才沉底血牛"，`hold_mask=1111`）、`rl/evaluate.py:176,482` 已实例化 `BeliefPlanner`。
  **但注意陷阱**（见 `AGENTS.md` §2.4）：`ScriptedPolicy(mode="heuristic")` 实为 mask 随机；
  脚本对手若用世界坐标必须做世界→本地逆变换。
