**禁止**：写"修好了 / 确认有效 / 确认无效"（n=1/臂）；跨 run 直接比数字（【R5】）；把描述性读数当判据（【R3】）。

## 7. 预先记录的分析先验（**不是读数**，来自启动记录 §9.2）

承诺期把合法集压成 `{保持, 取消, 改攒}` 只把**指数底**从 `P(STOP)=0.058~0.09` 抬到 `P(保持)≈0.5`；
**底数改善 ≠ 合取消失**——若每帧仍需抽一次「保持」，34 帧仍是 `∏p`（≈`0.5³³`）。
⇒ 先验：**若无初始偏差，「≥34 帧保持」的首条轨迹仍可能采样不到**；即便如此，
本 run 仍是有信息的：它能把「底数」这一层单独判定掉（例如 B 臂 `held` 分布明显右移但 `fired=0`）。
