## §0 为什么需要这一轮

v3 的结论是「**2731→128 的共享编码器瓶颈是证据最强的掉点处**」，但它**没有分开**这段里的两件事：

```
fused --(enc_fc 线性投影 2731→128)--> z_enc --(ReLU)--> r_enc --(enc_ln LayerNorm)--> enc
                【瓶颈 A：降维】                                  【瓶颈 B：归一化】
```

v3 只能比较 `fused` 与 `enc`（两端），而**中间两个张量没抓**。所以"是投影还是 LN"**没有回答**。
更糟的是 v3 判读 §3.3 拿 `pre_ln`（价值支路，**另一套权重**）与 `enc` 比——那是**两个不同的线性映射**，
只能说明"哪一路更不可读"，**不能**说明 LN 的净效应。**本轮把这一刀补上。**

### §0.1 离线重算为什么可行（并且怎么验证）

`z_enc = enc_fc(fused)` 是 `fused` 的**确定线性函数**，权重就在 ckpt 里（`enc_fc.weight (128,2731)`、`enc_fc.bias (128,)`），
`fused` 已逐帧存在 npz（`X_fused`，29991×2731 f32）。⇒ 可以离线精确重算
`z_enc → r_enc = relu(z_enc) → enc_off = LayerNorm_{γ,β}(r_enc)`，而 `enc` **本来就被 v3 抓下来了**（`X_enc`）。
⇒ **`enc_off` vs `X_enc` 的偏差本身就是一条闸门**（G-OFFLINE）：重算得对不对，**不需要相信我的实现**，直接对账。

价值支路同理，而且**三段都已经在 npz 里**（`X_pre_ln` / `X_relu_ln` / `X_post_ln`）⇒ 那是 v3 就已经抓到的
**真·同张量 LN 前后对**，本轮到这一轮才被正确地读（v3 只读了单点 argmax）。

## §1 问题（两条，都是"字面父子"对）

**Q1（共享支路）**：`fused → enc` 的损失发生在**投影 A**（2731→128 降维）还是**归一化 B**（`enc_ln`）？

**Q2（价值支路）**：第二轮的结论「`value_enc_ln` **不是**掉点层」在**真·同一张量**的对账下是否成立？
（第二轮的依据是 `relu_ln`(LN 前) 与 `post_ln`(LN 后) 都在同一个 α 网格上 ≈0 —— 那是**真同张量**，
但只在"各自 α*"的读法下看过；本轮按 R17 用**整条 α 曲线 + 同 α 配对**复核。）

## §3 协议

- 输入：`runs/_probe_v3/seed{7,11,13}.npz`（**不重跑 rollout**）+ `runs/critic_inert_probe_20k/solo_main_20000.pt`
- 目标：GAE 回报**按局中心化**（与 v3 逐位同一构造）；切分：按局分组 `test .25 / val .15`（与 v3 同一 `seed` ⇒ **同一批帧**）
- 估计器：Ridge + α 网格 v2（1e-6…1e8）+ 输出裁剪，**同时报整条 α 曲线与每层 argmax**（闸门 12）
- **同 α 配对**（闸门 11）：任何两层之差必须在**同一 α** 上报；判据只看"是否在**每一个** α 上同向"

## §4 闸门（跑前写死）

| 闸 | 判据 | 不过的处置 |
|---|---|---|
| **G-OFFLINE** | 离线重算的 `enc_off` 与 v3 抓下来的 `X_enc`：`max\|Δ\| ≤ 1e-4` **且** `EV_within(enc_off)` 与 `EV_within(enc)` 差 ≤ 0.002 | **`V4_INVALID`**（重算链不可用，后续全部作废） |
| **G-REPRO2** | seed 7 上，本脚本算出的 `EV_within(raw_obs)` / `EV_within(fused)` 必须**逐位复现** v3 的 **+0.12145137 / +0.04312000**（容差 0.002） | **`V4_INVALID`**（说明本脚本的估计器与 v3 不是同一套） |
| G-ANCHOR | `EV(raw_obs) ≥ 0.05` 且 `≥ 5 × 打散对照`（**仅退化护栏**） | `V4_INVALID` |
| G-PC / G-CLK / G-SCR / G-VAR | 与 v3 同（阳性对照 ≥0.15 / 时钟 ≤0.05 / 打散 ≤0.05 / `Var(R)>1`） | `V4_INVALID` |
| **G-RANDOM** | `z_rand` 与 `z_enc` 的**维度一致且同为 128**（构造检查） | 报告而不阻断 |

**闸门集 V4 = {G-OFFLINE, G-REPRO2, G-ANCHOR, G-PC, G-CLK, G-SCR, G-VAR}**

## §5 判据（**全部同 α 配对**；只采信"在每一个 α 上都同向"的结论）

记 `S(α, L)` = 同一 α 下 `L` 的 test `EV_within`；`4 个 α 参照集` = `{1e-2, 1e-1, 1, 10, 100, 1e3, 1e4, 1e5, 1e6}`。

- **P-PROJ（降维是掉点）**：**每一个** α 上 `S(α, z_enc) ≤ 0.5·S(α, fused)`
- **P-LN（归一化是掉点）**：**每一个** α 上 `S(α, z_enc) ≥ 0.5·S(α, fused)` **且** `S(α, enc) ≤ 0.5·S(α, z_enc)`
- **P-BOTH**：`S(α, z_enc) ≤ 0.5·S(α, fused)` 且 `S(α, enc) ≤ 0.5·S(α, z_enc)`（两段都掉）
- **P-NEITHER**：都不满足 ⇒ 报告为"§6 全不命中"
- **P-RANDOM（"这个投影有没有在保存信号"）**：
  **每一个** α 上 `S(α, z_enc) ≤ 1.5 · S(α, z_rand)` ⇒ **训练出来的投影并不比随机投影更能保住信号**
  （与 R14 的"权重位移恰为 0"互为独立证据；反之若 `z_enc ≥ 1.5·z_rand` 则投影确实做了事）
- **P-VLN（价值支路）**：**每一个** α 上 `S(α, relu_ln) ≥ 0.5·S(α, pre_ln)` **且** `S(α, post_ln) ≤ 0.5·S(α, relu_ln)`
  ⇒ 价值支路的 LN 是掉点（**推翻**第二轮"`value_enc_ln` 不是掉点层"）
- **P-VLN-NEUTRAL（复现第二轮）**：**每一个** α 上 `S(α, post_ln) ≥ 0.9 · S(α, relu_ln)`（LN 前后差异 <10%）
  ⇒ 第二轮结论在**真·同张量 + 整条 α 曲线**下**成立**（升级证据等级）

以上分支**互不排斥**，逐条报真值；`P-VLN` 与 `P-VLN-NEUTRAL` 是**互斥**的一对。

## §6 失败分支（跑前写死）

| 情形 | 处置 |
|---|---|
| G-OFFLINE FAIL | `V4_INVALID`；只报告"离线重算与网络不一致"及差多少（**不许**用重算链下任何结论） |
| G-REPRO2 FAIL | `V4_INVALID`；报告本脚本估计器与 v3 的差（**这本身是重要信息**：说明"同一套估计器"这个前提在我的新脚本里没保持住） |
| 其它闸门 FAIL | `V4_INVALID` |
| 某层在某 α 上退化（训练集零方差 / 最优落网格边界） | **只跳过该层该 α**，并在报告里标注；不得据此判 `P-*` |
| 全部 `P-*` 不命中 | `NOT_PREREGISTERED`：**不许**临时造分支；列出全部 `S(α,·)` 供下一轮设计 |
| 三条 seed 的分支不一致 | **只报"哪几条 seed 命中"**，不合并成一个结论；方向一致的才写进台账 |

## §7 成本与不做

- 成本：**3 次矩阵乘（30000×2731×128）+ 8~10 层 × 14 个 α 的 Ridge**；预计 **≤ 15 分钟**，无 rollout。
- **不做**：不改任何代码（`rl/` 一行不动）、不重跑 rollout、不用本轮的读数直接改架构
  （改架构须独立的架构预注册 + `--fresh`，R6）；不把 `z_rand` 的单一随机种子当分布
  （P-RANDOM 用固定种子，**只作方向性对照**，报出种子值）。
