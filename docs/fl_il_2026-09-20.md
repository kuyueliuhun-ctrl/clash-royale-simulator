## 0. 一句话结论

**管线成立、IL 确实学到东西，但学到的是「落点」而不是「出哪张牌」。**

我们第一次把**外部人类回放**（FL 的 IL_Replay 分片 0）灌进我们自己的引擎、产出 **47,715 条**
`(obs, masks, bundle)` 训练对、训了 3 个 epoch 的行为克隆，并在**按局切分**的 8,877 条留出上读数：

| 读数（留出 8,877） | 未训练（随机初始化，`torch.manual_seed(0)`） | **IL 训后** | trivial 基线 |
|---|---|---|---|
| **NLL**（`evaluate` 口径） | 8.649 | **5.596**（−36%） | — |
| **落点精确率**（给定出牌选择正确） | 0.07% | **12.10%**（14×） | 1/576 = 0.17% |
| 落点精确率（不分选择对错） | 0.62% | **9.98%**（16×） | 0.17% |
| **top-1 option**（出哪张牌） | 32.91% | **40.42%** | **常数「恒选槽 4」= 39.84%** |
| 宏平均 recall（对常数预测免疫） | 34.62% | 35.76% | 常数预测器 = 25% |

⇒ **预注册 J3 闸门（top-1 ≥ 40%）= PASS（40.42%）**，但**这个 PASS 没有分辨力**：
本留出集上「恒选槽 4」就能拿 **39.84%**（见 §5.3）。有分辨力的读数是
**NLL 与落点**（都大幅改善）与**出牌选择**（只比 trivial 高 0.58 pp、宏 recall +1.3 pp）。
**因此本轮实质性结论 = 预注册 F5「弱信号」**：落点侧确认学到，出牌选择侧**未获证实**。

## 1. 做了什么（三件新仪器 + 两次作业）

| 步骤 | 工具 | 口径 | 产物 |
|---|---|---|---|
| ① parquet → JSONL + 普查 | `scripts/_fl_il_extract.py`（WSL `/usr/bin/python3` + pyarrow） | 分片 0：5000 局 / 384,275 事件 | `/mnt/e/fl_il_data/replays_part000000.jsonl`(21.8 MB)、`census_part000000.json` |
| ② 回放 → IL 训练对 | `scripts/fl_il_to_bc.py --mode samples` | 2200 局、10 进程、`card_level=11`、0.5 s 决策帧 | `runs/_fl_il_bc/{train,holdout}/bc_*.pkl`（2.0 GB / 47,715 条） |
| ③ BC 训练 | `rl/human_play.py --bc-train`（**既有通路，未改一行**） | 38,838 训练样本、3 epoch、loss = `-logprob` | `runs/_fl_il_bc/bc_fl.pt` |
| ④ 留出判读 | **新** `scripts/il_eval_holdout.py` | 8,877 留出、`hidden=None`、三基线 + 宏 recall | `holdout_bc_fl.json`、`holdout_random_init.json` |

留出判读 40 s。数据源**只下了 1 个分片**（17.4 MB，与官方声明字节数逐字节相同）。

## 2. J1 · 管线可行性（两条判据全 PASS）

### 2.1 过滤漏斗（5000 局 → 3528 局）

| 拒绝原因 | 局数 |
|---|---|
| 局时长 > 我们引擎的 300 s 硬上限 | 1008 |
| 卡组含无法解析的卡键（`void` 等，普查里 `void` 出现 501 次） | 409 |
| `game_mode` 不在白名单（`1v1 Showdown` / `Normal Battle`） | 49 |
| 我方出牌 < 4 次 | 6 |
| **保留** | **3528（70.6%）** |

### 2.2 J1.1 卡牌经济对账（**外部真值**）＝ **PASS：99.72%**

逐局逐侧核 `Σ_{play_card} 实际费用` vs 回放自带的 `aggregate_stats[side].total[1]`：

- 双侧同时一致：**3518 / 3528 = 99.72%**（闸门 ≥90%）
- 我方侧：**3528 / 3528 全对**，总花费 **359,456 == 359,456**（逐圣水相等）
- 张数对账：双侧 **3528 / 3528**
- 残差 **10 / 3528 = 0.28%**：**全部含 `Mirror`**（10/10），方向混合，成因**未定**【R10】

★ **本仪器第一版口径错，修正后 99.32% → 99.72%**：`Mirror` 的实际费用 = **上一张牌费用 + 1**
（`rl/action_mask.py:30-36`），且 `Mirror` **不覆盖** `last_card`（`player.py:47`）。
第一版用**卡面费** `Card('Mirror').elixir`（=1）⇒ 当时 **24 个残差侧全部含 Mirror、而 0/7044 无 Mirror 的侧有残差**
（2×2 列联表由脚本复算）——**责任在仪器，引擎实现是对的**（这一点最初写成了「引擎缺口」，此处更正）。

### 2.3 另外两条外部对账（零成本、全对）

- `payload.events` 的条数 == `actions/part-*.parquet` 的逐局行数：**4997 / 4997**
- `payload.events[].coordinates.native_world_units` == actions 表的 `native_x/native_y`：**6530 / 6530**

### 2.4 J1.2 标签量 ＝ **PASS：47,715 ≥ 20,000**

2200 局 → **737,207 帧**、50,244 个「我方恰好 1 手」的帧 → **47,715 条标签**（0 错误）。
另有 244 个「同帧 ≥2 手」的帧按预注册丢弃（仍打进战局）。

## 5. J3 · 模仿质量（留出 8,877；同一仪器、同一留出、配对比较）

### 5.1 读数表

> 未训练对照 = `FollowerPolicy` **随机初始化且播种**（`torch.manual_seed(0)`）：不播种时每次运行抽到不同权重，
> 实测两次 `top1` **0.3287 vs 0.3261**、`nll` **8.72 vs 8.80** ⇒ 对照读数不可复现（本轮已修）。

| 指标 | 随机初始化 | IL 训后 | trivial 基线 |
|---|---|---|---|
| NLL（`evaluate`，与 BC 训练同口径） | 8.6492 | **5.5962** | — |
| 落点精确（给定选择正确） | 0.07% | **12.10%** | 0.17%（576 格均匀） |
| 落点精确（不分选择对错） | 0.62% | **9.98%** | — |
| top-1 option | 32.91% | **40.42%** | uniform-6 **16.67%** / uniform-4 **25%** / **常数槽 4 = 39.84%** / 常数最高频卡 = 6.32% |
| 宏平均 recall（4 槽） | 34.62% | 35.76% | 常数预测器 **25%** |
| 逐槽 recall | 0.411 / 0.352 / 0.347 / 0.275 | 0.220 / 0.306 / 0.342 / **0.563** | — |

### 5.2 判读（**两句话，都要写**）

1. **落点侧确认学到**：给定「出哪张牌」猜对的前提下，落点逐格命中 **12.10%**（随机初始化 0.07%，
   均匀 0.17%）；整条动作分布的 NLL **8.65 → 5.60（−35%）**。这是**明确**的学习证据。
2. **出牌选择侧未获证实**：top-1 **40.42%** 只比「恒选槽 4」的 **39.84%** 高 **0.58 pp**；
   宏平均 recall 只从 34.62% → 35.76%（+1.3 pp），且训后是靠**放大槽 3 的偏置**换来的
   （槽 3 recall 0.266→0.563，代价是槽 1 recall 0.412→0.220）。
   ⇒ 换句话：模型学会了「**在哪儿放**」和「**动作分布长什么样**」，但**没有**学会
   「**人类此刻为什么出这张牌**」。

### 5.3 ★ 预注册闸门失效（必须点名的仪器缺陷，【R16】）

预注册写死「top-1 option ≥ 40% ⇒ PASS」。实测本留出集的**常数预测基线 = 39.84%**
⇒ **闸门恰好压在 trivial 基线上，PASS/FAIL 无分辨力**；随机初始化策略也能拿 **32.91%**
（因为它对槽 4 有初始偏置，而标签分布本就偏斜）。
**处置**：预注册判定**照写为 PASS**（不篡改），但**实质结论以上表第 2 行为准**（= F5 弱信号）；
下一轮预注册必须**改用「配对 + 宏平均 + 相对 trivial 的余量」判据**（阈值余量 ≫ 散布）。

### 5.4 健康度

留出 8,877 条**全部** `logprob > -1e8`（0 条被掩码静默掩掉）⇒ 数据集与掩码**自洽**
（这是 BC 侧最容易静默出错的地方）。
