# 当前问题归因：critic 塌成常数 ⇒ 优势失去信用分配 ⇒ 上限停摆（2026-09-13）

> **本文回答的问题**：`d1_long_100k` 之后，为什么**防崩成立（最差锚点 0.237 ≫ 无干预的 0.000~0.025）**，但
> **绝对强度停在随机初始化水平**（41 点均值 0.570 vs 零点 0.625），且 **critic 的 EV 11 个全点里 9 个 ≈0 或负**？
>
> **证据分级**：`A` = 本次会话亲自复算/读码可复现；`B` = 来源为子智能体报告或既有文档（我未独立复核）；
> `C` = 单一来源或间接。**所有 A 级数字都可用文末命令重放**。
>
> **一句话结论**：不是"训练量不够"，也不是"学习率/尺度压制"。**价值分支（`value_enc_fc` → `value_enc_ln` → `value_head_mlp`）
> 除了最后一层偏置以外，在 27 个 2.5k 窗口里有 22~24 个窗口拿到的是"逐位为零"的梯度**——
> 价值函数实际上是一个常数（缓慢漂移的运行均值）。价值函数是 PPO 里唯一把"一局的标量胜负"摊到
> "每一帧具体决策"的部件；它一旦恒为常数，优势就退化成"折扣回报 − 常数"，策略梯度每局只剩下一个
> 低信息量的标量。再叠加**训练目标是相对目标**（60% 对手是本 run 自己的历史骨架，绝对参照只占 7.8%），
> 策略只能在"反制自己的血统"这个方向上移动（RPS 循环），无从获得绝对强度的爬坡。

## 0. 问题陈述（可否证形式）

**命题 P0**：`d1_long_100k` 的 critic 之所以 EV≈0，原因是"训练量不足 / 价值目标尺度不匹配 / 价值头结构不够深"。

**本文判 P0 为假**，并给出替代命题 **P1**：

**命题 P1**：critic 塌缩的具体形态是「**价值头隐藏层对几乎全部训练帧输出恒零**，只有输出层偏置在训」，
因此价值输出 = 一个慢漂的常数；其第一性原因是**价值编码器末端的 `LayerNorm` + 近常数输入**，
使价值头从一开始就无法产生所需量级的输出方差（10k 时输出 std 0.015，而回报 std ≈ 12.11，差约 3 个数量级），
随后隐藏层 ReLU 逐个死亡并锁死（死 ReLU 梯度精确为零 = 吸收态）。

**否证 P1 的判据**（跑之前写死）：若在 100k ckpt 的真实帧上测得
`value_head_mlp[0]` 的 ReLU 存活率 **> 30%**，或该层权重的逐窗相对位移与策略侧同量级（≥1e-2），
或价值输出 std ≥ 1，则 P1 被否证。

## 1. 因果链（主因 / 次因 / 并列）

```
[设计层] 价值编码器末端 LayerNorm（follower.py:246,310）
        + 近常数输入 fused（恒定分量 60~80 vs 跨帧变化 20~41，B）
                │  归一化后：逐维跨帧 std 0.0022~0.0072，恒定分量 ‖·‖≈11.6（B）
                ▼
[机制层] MLP0 输入信噪比 ~0.5~2% ⇒ 逐帧变化 0.11~0.25（B）
        ⇒ 价值头可表达的跨帧方差上界 ≈ |W_last|(0.777) × 0.18 ≈ 0.14   ← A 级参数实测
        而"拟合回报"需要输出 std ≈ 12.11 × √EV ≈ 8.6
        ⇒ 差 ~60~600 倍，且**增长 W_last 的梯度 ∝ Cov(a, v−R)，a 近似常数 ⇒ 梯度≈0**（自举失败）
                ▼
[锁死] MLP0 的 64 个 ReLU 逐个死亡：存活率 46.9%(10k) → 3.13%(20k) → 1.56%(25k/30k) → 0%(100k)（B）
        a ≡ 0 ⇒ 上游权重与输出层权重的梯度**精确为零**（吸收态）
                ▼
[指纹，A] 35k→100k 的 27 个窗口里：
        value_enc_fc.weight      22/27 窗口位移**恰为 0**
        value_head_mlp.0.weight  22/27 窗口位移**恰为 0**
        value_head_mlp.2.weight  24/27 窗口位移**恰为 0**（max 相对位移 4.4e-5）

                ▼
[后果] value ≡ 漂移常数 ⇒ EV≈0 是**结构性必然**，不是"还没学会"
                ▼
[策略侧，独立] 优势失去状态级信用分配 ⇒ 每局只剩一个标量信号
        + 训练目标相对化（hist 60%、绝对锚点 7.8%、RPS 三角确凿）
        ⇒ 策略梯度 ≈ 沿"反制自身血统"方向的有噪随机游走
```

## 2. 本会话新增的 A 级证据

### 2.1 参数级指纹：价值分支只有"输出偏置"在动

对 `runs/d1_long_100k/solo_main_{0,2500,…,100000}.pt` **全部 41 个 checkpoint** 逐窗（每 2.5k 步 = 27 个窗口）
计算「张量位移 L2 ÷ 该张量 L2」，取中位数与"位移恰为 0 的窗口数"：

| 张量 | 参数 L2 @100k | 窗口位移恰为 0 | 中位相对位移 | 最大相对位移 |
|---|---|---|---|---|
| `slot_head.weight`（策略侧） | 1.545 | **0/27** | 9.86e-2 | 1.55e-1 |
| `cell_head.weight`（策略侧） | 19.126 | **0/27** | 8.52e-2 | 2.57e-1 |
| `enc_fc.weight`（共享主干） | 10.988 | **0/27** | 8.75e-2 | 2.24e-1 |
| `value_enc_fc.weight`（价值侧） | 14.046 | **22/27** | **0.000e+00** | 1.43e-2 |
| `value_head_mlp.0.weight` | 5.699 | **22/27** | **0.000e+00** | 3.44e-3 |
| `value_head_mlp.0.bias` | 0.557 | **22/27** | **0.000e+00** | 2.60e-3 |
| `value_head_mlp.2.weight` | 0.777 | **24/27** | **0.000e+00** | **4.44e-5** |
| **`value_head_mlp.2.bias`** | 0.524 | **0/27** | **4.41e-2** | 2.08e-1 |
| `value_head.weight`（**未使用**） | 0.589 | **27/27** | 0.000e+00 | 0.000e+00 |

**读法（这三行就是全部结论）**：

1. **策略侧 100% 的窗口都在动**，价值侧除输出偏置外 81~89% 的窗口**位移精确为 0**。
   在 Adam 下"位移精确为 0"只有一个成因：**该参数的梯度精确为 0**（Adam 的 m、v 都是 0 ⇒ 步长 0）。
   这排除了"梯度很小但非零"的解释（Adam 会把任何非零梯度的步长放大到 ≈lr，与梯度幅值无关）。
2. **输出层权重与输出层偏置的行为截然分裂**：`mlp2.weight` 24/27 窗口冻结（最大 4.4e-5），
   而 `mlp2.bias` 每个窗口都在动、幅度与策略侧同量级。这正是「隐藏层激活 a ≡ 0」的指纹：
   `∂L/∂W2 = ∂L/∂v ⊗ a`（a=0 ⇒ 0），而 `∂L/∂b2 = ∂L/∂v ≠ 0`。
3. `value_head.weight/bias` 是 37 个参数里**唯二**逐位冻结的（0 与 100k 完全相同），因为
   `value_independent=True` 时它们**不参与前向**（`follower.py:309-314` 优先级 independent > bypass > shared）。
   ⇒ 旧诊断脚本 `diag_value_head.py` 打印的正是这两个死参数，**对该通路毫无信息**。这是一个长期存在的诊断盲区。

### 2.2 分支级对比：价值分支的总位移是策略分支的 1/1000 ~ 1/50

按"value-only 参数组（8 个）L2 位移" vs "其余策略侧参数组（25 个）L2 位移"逐窗对比：

| 窗口区间 | 比值（价值 / 策略）中位 | 范围 |
|---|---|---|
| 35k → 100k（27 窗） | **≈5e-3** | 5.4e-4 ~ 1.9e-2（50k 窗异常高，1.1e-1） |

即：**在同样的 Adam 下、同样的 2.5k 步里，策略分支整体移动约 1.5~5.2，价值分支只移动 0.002~0.04。**

### 2.3 量级核算：价值头为何"就算想拟合也拟合不了"

`follower.py` 的价值通路（`value_independent=True`）：

```
fused → value_enc_fc: Linear(2731, 128) → ReLU → value_enc_ln: LayerNorm(128)
      → value_head_mlp: [Linear(128, 64) → ReLU → Linear(64, 1)]
```

- 输入 `fused`：恒定分量 ‖·‖ 60~80、**跨帧变化 20~41**（相对变化 35~51%）——**这不是问题所在**（B）。
- 经 `value_enc_fc + ReLU`：恒定 188~217、跨帧变化 6.5~20.7（相对 3.5~9.9%）（B）。
- 经 `value_enc_ln`（LayerNorm 把每个样本的向量归一到单位方差）：**恒定分量恒为 ‖·‖≈11.6**，
  跨帧变化被压到 **0.11~0.25**（相对 1~2%）（B）。
- ⇒ MLP0 的输入**方向几乎不随帧变化**。价值头可表达的跨帧输出变化上界
  ≈ `‖W2‖ × ‖Δa‖` ≈ `0.777 × 0.18` ≈ **0.14**（`‖W2‖=0.777` 为本文实测，A）。
- 而目标 `R` 的量级：`run_state.json` 的 `ret_scaler` = `count 99840 / mean 2.9001 / m2 14649179.6`
  ⇒ **回报 std s ≈ 12.11**（A）。一个 EV=0.5 的 critic 需要输出 std ≈ `12.11×√0.5 ≈ 8.6`。
- **⇒ 差 60~600 倍。** 且要把 `‖W2‖` 从 0.777 涨到 ~48 才能补上，而
  `∂L/∂W2 ∝ E[(v−R)·a] = Cov(v−R, a)`；当 `a` 近似常数且 `v` 近似常数时该协方差 ≈ 0
  ⇒ **自举失败的闭环**：需要 W2 变大才能产生方差，而产生方差的梯度又需要 a 已有方差。
- 早期实测（B）：10k 时价值输出 std = **1.49e-2**（= 回报 std 的 0.12%），此后单调下降到 0。
  ⇒ 价值头**从未**进入可拟合区，塌缩不是"学到一半坏掉"，而是"从头就没起来"。

### 2.4 仪器更正：锚点的 40 局**不是**每点同一批（实证）

`AGENTS.md` §3.1 与 `docs/eval_cadence_c_2026-09-13.md` §5 写的是
「每评估点重打同样 40 局 ⇒ 锚点是权重的确定性函数」。**实测不成立**：

- 代码链：`eval_control(..., RAND_ANCHOR_EVAL_SEED)` → `eval_solo_parallel` →
  `env_kwargs["deck0"] = list(env.deck0)`（`train_solo.py:968`）→ worker `env.reset(seed=seed_base+2000+g)`
  （`train_solo.py:862`）。
- 而 `RLEnv.reset()` 是**原地链式洗牌**：`deck0 = list(self.deck0)` → `shuffle(deck0)` → `self.deck0 = deck0`
  （`env_wrapper.py:349-357`）。⇒ 训练期间父进程 env 的 `deck0` 已被反复覆盖，
  **每次评估点拿到的其实是"当前训练 env 的牌序"当作链的起点**。
- 实证：11 个评估点的 `replays/league_*.pkl` 里 `meta.decks[0]`（= 该点评估首局的 `env.deck0`）
  **11 个点 11 种不同的牌序**，无一重复（本文 A 级复算）。
- ⇒ 正确表述：**锚点是 (权重, 父进程牌序状态) 的函数**；固定种子只固定了 40 局之间的相对偏移，
  没固定起点。**后果**：`1σ=0.078` 是**真实**的噪声地板（好消息，判据因此仍然有效），
  但相邻两点的差分 SE = `√2×0.078 = 0.110`，所以「相邻 |Δ|≈0.225~0.240 ≈ 3σ」应改为 **≈2.05σ**。
  （`0.538`（70k→80k）与 `0.513`（80k→90k）≈ 4.7~4.9σ ⇒ 谷底是真的，C7 的**方向**不受影响，
  但"3σ"这个数字作废。）

## 4. 对上游子智能体报告的 3 处更正（必须记住，否则后续会话会照抄错方向）

1. **「40k–100k `value_head_mlp[0].weight/.bias` 逐位冻结」——不成立。**
   实测 40k→100k 该权重最大变化 **5.45e-3**（非 0），27 个窗口里 22 个为 0、**5 个非 0**。
   真正逐位冻结的只有 `value_head.weight/bias` 两个，而它们是**该通路下不参与前向的死参数**。
   ⇒ 用"逐位冻结"描述会诱导后续会话去找一个不存在的"参数被冻住"的 bug；正确措辞是
   **"绝大多数窗口梯度精确为零、少数窗口拿到约 1 次 Adam 步（≈3e-5，与 lr×(1−β1) 同量级）"**。
2. **「`1/s²` 使 critic 梯度放大约 147×」——方向反了。**
   `v_loss = v_mse / s²` 是把 loss（连同梯度）**除以** `s²≈147`，不是放大。
   而且在 Adam 下这个除法对逐参数步长基本是中性的（m/√v 同比缩放），它实际起的作用是
   **防止 critic 梯度淹没策略梯度**（全局裁剪阈值 0.5 是共享的）。
   ⇒ **不得以"压制 critic"为理由去关 `value_norm`**（关掉只会让 critic 淹掉策略）。
3. **「Φ 每帧密度被 γλ 放大 ⇒ 30+ 分/每 1 费差」——口径算错。**
   `reward += edw*((me_a−op_a)−(me_b−op_b))`（`env_wrapper.py:253`）是 **potential 的差分 ΔΦ**，
   在折扣累计下是望远镜求和：`Σ(γλ)^k ΔΦ ≤ 2·max|Φ|`（≈资源差量级，上限十几分），
   **不是 per-frame 值 × 1/(1−γλ) ≈ ×38 的量级**。
   ⇒ Φ 项**不足以**解释"躺平即最优"；要证它有害必须做 `edw=0` 消融（**至今未做**）。

## 5. 策略侧：为什么上限不动（与 critic 相互独立的一半）

### 5.1 训练目标是相对目标（A 级池配比复算）

终局对手配比（`docs/train_d1_long_100k.log` 41 行"对手池刷新"逐行复算）：

| 对手种类 | 局数 | 占比 | 名义 | 含义 |
|---|---|---|---|---|
| `hist` | 225 | **60.2%** | 0.6 | **本 run 自己的历史快照**（12 槽全历史均匀骨架） |
| `defend` | 70 | 18.7% | 0.2 | 脚本防守 |
| `frozen` | 50 | 13.4% | 0.1 | 冻结副本（自引用） |
| `rand_anchor` | 29 | **7.8%** | 0.1 | **唯一的绝对参照**（固定随机权重策略） |

而 hist 池的选择规则是 `np.linspace(0, N−1, 12)`（`train_solo.py:187-221`）——**含端点 0**
⇒ `solo_main_0.pt`（本 run **未训练**的随机初始化）被**永久钉在 0 号槽**，
其余 11 槽横跨全历史（100k 终点 = 0 / 7.5k / 17.5k / 25k / 35k / 45k / 52.5k / 62.5k / 72.5k / 80k / 90k / 100k，
成员平均年龄 ≈ t/2 ≈ 50k 帧）。

⇒ **训练目标 = 「打赢我过去 50k 帧里各个时期的自己」占 ~2/3。** 这是一个**没有绝对方向的**目标。

### 5.2 RPS 三角（B 级，既有取证）

| 对阵（main 侧胜率） | 读数 |
|---|---|
| main@20k **vs 冻结副本**（自引用） | 0.850 |
| main@20k **vs 训练起点 baseline0** | 0.130 |
| main@20k **vs 全新随机策略** | 0.505 |
| 全新随机 **vs baseline0** | 0.660 |

即"学到的能力"在传递性上不成立：**能赢自己的起点，但和全新随机打平，而全新随机能赢自己的起点。**
这正是不带绝对锚点的自对弈的典型产物：策略沿"反制自身血统"的方向移动，
该方向在绝对强度上无意义，并周期性把自己带进被随机策略打败的相位（80k 的 0.237）。

### 5.3 critic 与上限的耦合（本文的核心论点）

- 价值函数是 PPO 中唯一把"整局的标量结果"分摊到"每一帧具体决策"的机制。
  它恒为常数 ⇒ 优势退化成"折扣回报 − 常数"，**每局只能提供 1 个标量级的信息**。
- 定量：每 update = 128 帧 = **0.479 局**（批内 `corr(R_t,R_{t+1})≈0.99`，B），
  全程 374 局 / 780 次更新 / 12,480 次 Adam step。
- ⇒ **信息量与样本量脱钩**：把帧数从 20k 加到 100k（4~5×），每帧携带的有效信息没变，
  所以最差锚点没有位移（与 20k 组区间 [0.125, 0.250] 无统计差别）。
- ⇒ 这解释了 X4"加量救不了 critic"与 O1"上限不动"**是同一件事的两面**，不是两个独立问题。

## 7. 判别性实验（预注册要素，按"信息量/成本"排序）

### 实验 1（最便宜，~10 分钟，不改训练）：**critic 惰性检验**——把 critic 拿掉，看曲线是否一样

- **单变量**：现有配置基础上，把优势计算改为"纯 REINFORCE + 运行均值基线"（等价于 `v ≡ const`），
  其余全部不变。
- **要问的**：如果 critic 真的已经等于常数，那么**去掉它应该不改变结果**。
- **判据（跑前写死）**：20k 协议一次。若 20k 末点锚点与现基线差 **< 0.11**（= √2σ，相邻独立读数差分 1σ）
  **且** 41 点序列的块 worst 落入 [0.125, 0.250]，则"critic 当前贡献 ≈ 0"被确认 ⇒ §5.3 的耦合论点成立。
  若出现显著**变好**（> +0.11），则说明 critic 当前是在**帮倒忙**（用错的价值函数提供偏差优势），
  命题要改写为"critic 有害"；若显著变差，则 critic 仍在提供部分信用分配，§5.3 需降级。
- **成本**：20k ≈ 25~40 min（含评估）。

### 实验 2（便宜，~1 h）：**给价值通路去归一化 / 改目标尺度**（针对主因，非"换架构"）

- **单变量（三选一，先做 **a**）**：
  a) `value_enc_ln` 改为恒等（去掉末端 LayerNorm，让 MLP0 直接吃 `relu(value_enc_fc(fused))`）；
  b) 目标归一化：喂给价值头的是 `R/s`，使用时输出 `×s`（真正的"尺度对齐"，而非只除 loss）；
  c) 输出层零初始化 + 输出缩放补偿。
- **先决**：必须先写**存活率/输出方差探针**（见实验 3），否则无法判断"是去掉了 LN 起效，还是别的"。
- **判据（跑前写死）**：10k 短跑。成功 = ① `value_head_mlp[0]` ReLU 存活率 **≥ 30%**（现基线 1.56%@25k）；
  ② 价值输出 std / 回报 std **≥ 0.05**（现基线 0.00002@25k）；③ 池化 EV **≥ +0.2** 且 4 个评估点里 ≥3 个为正。
  失败 = EV 仍 ≤0 或存活率 <10% ⇒ 主因改写，LN 假设作废。
- **成本**：10k ≈ 12 min 训练 + 评估。

### 实验 3（最便宜，~5 分钟）：**把价值通路的健康做成常驻探针**

- 不改训练，在 `eval_and_write` 里对最近约 700 帧真实 rollout 记录：
  `value_head_mlp[0]` ReLU 存活率、`mlp0_post` 跨帧 ‖Δ‖、价值输出 std、唯一值个数、
  **以及价值分支各参数的窗口位移**（本文 §2.1 那个指标，零成本，直接从 ckpt 算）。
- **为什么必须有**：现有 `THRESHOLDS` 只监控 `h_std`（GRU 主干）与 `n_abs`，
  两者在 100k 全程**健康**（0.067~0.095 / 0.667~0.826），而价值头已经死了。
  **监控看错了通道**——这是本次能拖到 100k 才发现的第一位流程原因。

### 实验 4（针对策略侧，~2.2 h）：**绝对参照加剂量**（= 既有 O1 的 D2）

- **单变量**：`rand_anchor` 0.1 → 0.3（`_OPP_MIX` 单一来源，两处同改）。
- **判据**：分块 worst 至少 1 块 ≥0.475（现基线第 2 块实测），或 41 点均值 ≥0.680（0.570+0.11）。
  否证 = 全部块 worst 落回 [0.125, 0.250]。
- **注意**：若要同时验证 §5.3，须**先做实验 1**（确认 critic 惰性），否则"加绝对参照有效"与
  "critic 修好后有效"两种解释无法分离。
