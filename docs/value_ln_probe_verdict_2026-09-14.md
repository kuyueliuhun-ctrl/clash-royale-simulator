## §3 自披露：G-UP 的阈值是**跨实验照抄**来的（这是本轮最重要的方法学教训）

预注册 §3.1 给 G-UP 定 0.15 的理由写的是"沿用第二轮预注册的同一套阈值，目的是与 P3 判决的读数同尺度可比"。
**这句话是错的，而且错法是新的**：

- 第二轮（`pomdp_ceiling2_prereg`）的 **A 集 = 原始 `obs` 展平，8648 维**，Ridge `EV_within = **+0.2999**`；
- 本轮的 **L0 = `fused`，2731 维「编码后」融合特征**，Ridge `EV_within = **+0.0884**`。

两者**不是同一个量纲**（一个是原始观测，一个过了 `grid_ln → CNN → concat` 的编码器；
维数、尺度、可读性都不同）。把 0.15 直接搬过来，等于**用一个为 A 集标定的闸门去卡 L0**。

**失败方向是安全的**（闸门过严 ⇒ 挡住判决，而不是放过一个假结论），但它**浪费了 25 分钟算力
并让本轮没有产出判决**。⇒ 立一条新红线（见 `AGENTS.md`）：

> **【红线 R15】判据阈值不许跨实验照抄**：每个实验的闸门阈值必须在**该实验自己的量纲**上标定
> （要么用本实验的对照/阳性靶定标，要么用"上一步实测值 × 系数"并写明依据），
> **不许以"与上一个实验同尺度可比"为理由复用数字**。

（同日已有的另一条同类教训是【否证 X-15】：跨脚本复用的**过滤条件**没验证过。
R15 管**阈值**，X-15 管**口径**，两者是同一族失误。）

## §4 描述性结论（**不判决**，但值得记）

按预注册 §3.3，读数落在"闸门不过"这一行 ⇒ **一律只作描述**。三条：

1. **`value_enc_ln` 不是掉点层。** 在它**之前**的 `relu_ln` 已经跌到 **−0.0183**，
   LN 之后是 **−0.0173** —— **LN 前后没有可测的差别**。
   ⇒ 若非要按阶梯读，掉点在 **ReLU 或更早**（`relu_ln` 的 128 维里 **75% 零方差被丢弃**，
   只剩 32 维活着）。**"LN 把线性信号压掉了"这个假设没有得到支持。**
2. **但是掉点也可能根本不在编码器内部。** 上游 `fused`（价值编码器的**输入**）本身就只有
   **+0.0884**，而 round-2 在同一 ckpt / 同一 seed 上测**原始 obs** 是 **+0.2999**。
   ⇒ **"线性可读的局内信号在共享感知前端就已经损失了约 2/3"** 是一个更强的候选，
   但**本轮没有在同一批帧上同时测原始 obs**，所以这只是跨实验的**旁证，不是同源对照**
   （见 §6 与 §7）。
3. **分辨率不足是硬约束。** 全阶梯从 +0.088 到 −0.018，跨度只有 0.11；
   而阳性对照是 +0.75。层间差（+0.088→+0.052→−0.018）在这个估计器上**不足以区分**
   "编码器丢了信号"与"信号太弱读不出"。**不得**把 §4.1 当结论。

## §5 两条**独立于探针信号**的机制读数（这两条不依赖 EV，是本轮真正可用的产出）

### 5.1 价值头在当前权重下的放大能力，**差 9.7 倍**

| 量 | 值 |
|---|---|
| 目标的局内 std | **7.745** |
| `post_ln` 的局内变化幅度 `‖每维局内 std‖₂` | **0.3165** |
| ⇒ **需要的增益** `gain_needed` | **24.47** |
| 训练后价值头的最大放大 | `σmax(W₁)·σmax(W₂) = 2.9033 × 0.8702` = **2.5264** |
| ⇒ **缺口** | **9.7 ×** |

**读法**：`‖relu(W₁x)−relu(W₁x′)‖ ≤ σmax(W₁)‖x−x′‖`、再乘 `σmax(W₂)` ⇒ **2.5264 是价值头在
当前权重下从 `post_ln` 到输出的放大上界**。而目标要求 24.47 倍。
⇒ 在**当前权重**下，**无论优化器做什么，价值头都放不出目标的跨帧变化**。
结合【红线 R14】（这些张量在 22~24/27 个窗口里**位移恰为 0** ⇒ 权重**永远不会增长**），
**"价值函数 = 常数"就是自洽的**：需要的增益从来没有出现过，而梯度又不让它出现。

> ⚠️ 这条**不**等于"架构错了"：增益是**可以学的**（`W₁` 可以长大）。
> 它只是把 R14 的"吸收态"从一个观测事实，变成一个**有数量级的**事实。

### 5.2 塌缩的完全体在本轮再次逐位复现

- `value` 的 `EV_within = 0`、**唯一值 1 / 29998**、`std = 1.490e-08`、
  `std(V)/std(R) = 0.000000`；
- `mlp0_post` **逐帧 ReLU 存活率 0.000000、全零帧占比 1.0000**（64 个单元全死）；
- `relu_ln` 逐帧存活率 0.1469、存活维占比 0.2500；
- `value_enc_ln` 的 γ 均值 **+1.0355**、‖γ‖ 11.7212、‖β‖ 0.3417（LN 参数正常，**不是 LN 被关掉**）。

⇒ 与 `docs/critic_inertia_verdict_2026-09-13.md` §0.1 ④ 的独立复核一致（那里是 **1/600**，本轮 **1/29998**）。

## §6 已知口径缺陷（必须在下一轮修）

1. **`post_ln` 选中的 α = 1e-1 = α 网格的**下边界**。**
   按台账 §2 病理 ⑩ 的检查法（"最优超参是否落在网格边界"），**落在边界就是网格不够宽**。
   `post_ln` 想要**更少**正则 ⇒ 它的 **−0.0173 可能被过度正则压低了**，
   **不能**读成"LN 之后没有线性信号"。**下一轮必须把 α 网格下界扩到 1e-6。**
   （`fused` 1e4 / `pre_ln` 1e0 / `relu_ln` 1e2 都在网格内部，不受影响。）
2. **G-UP 阈值跨实验照抄**（§3）⇒ 下一轮按 R15 用**本实验自己的**标定。
3. **没有在同一批帧上测原始 `obs`**（§4.2）⇒ `fused` +0.088 与 round-2 原始 obs +0.30 的对比
   是**跨实验旁证**，不是同源对照。
4. **`relu_ln` 的 dim 从 128 掉到 32**（75% 零方差维被丢）⇒ 它的读数要在 **32 维**下解释，
   不能与 128 维的层直接比"容量"。
5. 单 ckpt / 单 seed / 单一对手（【红线 R5】）。

## §7 下一轮（预注册版）应该怎么做

**目标**：回答"线性可读的局内信号是在**共享感知前端**丢的，还是在**价值分支内部**丢的"。

1. **同一次 rollout 同时抓**：`raw_obs`（原始 obs 展平，作为**参考集**，不进阶梯）+
   整条阶梯（`fused → pre_ln → relu_ln → post_ln → mlp0_post → value`）。
   ⇒ 这才是**同源配对**对照（同一批帧、同一目标、同一切分）。
2. **α 网格下界扩到 1e-6**（修 §6.1）。
3. **闸门按 R15 重新标定**：对本实验的量纲，用"**阳性对照 ≥0.15**、**时钟基线 ≤0.05**、
   **两个状态打散 ≤0.05**"三道**结构性**闸门（它们与量纲无关），
   **再**加一道"**上游可读性 ≥ 本实验实测的 `raw_obs` 的 1/2**"——
   **不要**再写一个从别的实验搬来的绝对数。
4. **判据分支**：若 `EV_within(raw_obs) ≥ 2 × EV_within(fused)` ⇒ **信号损失在共享感知前端**
   （⇒ 修价值头/拆价值编码器都无效，要做的是**感知前端**）；
   否则若 `relu_ln < 0.05 ≤ pre_ln` ⇒ 掉点在 ReLU；
   否则若 `post_ln < 0.05 ≤ relu_ln` ⇒ 掉点在 LN（**本轮未支持**）。
5. **在此之前不做任何架构改动**（【红线 R3】/预注册 §3.3）。

## §8 追记（2026-09-14）：两个在本轮之后才查清的问题

### §8.1 对照 ckpt 已跑完：`fused` 的可读性**不是**稳定属性

`runs/d1_long_100k/solo_main_20000.pt`（100k run 的**活相位**末点，即 R14 的 **M2 型**：
"在动但拟合不上"），同一套参数（st seed 7 / stoch / 30000 帧）跑完：

| ckpt | `EV_within(fused)` | `value` 唯一值 | `std(V)/std(R)` | `mlp0_post` ReLU 存活率 | LN γ 均值 |
|---|---|---|---|---|---|
| `critic_inert_probe_20k`（本文主 ckpt，M1 塌缩） | **+0.0884** | 1 / 29998 | 0.000000 | 0.000000（全零帧 1.000） | +1.0355 |
| `d1_long_100k@20000`（M2 活但未拟合） | **−0.0081** | **29151 / 29849** | **0.003220** | 0.031250（全零帧 0.000） | +1.0300 |

**两条读数**：

1. **`fused` 的线性可读性在 ckpt 之间从 −0.008 到 +0.088** —— 同一个估计器、同一个 seed。
   ⇒ §4.2 那句"信号在共享感知前端损失约 2/3"**只是那个 ckpt 的性质**，
   **不能**当"编码器结构性地丢信号"来读。
2. **M2 被独立仪器再次确认**（【红线 R14】）：critic **不塌**（29151 个唯一值、变化量 0.0032 倍回报）
   但 `EV_within = −0.000005` ⇒ **`EV` 对 M1（吸收态）与 M2（活着但拟合不上）给同一读数**。
   这与 R14 的跨 run 扫描互证。

### §8.2 ⚠️ 本探针的 `EV_within` **绝对值跨 rollout 不可复现**（【否证 X-16】/ 病理 ⑪ 部分播种）

查清 v1 与 v2 的 `fused` 数值差异时发现：

- 同 ckpt、**同 seed 7**、**同一 `feat_obs` 特征构造**，两次随机 rollout 的
  `EV_within(raw_obs)` = **+0.2999**（32982 帧 / 149 局，round-2 的 cache）vs
  **+0.1629**（29654 帧 / 135 局，本文 v2）——**差 1.84×**；
- **机制（代码级）**：`rl/follower.FollowerPolicy.act` 的动作采样是
  `slot_dist.sample()`（**全局 torch RNG**），而 `probe_value_ln.py` / `pomdp_ceiling_probe.py`
  **从未 `torch.manual_seed`**（后者唯一的 `manual_seed` 在 `fit_mlp` 内部）
  ⇒ **每个进程一条全新轨迹**；
- **实测互证**：两个 cache 的 `y`/`ep` **第 0 帧起就不同、100% 帧不同** ⇒ 是**轨迹差异**，
  不是"多采了几千帧 / 切分不同"。

**对本判读的影响**：

| 本文的判据 | 类型 | 是否受影响 |
|---|---|---|
| G-UP / G-RAW（`≥0.15`） | 绝对阈值 | **⚠️ 已因【红线 R15】作废（跨量纲）**；X-16 再补一刀：**同量纲也不可跨 rollout 比** |
| G-PC / G-CLK / G-SCR | 同 run 内对照 | ✅ 不受影响 |
| `L0..L5` 阶梯**层间**比较 | **同一次 rollout 内的配对** | ✅ 不受影响（同一批帧、同一目标、同一切分） |
| `post_ln` 的 `gain_needed = 24.47` vs `max_gain_head = 2.5264` | **与探针无关**（只用权重与逐帧统计） | ✅ 不受影响 |

⇒ **"LN 不是掉点层"这条描述性读法保留**（它是同一次 rollout 内的层间配对）；
**但所有绝对值（+0.0884 / +0.0521 / …）不得作为"信号强度"引用。**

**已立的纪律**：新增**第 10 道闸门「复现闸」**（固定种子跑两次、前缀逐位一致）；
修法：探针跑前 `torch.manual_seed(seed)`。
