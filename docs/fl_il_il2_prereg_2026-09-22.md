## 0. 一句话目标

现在的塌陷（部署 **0.3 次/局**、10 局全平、出牌帧 top1 **0.4042→0.0174**）**同时符合两种机制**，必须先分开再花钱：

* **H-A 优化/混比**：save 帧占 **77.1%**，共享 `slot_head` 的 STOP logit 被多数类推高；且 Adam+bs=1 下**逐样本 loss 加权是 no-op**（尺度无关）⇒ 只有**改混比**能动。
* **H-B 表示不足**（用户假设）：act 决策所需的量（对手手牌/循环/圣水、双方距下一点圣水的帧数、对手刚下了什么）**不在输入里** ⇒「何时出牌」原则上不可判 ⇒ 最优解就是多数类。

**Stage 0 用「信息增益上界」把两者分开，再按性价比排后续。**

## 1. 口径（跑前定死）

### 1.1 观测量 vs 不可观测量（**这条决定 F_obs / F_oracle 的分界**）

| 量 | 人类回放里 | 判定 |
|---|---|---|
| 我手牌（重建 4 槽）、我圣水（重建）、时间、`next_card` | 可重建 | **F_obs** |
| 对手**已出牌**（卡 + 位置 + tick） | **真值可读**（回放事件） | **F_obs** |
| 对手手牌**后验** `hand_probs(8)`、下一张后验 `next_probs(8)`、`elixir_mean/uncertainty`、事件 token | **推断量**（`CycleBayesFilter`，128 粒子） | **F_obs** |
| 我/对手「距下 1 点圣水还有几帧」 | **精确可算**（`battle.py:2881`：2.8 / 1.4 / 2.8÷3 s 每点 ⇒ 每决策帧 **0.1786 / 0.357 / 0.536** 点） | **F_obs 候选**（EBK，【R12】） |
| 对手**真值**手牌 `opp_hand(4)` / 循环 `opp_cycle(8)` / 下一张 `opp_next` / **真值圣水** `opp_elixir` | **不可观测**（回放里没有） | **仅 F_oracle**（诊断用，**不进最终策略**） |

⚠️ **真值只作标签 / 辅助任务 / 上界诊断，不进主观测**（用户已确认的纪律②）——否则「预判」退化成读答案。
⚠️ 对手圣水在回放里不可观测：我方引擎侧是 `_force_elixir` 重建值（出牌强制率 **2.17%**）⇒ 凡用它的结论都标「重建口径」（【R10】）。

### 1.2 帧总体与标签

* 总体 = **掩码放行 ≥1 个「有合法落点」出牌槽的决策帧**（= `save` 帧 ∪ `play` 帧；2200 局里 **686k** 帧）。
* 标签 `act ∈ {0,1}`：该帧人类是否打出牌（`play` 帧 = 1）。
* **切分 = 按局（`tag`）分组留出**（【R9】）：5 折 GroupKFold，AUC 的 CI 用**按局 bootstrap**（不是按帧——帧间强相关）。
* 样本量：**先 200 局**；若 `ΔAUC ∈ [0.03, 0.07)`（边界带）⇒ **自动扩到 600 局再判**（写死，不许事后挑样本量）。
* 分类器 = logistic 回归（`C` 由内层按局 CV 选）+ 直方图 GBM 各一；**两族同向才算数**（防单模型假象）。

## 2. Stage 0 判据（本轮要跑的）

| # | 判据 | 阈值 / 处置 | 失败分支 |
|---|---|---|---|
| **J7.0** | 仪器门：所有特征由脚本复算（禁手抄）；分箱统计每箱 **n ≥ 500** 才报 | 硬约束 | 违反 ⇒ 读数作废 |
| **J7.1** | **ΔAUC = AUC(F_oracle) − AUC(F_obs)**（同帧、同折、配对 bootstrap CI） | **≥ 0.05 ⇒ H-B 优先（先做输入阶梯 Stage 1）**；**< 0.05 ⇒ H-A 优先（先做混比 Stage 4）**；`[0.03,0.07)` ⇒ 扩到 600 局复判 | 扩样后仍落在带内 ⇒ **判「不可分辨」**，按成本择先（写：先混比，因它更便宜） |
| **J7.2** | 阈值基准：**只用「我圣水」的单变量 AUC**（【R15】本实验自己的量纲） | 后续所有 AUC 增益都要与它比 | — |
| **J7.3** | 对手预判（描述性 + 门禁）：规则 filter 的 **next-card top-1 / NLL** vs **常数（最常见牌）** / 均匀 | 规则 filter **必须 > 常数**，否则记「belief 无信息 ⇒ Stage 2a 的对手头必须同时 > 常数 **且** > 规则 filter」 | — |
| **J7.4** | 分箱曲线：**人类 vs 模型** `p(act \| 圣水分箱)`（模型用现有塌掉 ckpt 与旧基线 ckpt 各一条） | 描述性（无门禁），用来指认 **H2 自强化陷阱**（期望看到：塌掉 ckpt 在**高圣水箱**比人类更倾向不出） | — |

**新仪器**：`scripts/il_act_upper_bound.py`（J7.1–J7.2、J7.4）、`scripts/il_opp_prediction.py`（J7.3）、帧特征导出 `fl_il_to_bc.py --dump-frames`。
**本轮不训练任何网络**（Stage 0 只用小分类器与现有 ckpt 的读数）。

## 3. Stage 1–4 的门禁（后续各项跑前只看这一节）

### 通用
* **单变量**：每次只加一项；对照臂 = 同批同 worker 数（跨进程 **5.9%** 漂移在案）。
* **性价比账本**：每项必须报 `Δact-AUC / ΔNLL(play) / Δ部署出牌`，**增量与收益同批配对**（【R17】），**无收益回滚**（【R11】修订版）。
* 参数增量由 `scripts/count_vectors_ckpt.py` **复算**（【R4】）。

### J8（Stage 1 输入分派）
| # | 判据 | 阈值 |
|---|---|---|
| J8.1 | act-AUC 增益 | **> J7.1 得到的 bootstrap 噪声带**（同批帧） |
| J8.2 | play 组条件项不许退 | **top1 ≥ 0.35** 且 **NLL ≤ 5.75**（基线 0.4042 / 5.5962） |
| J8.3 | 部署行为（**双侧**） | 局均出牌 **∈ [18, 28.5]**（人类 22.8 的 ±20%） |
| J8.4 | 「进 conv vs 进 MLP」的分派要**被证明** | 两条接线各跑，Δact-AUC 同向且 > 噪声带，否则记「无差」 |

### J9（Stage 2 多任务输出 / 回喂）
| # | 判据 | 阈值 |
|---|---|---|
| J9.1 | 对手头有效性 | next-card **top-1 > max(常数, 规则 filter)** 且 Brier 更小 |
| J9.2 | 辅助头不伤主任务 | play 组 NLL 劣化 **≤ 0.15** |
| J9.3 | 安全回喂（独立 belief 输出当输入） | J9.1 达标 + J8.3 仍在带内 |
| J9.4 | 自回喂 | **必须与 Stage 3 时序训练同轮**；teacher forcing + scheduled sampling + 置信度门控 + **停滞指标**（空 bundle 率 / 局均帧 / 高圣水帧占比 / 局均出牌）全报 |

### J10（Stage 3 时序）
* 先**算**窗口 `W`：人类「等待段」长度分布 ⇒ 取 `P(段长 ≤ W) ≥ 0.9`；两臂（帧堆叠+1D conv / GRU 截断 BPTT）同 W、同参数预算。
* 判据：act-AUC + play 组 NLL + 双侧行为带 + **等待段长度分布**（区分「学会等」与「只会不出」）。
