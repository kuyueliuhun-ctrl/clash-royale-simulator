### 2.1 读数（复算，非印象）

| 指标（bridge_left 局） | 我方 | 上游 |

| 河带 `y∈[15,17]` 内**越出桥廊**帧数 | **2 / 222** | **0 / 280** |
| 桥廊内**最大同时**在员 | 7 | 6 |

| 末只过河时刻 | **6.0 s** | **8.3 s** |

**两条能复述的观察**：
- 我方过桥**更快清空**（末只 6.0 s vs 8.3 s），但过桥后**横向摊得开 6.5 倍**（1.3 vs 0.2 格），
  并且**有 2 帧存在个体在河带内跑到桥廊之外**（几何上就是河面上）；上游 0 帧。
- 我方**单只最长静止 3.5 s**（桥头互顶），上游最长 0.9 s（该局）——即「卡住」这一现象
  **我方在桥头更重**，而上游在 `behind_king` 局更重（最长 29 帧 = 2.9 s）。

### 2.2 机制：候选**两条**，本文**不判**是哪一条（【R10】）

1. **`_lane_offset`（我方独有）**：部署时给每个出兵位置打「相对部署中心的横向偏移」
   （`battle.py:3193-3195`，截断 ±0.8），行进时把路点沿法线平移（`battle.py:1281-1287`）。
   上游**没有这个字段**（其 `Troop.__init__` 无 `_lane_offset`，`get_spawn_position` 无打标）。
   ⚠️ 一个**可解释「越出桥廊」的路径**：偏移按**出兵环**坐标算（±0.55），但单位实际位置
   已被碰撞炸开到 ±2（§5）⇒ 偏移把**本来就在桥边缘外**的单位再往外推 0.55 格。
   该解释**只是假设**，§6 的单变量消融就是为它设计的。
2. **碰撞分离强度**：我方 `resolve_collisions`（`battle.py:3299-3303`）对 e1 的位移**不减半**，
   上游（`battle.py:741-757`）**减半（`*0.5`）** ⇒ 同样是挤在一起的 15 只，我方推开得**更猛**。
   §5 的实测与这条**方向一致**（同为桥头局，首帧横向宽度 **3.9 格 vs 3.0 格**）。
   ⚠️ 但这只是**相关性**：本轮没有做 `*0.5` 的单变量消融。

## §4 O3「己方半场不主动靠近桥心，走到河道才转向桥」

### 4.1 读数：**成立，且只有我方如此**

`behind_king` 局，两个**互相独立**的指标都指向同一结论：

| 指标 | 我方 | 上游 |
|---|---|---|
| 平均 \|Δ该单位最终那座桥的中心\|：y=2 / 4 / 6 / 8 / 10 / 12 / 14 | 2.53 / 2.53 / **2.61 / 2.60 / 2.59 / 2.57** / 1.99 | 3.38 / 1.97 / 1.83 / 1.33 / **0.89 / 0.85 / 0.80** |
| **横向行程完成度**（0=还在出兵 x，1=已到桥心）：y=6 / 10 / 14 | **0.363 / 0.35** / 0.528 | 0.60 / **0.833** / 0.833 |

- **我方**：横向行程在 y=6 就停在三成半，**y=6 → y=10 一动不动（0.363 → 0.35）**，
  最后**一半的横移全部发生在 y≈14→15 这两格**，即**到河道才拐**。
- **上游**：**持续**收拢，y=10 已完成 **83%**，到 y=14 稳定在离桥心 0.80 格。

⚠️ **口径限定（【R17】）**：两仓的**首帧团块宽度不同**（我方 x∈[6.7,12.2] vs 上游 [7.7,11.0]），
所以 **y=2 那一行的绝对值不可直接对拍**；可对拍的是**趋势**（y=4→12：我方恒 2.53→2.57，
上游 1.97→0.85）与**按单位归一化的完成度**（第二行）。

### 4.2 机制：我方是**一次刻意改动**的直接后果（代码逐字）

| | 我方 | 上游 |
|---|---|---|
| 桥面格 `'.'` 的 A\* 代价 | **5**（= 普通地面）——`pathfinding_heap.py:135-140` | **8** ——`pathfinding_heap.py:99-100` |
| 河道可走性 | **硬阻挡**，只放行两条桥带 `x∈[2,5)` / `[13,16)` ——`arena.py:106-119` | **河格可走**（`BLOCKED_TILES` 已移除河；`is_walkable` 无河分支）——`arena.py:46-55` |
| 通道 | 只有 3 格宽的两条桥 | 全河面可穿越（只是贵） |

我方那 5 是**刻意**改的，注释逐字写着原因（`pathfinding_heap.py:136-139`）：

> `# 桥面代价与半场地面一致（5）：真实 CR 桥 3 格宽，三车道过桥`
> `# 代价相同，单位保持部署时的横向车道（2026-09-10 用户机制：`
> `# 桥头左侧的单位上桥后靠左、右侧靠右，寻路按边缘最近贪心）。`
> `# 旧值 8 让 A* 把单位吸向更便宜的桥中央地面格，抹平车道。`

⇒ **两条结构因果**（与读数方向一致）：
1. **上游的横向收拢来自「河可走但贵」**：整条路线在**部署那一刻**就被 A\* 全局规划，
   而穿越点越靠桥心越短 ⇒ 路线**很早**就开始向桥心偏（实测 y=6 已完成 60%）。
2. **我方把河设为硬阻挡、且桥面不再比地面贵** ⇒ 在 A\* 的代价面上**河道方向没有横向梯度**，
   `pathfinding_ground_walkable` 只在**真正贴到不可走河带**时才迫使路径横向平移 ⇒
   「沿原 x 直走，到河道才拐」。

**⚠️ 这不是 bug，是取舍**：那条改动的目的（保持车道、避免全部吸到桥心）**正是**
2026-09-10 用户自己拍板的机制。⇒ 本文只陈述**后果**，不主张回退；
若要改，属**新实验**，须按【R3】另行预注册（本文 §6 的消融**不是**它）。

## §6 单变量消融：`_lane_offset` 是不是「过桥后横向散布」的成因？

### 6.1 预注册（**跑前写死**；本节在任何消融读数产生之前落盘）

- **问题**：我方**独有**的 `_lane_offset`（部署时按出兵环打标、行进时平移路点）
  是不是「过桥后横向散布」（§2.1 中位 1.3 格 / 越出桥廊 2 帧）的**主要成因**？
- **单变量**：只把 `Troop._lane_offset` 强制 `0.0`，**其余逐字不变**
  （外部猴补丁，**不改引擎源码**；开关 = `scripts/skarmy_probe.py --no-lane-offset`）。
- **基线（脚本复算，禁手抄）**：`runs/skarmy_probe/replays/league_1800.pkl`（无开关）
  ⇒ 两座桥的过桥后横向跨度中位均 **1.3 格**；河带内越出桥廊 **2/222**（左局）、**2/222**（右局）。
- **主判据（两条同时满足才算 H1 成立）**：
  (a) 两座桥的过桥后横向跨度中位 **≤ 0.65 格**（= 基线的 50%）；
  (b) 河带内越出桥廊帧数 **= 0**（两局皆是）。
- **失败分支（写死）**：若横向跨度中位 **> 0.91 格**（= 基线的 70%）⇒
  **`_lane_offset` 不是主要成因**，§2.2 的候选 1 记为「未定」，**不得**写成「已排除」。
- **中间带**：0.65 < 中位 ≤ 0.91 ⇒ 只记「**部分贡献（弱）**」，不写「是/不是」。
- **阳性对照（必须，否则本轮不可判）**：消融录像的 sha256 **必须与基线不同**
  （证明开关真的生效）。若相同 ⇒ 判「消融未生效」，本轮**作废**。
- **同一性对照**：`--no-lane-offset` **关**（默认路径）重跑一次，必须与基线**逐字节相同**
  （静音对手 + 固定 seed ⇒ 确定性）。
- **写作禁则**：只写「是/不是主要成因」与幅度；**不写**「更好/更差」「修好了」；
  不把本条并入任何疗效判据集。

### 6.2 结果（已跑完；判据按 §6.1 **机械判定**）

**两个对照（先过对照才谈判据）**

| 对照 | 要求 | 结果 |
|---|---|---|
| 阳性对照：消融录像 sha256 ≠ 基线 | 必须不同 | **通过**：`11d152fa26df222a…` ≠ `254c661efbba45a4…` ⇒ 开关真的生效 |
| 同一性对照：默认路径重跑 == 基线 | 必须逐字节相同 | **通过**：重跑 sha256 = `254c661efbba45a4…`，与基线**逐字节相同** ⇒ 确定性成立、默认路径零扰动 |

**主判据（(a) 与 (b) 必须同时满足，H1 才算成立）**

| 判据 | 基线 | 消融后 | 门槛 | 判定 |
|---|---|---|---|---|
| **(a)** 过桥后横向跨度中位（左桥 / 右桥） | 1.3 / 1.3 格 | **0.2 / 0.2 格** | ≤ 0.65 | **满足**（−85%，且与**上游参考值 0.2 逐值相同**） |
| **(b)** 河带内越出桥廊帧数（左桥 / 右桥） | 2/222 、 2/222 | **7/244 、 7/244** | = 0 | **不满足**（反而变差 3.5 倍） |
| (b′) 同项（王塔后局） | 2+3 | **0+0** | = 0 | 满足 |

⇒ **合取判据不成立** ⇒ 按 §6.1 的写死条款，**H1 原命题（「`_lane_offset` 是过桥后横向散布**与**越出桥廊的共同成因」）未被证实**。
⚠️ 但这**不等于「消融无效」**：判据之所以不成立，是因为它把**两个不同现象捆成了一个命题**（见 §6.3 与 §6.4）。

### 6.3 消融分离出的六件事（本轮真正的产出）

| 现象 | 基线 → 消融 | 结论 |
|---|---|---|
| **过桥后横向跨度中位** | **1.3 → 0.2 格** | **`_lane_offset` 是主因** —— 这是本轮**唯一被证实的因果**，且幅度与上游参考 0.2 逐值相同 |
| 河带内越出桥廊（**桥头**局） | **2 → 7 帧**（变差） | 与 `_lane_offset` **无关**，去掉它反而更差 ⇒ 成因**未定** |
| 河带内越出桥廊（**王塔后**局） | **5 → 0 帧** | 该局与 `_lane_offset` **有关**（方向相反）⇒ **同一指标在两局不是同一个成因**（【R17】并列不调和） |
| 过桥后 x 方向反转均值 | **1.0 → 1.27** | 「横向散布」与「反复改向」**不是同一个量**：`_lane_offset` **减小散布但增加改向** |
| 分道数量（O4）／首帧团块宽度 | **不变**（6/9、15/0；3.9 / 5.5 格） | 出兵爆炸与分道**都与 `_lane_offset` 无关** |
| 己方半场收拢（O3） | **不变**（平台 2.57→2.58；完成度 0.36 / 0.37 / 0.51） | **O3 与 `_lane_offset` 无关** ⇒ §4.2 的「代价表 + 河格硬阻挡」解释**未被本消融动摇** |
| 最长静止段（桥头局） | 35 → 30 帧 | 变化小，**不单独解读** |

**一句话（消融）**：`_lane_offset` 唯一被证实的作用是把**过桥后的横向散布从 0.2 抬到 1.3 格**；
它**不解释**越出桥廊、**不解释** O3、**不解释** O4，而且**略微增加**过桥后的改向次数。

### 6.4 判据瑕疵（留档，自己的错）

§6.1 把「横向散布」与「越出桥廊」写成**合取**判据，等于**预先假设两者同源**——
而这个假设**本身是错的**。所以「合取不成立」既是**判据有判别力**的证据（它真的把命题否掉了），
也暴露一个方法论错误：**这类消融应当先分离现象、再逐现象写判据**。
⇒ 本条已按原样保留，不追溯修改 §6.1（只增不改）。
