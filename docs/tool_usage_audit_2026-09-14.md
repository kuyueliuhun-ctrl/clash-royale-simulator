# 外置工具接线与使用审计（2026-09-14）

> **触发**：用户问「我们已经有工具让模型去算未来塔伤，模型真的用了吗？」
> **仪器**：`scripts/probe_tool_usage.py`（只读；§1 静态扫描全仓调用点，§2 真 ckpt 消融实测）。
> **样本**：ckpt `runs/d1_long_100k/solo_main_100000.pt`、200 决策帧、CPU、随机对手、递归隐状态跨帧携带。

---

## §0 结论

| 工具 | 是否接进决策路径 | 「模型用了吗」的答案 |
|---|---|---|
| **① 未来塔伤** `threat_calc.estimate_tower_threat` | ❌ **零生产调用** | **不成立**——模型**没有机会**用它（唯一调用点是它自己的对账 selftest） |
| **② 交换模拟器** `simulate_exchange` | ✅ 但只被**对手**调用 | **是对手在用**（`SelfDefenderPolicy`），我方模型没用 |
| **③ 法术知识** `spell_module` | ✅ 两条路径（掩码闸门 + 规划器） | 间接用上了，**但见 §2：网络自己学到的部分 ≈ 0** |

**更强的读数（§2）**：在真 ckpt 上把**帮手信息整个置零**，策略的动作分布**几乎逐位不变**——
`belief` 通道的影响 **≈3e-9（数值零）**，`plan` 的**学习分支**贡献上界 **1.7e-4**；
`plan` 唯一可见的效果（KL 均值 1.7e-2、槽位翻转 4.5%）**全部来自硬编码软偏置**，
不是网络学出来的。⇒ **当前模型"没用"这些通道，不是因为没接线，而是因为没学会用。**
附带重大读数：**P(不出牌) = 0.945**（策略 94.5% 概率质量落在 STOP）。

## §1 静态接线（脚本扫描 + 逐条人工核对）

扫描方式：遍历 `src/clasher_new/**/*.py`，正则匹配工具入口函数名，**排除定义文件自身与 selftest**。
⚠️ 扫描是**文本级**（注释/docstring 中的提及也会命中）⇒ 下表已**逐条人工核对**：

| 工具 | 生产命中 | 核对结论 |
|---|---|---|
| ① `estimate_tower_threat` | **0 处** | 全仓仅 `rl/selftest.py`（5 处对账测试）⇒ **从未被生产代码调用** |
| ② `simulate_exchange` | 3 处 | `spell_module.py:27`＝docstring 提及；`rl/opponents.py:126`＝docstring；**`rl/opponents.py:157`＝真调用**（`from simulate_exchange import script_defender`，在 `SelfDefenderPolicy` 内）⇒ **对手脚本在用** |
| ③ `get_spell_profile` | 5 处 | `rl/action_mask.py:131-132`（9h 法术对塔 EV 硬闸门）、`rl/belief_planner.py:268-270`、`rl/mcts.py:262` ⇒ **真接进决策路径** |
| ③ `best_cast` | 3 处 | `rl/belief_planner.py:257-273`（法术落点估值 → plan） ⇒ **真接进规划器** |

**① 的接线缺口还有一个具体反差**：`belief_planner.py:160-173` 需要威胁估计时，
用的是**自己写的粗略近似**（`threat += 1.0 + max(0, (16 − y)/16)`），
而**不是**已经过引擎对账的工具①。⇒ 这是【R12】「能算的不许让网络猜」的**反向**情形：
算得准的没用上，用了算不准的。

## §2 动态消融：模型对已接线通道的反应（真 ckpt，n=200 帧）

设计：同一帧、**同一 GRU 隐状态**下比较四种条件的第一决策步**槽位分布**（含掩码）：
A＝完整；B＝plan 向量在、**软偏置关**（隔离"网络自己学的 plan 分支"）；
C＝plan 置零 + 偏置关；D＝**belief 置零**。

| 条件对比 | KL(A‖·) 中位 | KL 均值 | 槽位 argmax 翻转率 |
|---|---|---|---|
| B plan 学习分支（偏置关）vs A | 0.000e+00 | 1.731e-02 | 4.5% |
| C plan 置零+偏置关 vs A | 0.000e+00 | **1.731e-02** | 4.5% |
| D belief 置零 vs A | 0.000e+00 | **2.985e-09** | **0.0%** |

**分离读数（关键）**：
- **plan 学习分支的贡献上界** = 逐帧 `|KL_B − KL_C|` **最大 1.669e-04（中位 0）**；
- **belief 的影响上界** = 逐帧 `max|p_A − p_D|` **最大 1.634e-04（中位 0）**。

**读法**：B 与 C 的 KL 均值完全相同（1.731e-02）⇒「plan 向量在」与「plan 向量置零」在偏置关闭后
**结果一致** ⇒ **`plan_mlp` 学习分支的贡献比硬偏置小两个数量级**，而硬偏置是**人手写的常数**
（`PLAN_CARD_BIAS=0.8 / PLAN_HOLD_BIAS=2.5 / PLAN_REGION_BIAS=0.8`，`follower.py:42-44`）。
`belief` 的影响则在数值噪声以下。

**附带读数**：P(STOP) 均值 A=**0.947** / B=C=0.945 / D=0.947 ⇒ 策略绝大多数概率质量落在"不出牌"。

## §3 三条结论

1. **"模型用没用工具"必须分两层问**：**接没接线**（§1）与**学没学会用**（§2）。
   工具①卡在第一层（没接线）；工具③过了第一层但在第二层失败（网络没学会用 plan/belief）。
2. **加更多工具/更多通道的期望收益 ≈ 0**——因为**现有辅助通道已经被证明是死的**
   （belief 影响 3e-9、plan 学习分支 1.7e-4）。这与【P3′】（belief/特权通道增量上限 +0.4~1.1pp）
   方向一致，但比它更强：不是"信息价值小"，而是"**网络对这些通道不敏感**"。
3. **工具③的可见影响全部由硬偏置承担** ⇒ 当前策略的"计划性"来自**人手写的 logit 偏置**，
   不是学习结果。这与行为取证里"策略近乎无计划地打便宜牌"是同一现象的两种读数。

## §4 建议（按"先修用不用得上，再加东西"排序）

| 优先 | 做什么 | 成本 | 判据 |
|---|---|---|---|
| **P1** | **先测"辅助通道的梯度有没有到"**：用【R14】的逐窗 `‖ΔW‖/‖W‖` 指纹扫 `plan_mlp` / `belief_mlp`（现有仪器 `scripts/value_displacement_scan.py` 的模式，需扩到这两支）——若出现"位移恰为 0"的窗口，根因就是**梯度精确为零**（吸收态），而非"信息没用" | 小（只读扫 ckpt） | 位移恰零的窗口数 > 0 ⇒ 判"通道梯度死" |
| **P2** | 若 P1 显示通道活着而网络仍不敏感 ⇒ 查**尺度/条件数**（`plan_f`/`belief_f` 只有 64 维且被 2560 维 `grid_feat` 压住，见 `follower.py:219-232` 的历史取证） | 中 | 融合层各分量范数比 |
| **P3** | 把工具①接上（替换 `belief_planner` 自写的粗略威胁近似，或作为 plan 的显式字段） | 中（规划器改动，无架构变更） | 需先过 P1/P2，否则大概率**白接**（§2 第 2 条） |
| **不做** | 在 P1/P2 出结果前**新增**任何辅助通道/工具输入 | — | 【R2】新增架构改动要 `--fresh`，而"网络不敏感"的问题不会被新通道解决 |

## §5 局限（预先声明）

1. **单 ckpt / 单 run / 200 帧**（`d1_long_100k@100k`）⇒ 不跨 run 外推（【R5】）；
   尤其**不能**推断"所有 ckpt 都不用辅助通道"——需在多个 ckpt 上复测。
2. 只测**第一决策步的槽位分布**；**cell 分布与后续 decoder 步未测** ⇒ 待确认。
3. 对手为 `opponent=None`（随机），非训练对手池 ⇒ 状态分布与训练不同。
4. §1 的扫描是**文本级**：已人工核对命中行，但**不排除**通过字符串/动态导入调用工具①的可能
   （未发现证据，标为待确认）。
5. `unexpected=8`（ckpt 有 8 个未被当前模型使用的键）未深究，可能对应 `value_independent=True`
   下的 `value_head.*`（【R14】已记录其不在前向路径）。
6. 本审计**只回答"用没用"**，不声称"接上工具能提升强度"；收益上限见【P3′】与 §2 第 2 条。
