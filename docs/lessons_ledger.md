## 2. 病理分类学（13 类）与最小检测手段

| 类 | 病理 | 我们的实例 | 最小检测手段（可抄） |
|---|---|---|---|
| ① | **in-sample 口径**（读过拟合，不是读能力） | X1 | 一切"预测质量"必须在**参数更新前**、且在**独立 rollout**上读 |
| ② | **时间泄漏**（逐帧随机留出） | X2 | 留出必须**按局分组**；先报 `corr(R_t, R_{t+1})` |
| ③ | **单 run 曲线外推** | X4 | 结论必须写进**预注册判据**；跨 run 数字默认不可比（R5） |
| ④ | **自引用仪器**（打自己/打刚同步的副本） | X6、X-13 | 只用**外生绝对仪器**（固定随机锚点）；自引用指标一律不作进步证据 |
| ⑤ | **基线不可信 / 阈值无标定 / 阈值跨实验照抄 / 阈值用单次观测标定** | X7、X9、**R15 实例**、**R16 实例** | 基线**脚本复算**；阈值改为**相对本 run 首点**；**跨实验复用阈值前先问"这是同一个量纲吗"**（R15） |
| ⑥ | **口径混装 / 口径未验证**（eval 侧统计当训练侧结论；**跨脚本复用的过滤器/阈值没验证过就当事实用**） | X8、**X-15** | ① 声明每个数字的**样本集**；比值分子分母同集（R9⑤）；② **任何被第二个脚本或外部方复用的过滤条件，必须先用一条独立证据验证一次**（X-15 用的是"费用是否被扣"）——注释里写着"非法/未执行"**不算依据** |
| ⑦ | **随机链状态**（看似固定，实则比上次多走了一步） | X10 | 固定种子前后**实测首局牌序**是否相同，不靠推理 |
| ⑧ | **判据在退化情形下成为恒等式** | X-11、X-13 | 问"若被测量退化为 X，这个判据会给出什么？"——若答案与"正常情形"相同，判据无效 |
| ⑨ | **跨相位池化**（把活相位与死相位平均成一个漂亮数字） | X-12 | 报告**分布而非均值/池化值**；批内与池化**两个口径都报**，并声明差异来源 |
| **⑪** | **部分播种**（随机状态只播了一部分：环境播种了、**采样器没播**；或播了相对偏移、没播起点） | X10、**X-16** | **固定种子后实测两次 rollout 的 `y`/`ep` 前缀是否逐位一致**——不一致就说明存在未播种的随机源（本项目已两次：deck 的**原地链式洗牌**、`slot_dist.sample()` 用**全局 torch RNG**）。⚠️ 与 R5 的"前 435 步逐位一致后 1e-4 漂移"是**两件事**（后者是训练路径的浮点非确定性，机制仍未定） || **⑫** | **逐层阶梯用「每层各自选超参」的读数互相比较**（比较的是"这一层的超参好不好选"，不是"这一层有没有信息"） | **X-17** | ① 对已知的**包含关系**（`A ⊇ B`，**逐位可验**）做**同一超参**对账：在各自超参下 `EV(A) < EV(B)` 时该对比较**作废**，不许读成"信息损失"；② 报**整条超参曲线**，不只报 argmax；③ 先问"**有没有一个超参对所有层都公平**"——若各层最优超参相差 ≥2 个数量级，则**"阶梯"这个比较本身没有定义**。⚠️ 与 ⑩ 的区别：⑩ 是**网格太窄**（最优落在边界），⑫ 是**网格够宽但不可共用** |

| ⑩ | **估计器可控范围不足 / 退化层不可比**（超参网格太窄 / 未做保信息降维 / 无输出约束；**在"val 曲线全负或全平"的退化层上，`argmax` 是噪声，两个几乎相同的张量会选出差几个数量级的超参**） | X-14；**2026-09-14 新实例**：价值探针 v4 的 G-OFFLINE EV 子闸——seed 11 的 `enc` 全 α val 为负，逐位只差 **4e-06** 的 `enc` 与 `enc_off` 选了差 10⁵ 倍的 α（1e-4 vs 10），读数差 **8.7e-03**，把一个**张量侧 PASS（4.3e-06）**的检查判成 FAIL | ① 检查最优超参**是否落在网格边界**——落在边界就是网格不够宽；② 给估计器一个**平凡解下界**（"预测训练均值" = EV 0），保证任何取值都不会比它更差；③ 先丢**训练集内零方差列**（保信息、降 d） |

## 5. 技术核心：**参数位移指纹**（本文档最可引用的单条产出）

**命题**：在 Adam 下，**"某张量在一个训练窗口内位移恰为 0" ⟺ "该张量梯度精确为 0"**。
理由：Adam 的更新对 loss 的**常数缩放不变**（`m` 与 `√v` 同比缩放）⇒ 任何非零梯度都会给出 ≈`lr` 量级的步长。

**为什么它比 EV/loss 强**：EV 与 loss 对两种完全不同的状态给出**同一个读数 ≈0**：
(a) **梯度小**（加量/调系数可能救），(b) **梯度精确为零**（吸收态，加量永远救不了）。
位移指纹能分开这两者，**且零成本**（直接从 ckpt 序列算 `‖ΔW‖/‖W‖`）。

**实测（100k，41 个 ckpt、27 个窗口）**：
- 策略侧：**27/27** 窗口全在动；
- 价值侧：`value_enc_fc` / `mlp0` / `mlp2.weight` **22~24/27** 窗口**位移恰为 0**，而 `mlp2.bias` **每窗都动** ⇒ **价值函数 = 常数**。

**两条独立的闭合证据（2026-09-13）**：

| 证据 | 读数 |
|---|---|
| 训练批逐批 EV | `EVb` **145/145 为负**（中位 −3.149、**最大 −0.05**）；批内常数预测器**数学上必然** `EVb ≤ 0` |
| 权重直读（独立实现 `_probe_value_path.py`，600 帧） | `value` **唯一值 1/600** = `value_head_mlp[2].bias` = **+0.1425485**（`std=0`）；`MLP0` ReLU **逐帧存活率 0.000000 / 全零帧 1.000** |

**机制（上游诊断）**：价值编码器末端 `LayerNorm` 把近常数输入归一化 ⇒ 价值头可表达的跨帧方差 ≈ **0.14**，
而目标 std ≈ **12.11** ⇒ 差 **60~600 倍** ⇒ 自举失败 ⇒ ReLU **逐个死亡锁死**（**吸收态、双稳态**：
同一协议三次 20k 里 `_r2` 在 20k 之内就死，r1/r3 到 20k 仍活）。

**已排除的替代解释**：不是"梯度小"、不是被 `1/s²` 压制、不是奖励尺度、不是价值头结构（四代架构 EV 全 ≤0）。

### 5.1 跨 run 指纹扫描（2026-09-13 新增，脚本 `scripts/value_displacement_scan.py`）

**on-path** 值头张量 = `value_enc_fc.weight` / `value_enc_ln.weight` / `value_head_mlp.0.weight` /
`value_head_mlp.2.weight`；窗口 = 相邻 `solo_main_<step>.pt`（2500 步），共 8 窗。

| run | 冻结窗口（on-path） | 读数 |
|---|---|---|
| `critic_inert_probe_20k` | 前 5 窗在动；**12500→15000 / 15000→17500 / 17500→20000 全冻结** | 死于 ~12500（62% 训练量处） |
| `d1_league_20k`、`_r3`、`eind_20k`、`fprime_20k` | **8/8 窗口全在动** | 从未冻结 |
| `d1_league_20k_r2` | 12500→15000、15000→17500 冻结，**17500→20000 又动了** | **准吸收态可逃逸** |
| 6 个 `value_independent=True` run 的 `value_head.weight/bias` | **8/8 全冻结** | **不在前向路径**，不是死亡 |
| `byp_cprime_20k`（`bypass=True, independent=False`） | `value_head.*` **8/8 都在动**（0.024 / 0.035） | 反例，印证"先搞清前向路径" |

**由此得到四条新结论（都进论文）**：

1. **两种失败模式必须分开**：
   - **M1 吸收态**：on-path 张量**位移恰为 0** ⇒ 梯度精确为零（`critic_inert_probe_20k` 后 3 窗、100k run 22~24/27 窗）；
   - **M2 活着但拟合不上**：on-path 张量**在动**、EV 仍 ≈0（`d1_league_20k` 8/8 在动、pooled EV **+0.0183**；
     四代架构变体 `eind_20k`/`fprime_20k` 同样全程在动）。
   ⇒ **EV 把 M1 与 M2 读成同一个 ≈0；位移指纹能把它们分开。** 这是检测器的真正价值。
2. **准吸收态可逃逸**：`d1_league_20k_r2` 在两个窗口完全冻结后又恢复非零梯度
   ⇒ 机制叙述中的 "absorbing" 应改为 **"quasi-absorbing / escapable"**（对"死就永远救不回"的说法是反例）。
3. **`value_head.*` 在 `value_independent=True` 下全窗冻结是"不在前向路径"，不是"死亡"**
   （6 个 run、8/8 窗口），而 `byp_cprime_20k` 里同一批张量 8/8 都在动
   ⇒ R14 的"诊断陷阱"现在有了跨 run 的量化证据。
4. **Layer 1 的惰性不是同义反复**：把该 run 按 12500 切成"活头期（89 点）/ 死头期（56 点）"后，
   `resid_norm` 中位 **0.0473 / 0.0414**（活头期尾部更重：max 1.688 vs 0.290）
   ⇒ 一个**梯度非零、参数在动**的 critic 对优势形状的贡献仍只有 ~5%；
   但**"在动"≠"拟合"**（本 run 逐批 `EVb` 全程 ≤0）⇒ **位移与 EV 是两个正交读数**。
   详见 `critic_inertia_verdict_2026-09-13.md` §0.1 ⑤。

**对论文的影响**：E6（用指纹重判四代架构）**已做**，结论是**分类而非推翻**——
四代变体的值头全程在动，它们不是死于吸收态；因此 §3 的 K4 从
"用指纹提前否掉一个会被接受的错误结论"改写为 **"用指纹把 EV≈0 分成 M1/M2 两类"**。

## 6. 正面结果（论文里必须有一节"什么 work"）

## 8. 检测协议（读者可直接抄的 12 道闸门）

> 任何"指标变好了/模型学会了"的结论，按顺序过这 12 道；任一道不过就不下结论。

1. **口径闸**：这个数字读的是**参数更新前**还是更新后？样本集是哪个？（R9①②）
2. **留出闸**：留出是**按局分组**的吗？先报 `corr(R_t, R_{t+1})`。（R9④）
3. **基线闸**：基线是**脚本复算**出来的吗？（R4）
4. **退化闸**：**若被测量的东西退化为常数/平凡解，这个判据会给出什么？** 若与"正常情形"给出同样的读数，判据无效。（X-11/X-13）
5. **相位闸**：报的是**分布**还是**池化值/均值**？批内与整体两个口径都报了吗？（X-12）
6. **参数闸**：**参数在动吗？** 逐张量 `‖ΔW‖/‖W‖`；出现"位移恰为 0"的窗口 ⇒ 该参数**梯度精确为零**。（R14）
7. **仪器闸**：这个读数是**外生绝对仪器**（固定随机锚点）还是 run 内自引用？自引用读数不得当进步证据。（X6/C4）
8. **估计器闸**（2026-09-13 补）：这个读数是**一个合格估计器**给出的吗？两个子闸——
   **（a）阳性对照（上界）**：构造一个"按构造必然含信号"的靶子，**同一条流水线**必须能打中它；
   **（b）证伪对照**：把信号源打散/置换（保留其余结构），读数必须**塌回去**。
   并且：**在自己的留出集上都劣于平凡解的估计器，其读数不得用来断言"信息不存在"。**
   （用例：① X-14 的发散拟合；② `pomdp_ceiling_prereg` §9 的 V5 ——
   "打散状态、保留时钟 ⇒ `EV_within` 从 +0.20 塌到 +0.005"；
   ③ `pomdp_ceiling2_prereg` 的**四道对照电池**（阳性对照 ≥0.15 / 时钟基线 ≤0.05 /
   状态打散 ≤0.05 / **目标打散 ≤0.05**）——四条同时通过才允许读主判据；
   **合格性由对照决定，不由结论决定**，这是本轮能把"P0 灰区"推进到"P3"的唯一理由）
9. **口径复用闸**（2026-09-14 补）：这个过滤条件/阈值是**谁验证过的**？
   如果它要被第二个脚本、外部方或下一轮复用，必须先用**一条独立证据**验证一次——
   "代码注释里写着非法/未执行/无信号"**不是依据**。（用例：X-15 —— `y≥20` 的"幽灵动作"
   过滤器跨三手复用无人验证，实际把 **452 次合法进攻法术落点**判成了非法；
   独立证据是"本帧费用有没有被扣"。）
10. **复现闸**（2026-09-14 补）：**这条探针的读数可复现吗？** 固定种子跑**两次**，`y`/`ep` 的**前缀必须逐位一致**；不一致 ⇒ 存在未播种的随机源，该读数**只能**用于「同一次 rollout 内的配对比较」，**不得**用作跨 run 的绝对阈值。（用例：X-16 —— `slot_dist.sample()` 用全局 torch RNG 且从未 `manual_seed`，同 ckpt/seed 两次 `EV_within(raw_obs)` 差 **1.84×**。）
11. **超参一致性闸 / 包含闸（2026-09-14 补）**：凡比较 `A ⊇ B`（**逐位可验**）的两层，必须**先用 `np.array_equal` 验证包含关系**，再在**同一个超参**下报差值；在"各自选超参"的读法下出现 `EV(A) < EV(B)` ⇒ 该对比较**作废**，不许当成"信息损失"。（用例：X-17 —— `fused` 的前 2560 列逐位就是 `grid_ln_out`，各自 α* 下低 **0.032~0.059**，同 α 下只差 **≤0.010**。）
    **补丁（2026-09-14，v4；下一轮生效）**：报 `EV(A) vs EV(B)` 时**必须标注两端 α\***；两端 α\* 不同、或任一端 val 曲线**全负** ⇒ 该对比较**降级为描述性**，判据改用**整条曲线的逐 α 比较**。（触发：v4 的 G-OFFLINE EV 子闸在退化层上不稳定，见病理 ⑩ 新实例。）
12. **同一超参阶梯闸（2026-09-14 补）**：报"逐层"读数时，除**每层各自的 argmax** 外，必须同时报**同一超参下的整列**；若两层的最优超参相差 ≥2 个数量级，则**"阶梯"这个比较本身没有定义**，只能读**方向一致**的部分（用例：`grid_ln` 中性 = 3/3 seed、9 个 α 上同向；`fused → enc` 崩塌 = 3/3 seed、每个 α 都成立）。

## 9. 两条"非架构/非程序"的瓶颈（论文的第二个支柱）

用户 2026-09-13 提出的写作条件是"等到项目遇到一个不是来自架构与程序的瓶颈"。**这个条件其实已经（部分）满足**：

1. **自对弈的非传递性 / cycling（C4）**：RPS 三角是**博弈结构的性质**——自对弈必然转圈，
   任何实现都会遇到；D1 只做到"防崩"（C5/C6），没有也不该期望"破除"。
   ⇒ 它是**问题本身的属性**，不是我们的 bug。
2. **（待判）advantage 窗口内回报的状态可预测性**：由
   [`pomdp_ceiling_prereg_2026-09-13.md`](pomdp_ceiling_prereg_2026-09-13.md) 判定。
   若落在 **P2**（连 oracle 隐藏量都解释不了局内回报变化）⇒ 瓶颈是**环境/奖励结构本身**
   （GAE 窗口内的回报不可由状态预测），与我们一行代码无关。
