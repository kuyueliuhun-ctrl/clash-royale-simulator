## 0. 一句话

**用户的怀疑成立**：现有 IL 数据集只取了「人类出牌的那一帧」，**689,492/737,207 = 93.53% 的决策帧被丢掉**，
其中**全部**是「人类没出牌」的帧 ⇒ 训练标签里 **STOP = 0 条**，BC 学到的是
**条件分布 `p(出哪张 | 人正在出牌)`**，而不是策略 `p(出牌 / 不出牌)`。本预注册把「补齐攒费帧」做成**单变量**实验。

## 1. 事实认定（脚本复算，禁手抄）

来源 = `docs/fl_il_2026-09-20/samples_part000000.json`（`scripts/fl_il_to_bc.py --mode samples --games 2200 --workers 10`）
+ 代码路径 `scripts/fl_il_to_bc.py:356-434`。

| 量 | 读数 | 出处 |
|---|---|---|
| 推进的决策帧（0.5 s/帧，2200 局） | **737,207** | `aggregate.frames` |
| 人类「恰好 1 手」帧 | 50,244 | `aggregate.team_single` |
| 人类「同帧 ≥2 手」帧 | 244 | `aggregate.team_multi`（**不产标签**） |
| 实际落盘标签 | **47,715** | `aggregate.labels`（= single − `mask_reject` 2,529） |
| **被丢弃的「人类没出牌」帧** | **689,492（93.53%）** | 737,207 − 47,715 − 244 − 2,529 … 见下 |

**代码级证据**（`scripts/fl_il_to_bc.py`）：样本**只在** `if label_bundle is not None:` 分支里产生（第 424-431 行），
而 `label_bundle` 只在「本帧**恰好 1 个** team `play_card` 事件」且该动作通过我方掩码时才被赋值；
**其余帧一律 `step_bundle = ActionBundle.noop()`（第 434 行）——战局推进了，样本没留**。

**注**：`frames` 口径含 `team_single`、`team_multi`、`mask_reject` 三类「人出过牌」的帧，
真正「本帧人没出牌」的帧 = `team_off`，由新增计数器 `stop_*` 实测（§3 J6.1），**不在此处手算**。

**后果（可检验的预测，写死）**：模型在部署时必须对**从未被监督过**的那些帧输出动作 ⇒
(a) 局均出牌 **35.9**（solo 逐帧臂）显著高于人类 **22.8**（= 50,244/2,200）；
(b) 圣水**从不主动攒**（与 **C14** 同向）；
(c) 「有牌可出却选择不出」这一**决策**在训练集里**零样本** ⇒ 0 梯度（与 C14 的机制同型，但**成因不同**：C14 是采样侧，这里是**标签侧**）。

## 2. 处置（单变量）

给 `scripts/fl_il_to_bc.py` 增加 `--stop-mode {none,save,all}`（**默认 `none` = 逐位保持旧行为**）：

| 模式 | 采集的 STOP 帧 | 理由 |
|---|---|---|
| `none` | 不采集 | 旧口径，仅用于 J6.2 等价性自检 |
| **`save`（本次主用）** | 只采集「我方掩码**至少放行 1 个可出牌槽**」的 STOP 帧 | 这是**真正的攒费决策**（有得选而不选）；掩码禁掉一切的帧**本来就没有选择** ⇒ 其 STOP 项 logprob ≈ 0、梯度 ≈ 0（掩码把它们压到 −1e9），采集它们只增体积不增信息 |
| `all` | 全部非出牌帧 | 保留作对照/审计，不作主口径 |

- **不改**「人类出牌帧」的采集逻辑（47,715 条逐位不变）⇒ 唯一差异 = **新增 save 帧**。
- `--stop-stride S`：save 帧按**全局帧号 `k % S == 0`** 等距抽稀（确定性、无 RNG、覆盖全时程）；
  **候选数一律如实计数**（`stop_save_cand`），抽稀只影响落盘量。训练内存上限见 §5。
- 新目录 `runs/_fl_il_bc_save/{train,holdout}/`；**旧 `runs/_fl_il_bc/` 只读不动**（C15/C16 的证据链）。
- `--with-frames`：额外落 `frames_fl_%04d.json`（`[帧号, "play"/"save"]` 列表）⇒ 为 **L6（时序 BC）** 预留帧序，不改 pkl 元组格式。

## 3. 判据（跑前写死，含失败分支）

| # | 判据 | 阈值 | 失败分支 |
|---|---|---|---|
| **J6.1** | **普查（描述性，无门禁）**：报 `team_off` 帧数、其中「掩码放行 ≥1 槽」(`stop_save_cand`) 与「全被掩」(`stop_forced`) 的比例、save 帧的圣水分布 | 照实报，**不设阈值**（R10） | — |
| **J6.2** | **等价性自检**：`--stop-mode none` 重跑 30 局，与旧 pkl **逐样本全等**（obs 各键 / tok / plan / bundle 子动作 / masks 逐位 `np.array_equal`） | **30/30 全等** | 不等 ⇒ **停**，先修脚本（不得带着未知差异开跑） |
| **J6.3①** | **行为侧（主判据）**：3 ep / lr 1e-3 / seed 0 训练集（旧 play 帧 + save 帧）部署（`--hidden none`，solo 卡组，10 局）**局均出牌数** vs 基线 **35.9** | **≤ 28.7（Δ ≤ −20%）** | 未下降 ⇒ 结论 =「BC 目标（帧级、无时序）才是瓶颈，标签缺口不是」⇒ 下一刀 = **L6 时序 BC**，不是继续补数据 |
| **J6.3②** | **似然侧（守门）**：留出集**只读 play 帧子集**的 NLL 不得劣化超过 **+0.05**（基线 5.4494） | ≤ 5.50 | ①降但②超 ⇒ 结论 =「攒费帧有效，但挤压了出牌建模」⇒ 下一刀 = 损失侧加权，**不换数据**；**不得**由②单独得出「save 帧无用」 |
| **J6.3③** | **校准**：留出集「掩码放行 ≥1 槽」的帧上，模型 STOP 率 vs 人类 STOP 率之差 | **≤ 0.05** | 未达标但①达标 ⇒ 只报行为侧，**不报校准**（写明「未标定」） |
| **J6.4** | **纪律**：不动 lr、不动参数量（R11）、旧目录只读、单变量 = 只加 save 帧 | 硬约束 | 违反 = 本轮作废 |

**阈值自证（R15/R16）**：① 的 20% 标定在**本实验自己的量纲**上——基线 35.9 vs 人类 22.8（差 36%），
而同口径重复性 ~2-3%（`--hidden none` 两臂读数 353/354 与 264/297）⇒ 20% ≫ run 间散布。
② 的 +0.05 标定在留出集 NLL 的**同 run 复现位差**（F0 自检：同种子同配置逐位相同 ⇒ 位差 0；取 0.05 = 保守余量）之上。

## 5. 已知局限（照实报，不粉饰）

| # | 局限 | 影响方向 |
|---|---|---|
| L1 | **`activate_ability` 事件未注入战局**（`_convert_one` 的 `sched` 只收 `e[0]==0`） | 人类用技能的局（实测 team **1.81 次/局**，reconcile 2,200→3,528 局口径）我方状态会**发散**；本轮不修，记为限制 |
| L2 | **圣水不可观测** ⇒ STOP 帧的圣水 = 我方引擎 regen 值 | 实测 `elixir_forced = 1,093/50,244 = 2.18%`（人类出牌时我方圣水**不够付**的比例）⇒ 重建圣水**偏低**的时刻占 2.18%，整体偏低幅度有限；但「放行 ≥1 槽」的判定**依赖**这个重建值 ⇒ J6.1 的数字是**基于我方圣水模型**的口径 |
| L3 | 人类手牌顺序不可观测 ⇒ `_force_hand` 交换率 **8.83%** | 槽位标签含构造性偏差（既有口径，本轮不改） |
| L4 | 内存 | 全量 save 帧可能达 ~10× play 帧；`--stop-stride` 抽稀到训练集总量 **≤ ~150k**（15 GB 内存机上 `load_bc_samples` 全量入内存） |
