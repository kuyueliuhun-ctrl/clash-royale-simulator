## 0. 本轮要回答的问题（与上一轮同一个 Q，不换）

**Q**：在当前实际使用的逐帧输入下，**状态能否解释局内（intra-episode）回报的变化**？
把 oracle 隐藏量加进去，解释力能提升多少？

三个互斥假设照抄上一轮：
**H-POMDP**（信息不足）/ **H-STRUCT**（连 oracle 都解释不了 ⇒ 惰性不是信息问题）/
**H-LEARN**（信息已在现有输入里，只是 critic 没用上）。

## 1. 主估计器（**跑之前写死，本轮不得更改**）

| 项 | 设定 | 理由（**设计理由，不是结果理由**） |
|---|---|---|
| 目标 | **局内中心化回报 `y − ȳ_ep`** | 主判据 `EV_within` 的算子就是"局内中心化"（`docs/pomdp_ceiling_prereg` §2）。**拟合目标必须与评价算子同口径**——否则模型把容量投给"每局水平"（本数据 **82% 方差在局间**，`Var(R)=203.20`、between 166.75、within 58.17），而判据量的是局内 |
| 模型选择 | `--select within`（α 与早停都用 `val_EV_within`） | 同上：选择口径与判据口径必须一致 |
| 模型 | **MLP（主）/ Ridge（对照）**，MLP `--repeats 3` | 沿用上一轮；MLP 容量更接近天花板 |
| 特征集 | A / C / B（定义照抄上一轮 §1） | 不变 |
| 切分 | `--npz runs/_probe_cache_ceiling_stoch.npz`、`--seed 7`、`test-frac 0.25`、`val-frac 0.15`、**按局分组** | **与上一轮逐位相同** ⇒ 可直接比对（R9④） |
| 采样 | `--mode stoch`（上一轮的 32,982 帧 / 149 局 / 17.6 帧·s⁻¹） | 不变 |

**命令（照抄执行）**：

```bash
python scripts/pomdp_ceiling_probe.py --ckpt runs/critic_inert_probe_20k/solo_main_20000.pt \
  --npz runs/_probe_cache_ceiling_stoch.npz --mode stoch --models ridge,mlp --repeats 3 \
  --device cuda --select within --center-target --sets A,C,B --tag v2_primary
```

> **为什么这不是"换估计器换到想要的答案"**：上面每一条都是**口径对齐**的设计要求

> 若这条设计理由站不住，它会在 §3 的对照电池上现形——**四个对照里有三个都能否掉它**。

## 3. 判据（**阈值一字不改，照抄上一轮 §3**；主判据用 MLP）

| # | 条件 | 结论 |
|---|---|---|
| **P1** | `EV_within(B) ≥ 0.15` **且** `EV_within(B) − EV_within(C) ≥ 0.08` | **H-POMDP 支持**：oracle 隐藏量带来实质增量 |
| **P2** | `EV_within(B) ≤ 0.05` | **H-POMDP 否证 ⇒ H-STRUCT**：连 oracle 都解释不了局内回报 ⇒ 挂起 bf 通道不会改变惰性 |
| **P3** | `EV_within(C) ≥ 0.15` **且** `EV_within(B) − EV_within(C) < 0.08` | **H-LEARN**：信息已在现有输入里（含 belief token），oracle 无实质增量 ⇒ 惰性不是 POMDP 的信息缺口 |
| **P0** | 以上都不满足 | **不判决** |

### 3.1 附加预注册子判据（本轮新增，直接回答用户的原始问题）

**P3′（belief/prophet/plan 通道的增量）**：
`EV_within(C) − EV_within(A)` = **belief token 相对原始观测的净增量**（A = `obs` 原样展平；
C = A + belief token 563 维）。判据：

| 条件 | 结论 |
|---|---|
| `EV_within(C) − EV_within(A) < 0.05` | **belief 通道无增量** ⇒ "挂起 bf（belief/prophet/plan）再跑"**不会改变惰性**（该方向的收益上界 < 5 个百分点） |
| `≥ 0.05` | belief 通道确有增量 ⇒ 挂起它会损失已学到的信息，**不该挂** |

> 这是本轮**唯一**新增的判据，写在这里、写在跑之前。它不改 P1/P2/P3 的任何一个阈值。

## 5. 已知局限（跑前登记）

1. 单 ckpt、单 seed、单一对手（自身冻结副本，比训练期混合对手池窄）。
2. 判据是**机制量级**判据（0.05 / 0.15 / 0.08 的宽区间），不是精密估计。
3. 监督探针**没有 RNN**（逐帧 Markov）⇒ A 可能**低估**可观测量天花板（这正是保留 C 集的原因）。
4. oracle 集 B 只含 replay/label 里有的隐藏量；**对手未来决策的随机性不可消除**，
   它构成 `EV_within` 的不可约上界损失——P2 若成立必须照实写这一点。
5. **本轮的估计器是"为这个量定制的"**：它把"每局水平"作为代价换来"局内形状"的拟合能力。
   ⇒ 它的读数**只回答"局内形状可否由状态解释"**，**不能**读成"critic 应该能拟合整局回报"。
