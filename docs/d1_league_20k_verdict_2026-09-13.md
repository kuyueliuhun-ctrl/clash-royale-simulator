## 3. ⚠️ 预注册标定有错，必须披露（这条比结果重要）

（0.750/0.450/0.425/0.725）。连带 P2 的理由句"三次 run 的最后 4 点里都至少有一个 ≤0.075"

⇒ **P1/P2 这两条预注册判据本身没有区分力**：它们无法把 D1（0.600）与一个
"什么都没改的 run"（F′ 首跑 0.588）分开。判据照单 PASS，但**不足以支撑"有效"结论**。

补充全部可得的口径（**不是事后移动球门，是把能算的都摊开**，四个统计量 D1 都是最好，

## 5. 判定规则（**在 r2 结果出来之前写定**）

r1 的结论：**方向提示有效，但未定论**（预注册标定失效 + 单跑噪声 > 待测效应）。
r2（`d1_league_20k_r2`，命令逐字相同，只有 config-name 不同）已启动，判定按下表：

| r2 结果 | 判定 | 下一步 |
|---|---|---|
| 末 4 均值 ≥ 0.35 **且** 最差点 > 0.10 | **两次都过 ⇒ 有效**：D1 进主线（`main`），继续加量（100k） | 长跑 + 行为取证 |
| 末 4 均值 < 0.35 或 最差点 ≤ 0.10（与 r1 冲突） | **不可判**：单跑噪声 ≥ 效应 ⇒ D1 保留为实验开关，**不进主线** | D3 = 3 跑聚合，或改判据为"跨 3 跑的最差点中位数" |
| 末 4 均值 < 0.20 | **无效**：D1 的问题在对手分布之外 | D2 = `rand_anchor` 剂量 0.1→0.3（剂量-反应），或转奖励侧 |

**两条不变的红线**（沿用预注册）：
1. 不判 EV/critic（已证据闭合）；
2. 不判单点胜率与 `gates.json` 的相位型指标，除非能在 3 个以上点复现同一方向。

### 最终判定

**C1 过 + C2 名义过 ⇒ 按 §7 写定的表判为"有效"**，但要说清它有效在哪一层：

1. **成立（强）**：D1 **消除了"整段输给固定随机策略"的相位**。三跑最差锚点
   0.125/0.200/0.250，对照组三跑 0.000/0.000/0.025，区间不相交。
   这正是 cycling 取证里最病态的那条（A′：main 打冻结副本 0.85 / 打随机 0.13）。
2. **未成立（不能宣称）**：D1 **没有证明提高绝对强度上限**。
   用户最初指定的"末 4 点滚动均值"这条判据**两组重叠**（D1 0.312~0.600，
   无干预 0.019~0.588），在 n=3 下不可判——**这不是 D1 无效，是这条统计量本身被
   相位主导**（`fprime_rerun_20k_verdict` §8 的 run 间噪声 sd≈0.29 与效应同量级）。
3. **机制指纹三跑全成立**（镜像自对弈 40% → 6.6% / 13% / ~13%，本 run 快照 1→9 进池，
   PFSP 门禁生效，0 降级 / 0 Traceback）⇒ 结论可以归因到"对手分布"这个变量本身，
   不是某个未观测的伴生变化。

**下一步（按 §7 的表）**：D1 进主线 → 100k 长跑（看上限是否随步数上移）+
行为取证（接敌几何）；若要动上限，D2 = `rand_anchor` 0.1→0.3（剂量-反应，单变量）。

**记录一条方法学教训（第三条，与前两条同源）**：本项目做"阈值判据"的正确姿势是
**先把基线的每一列用脚本算出来贴进预注册**，再写阈值；手抄基线列已经连续出错两次
（r1 的 F′ 首跑末 4 均值、r2 的 C2 基线计数），且两次都是"把基线算弱"，
会让判据看起来比实际更有区分力。这条与 §8 的"单跑不可复现"是同一件事的两面：
**判据的力量必须来自设计（区间/聚合/机制），不能来自对单跑或手算数字的信任。**
