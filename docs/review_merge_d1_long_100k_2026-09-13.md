## 一、问题陈述

**在 `d1_long_100k` 这个 run 上，"100,000 步训练（=99,964 决策帧 / 374 局 / 780 次 PPO 更新 / 12,480 次 Adam 更新）使 main 策略在固定随机锚点上"每阶段胜率 ≥0.5、即不输给随机策略"这一命题为假：41 个锚点中的 5 个区块有 4 个块最差读数 <0.5（最低 0.237 @80000 = 8W/29L/3D）；并且该失败不能由"训练预算不足"解释——把预算从 20k 扩到 100k（4~5×）后最差锚点 0.237 仍落在 20k 组区间 [0.125, 0.250] 内。**

可否证形式：只要出现「块 worst ≥0.5 全 5 块」或「有脚本复算证据表明 20k→100k 的最差锚点统计量被推出 [0.125,0.250]」，本命题即被否证。

## 三、因果链

### 3.1 主因（未定 —— 两条互斥主因并存，现有取证不能定向裁决）

**主因候选 M1：价值通路结构性强直（死 ReLU 吸收态）**
- 证据链（A 级，逐层前向实测）：`fused` 跨帧变化 20~41 → `pre_ln` 6.5~20.7 → `relu_ln`（85~95% 维度恒零）→ `post_ln` **0.11~0.25** → `mlp0_post` **0→0.043→0**；MLP0 ReLU 存活率 100k = **0.000%**，输出方差精确为 0，40k 后 MLP0 权重逐位冻结（`follower.py:303-314`；子任务 5 ckpt 实测）。
- 时序闭合：塌缩与 `vstd/rstd` 30k 后 ≈0.001 同期（`docs/d1_long_100k_verdict_2026-09-13.md` §4）。
- **但不能单独判为主因**：M1 说明「critic 为什么输出常数」，不说明「策略为什么在 80k 掉到 0.237」——两者之间缺一环（critic 塌缩 → advantage 失真 → 策略退化）的直接证据。

**主因候选 M2：对手分布非平稳（hist 池 = 全历史均匀骨架 + 自我对弈 cycling）**
- 证据链：hist 池成员平均年龄 ≈ t/2（100k 时≈50k 帧，`train_solo.py:187-221`）；50% 池换血周期仅 2500 帧；RPS 三角确凿（`docs/rl_training_fix_plan_v3.md:364-369,376-377`）；对照曲线相邻点摆幅高达 0.538（`docs/diag_d1_long_100k.md:26-38`）。
- 与 M1 的交叉点：`R = adv + values`（`ppo.py:188`）**自引用**——`values` 由被训对象给出（critic 报告 §4 表格明列「rollout value 估计 → 是 R 的原料 → 漂移」）。此为结构性事实（A 级），但**「塌缩 → R 尺度 → 梯度」的定量传导未被任何子任务测量**，故不列入主因，仅作接口。
- **但不能单独判为主因**：RPS 循环在 D1 后的 20k/100k 全程存在（池配比曲线本身几乎不非平稳，见 §2.6），无法解释 80k 的单点崩塌幅度。

> **主因判定：未定。** 两条候选各自有 A 级证据、各自不能解释对方的现象；子任务报告之间**未做**交叉裁决实验。

## 五、判别性实验（≤3 条）

> 所有判据均在跑之前写死；所有基线数字均引用现有 run 的实测值（禁手抄，R4）。

### 实验 1：`edw` 后期权重消融（回答「Φ 项每帧密度是否伤害策略」）

- **单变量**：仅 `config.py` 中 economy 预设的 `elixir_diff_late`，由现值 **0.1** 改为 **0.5**（与前期一致）。其余全部不变（`ppo-epochs 4 / minibatch 32 / shuffle / value-norm running / adv-norm scale / anchor-every 2500 / n-eval-games 40 / eval-workers 12 / total-steps 100000`）。
  - ⚠️ 连带常量（须同时声明为已知多源）：`env_wrapper.py:53`、`config.py:52`、`mcts.py:56`、`action_mask.py:120 SPELL_EV_EDW=0.5`（`action_mask.py:118` 注释自称消费者注入但**无注入点**）。本实验**只改奖励侧**，法术闸门保持 0.5 不动——即实验本身就在制造「闸门 vs 奖励」失配，需在预注册中写明这一混淆项。
- **判据（跑前写死）**：
  - 支持「Φ 密度是瓶颈」：分块 worst 中至少 1 块 **≥0.475**（= 现基线第 2 块实测值，`judge_anchor_blocks.py` 复算），或末点锚点与现 0.625 之差 **≥0.11**（= 相邻独立读数差分的 1σ，√2×0.078）。
  - 否证：分块 worst 全部落回 [0.125, 0.250]（= D1 20k 三跑区间），或 41 点均值相对现基线 0.570 的位移 **<0.11**。
- **成本**：训练 100k 步 ≈ 374 局；全点 11 次 ×（4 块×40 局 ≈210s）+ 轻点 41 次 ×（40 局 ≈53s）⇒ 评估墙钟 ≈ 11×210 + 41×53 ≈ **64.8 分钟**；训练按纯训练 26 步/s（`AGENTS.md` §3）≈ **64 分钟**；合计 **≈2.2 小时**（不含重跑轮次）。
- **可能证伪结果**：若 worst/末点**都**显著改善 ⇒ 「奖励塑形密度是约束」成立，M2 侧升级；若**毫无移动** ⇒ 排除奖励塑形路径，M1（critic 塌缩）所有权重上升。

### 实验 2：`_HIST_POOL_MAX` 12→24（回答「池成员换血时间尺度 / 自我对弈扰动是否是约束」）

- **单变量**：`train_solo.py:148 _HIST_POOL_MAX` 由 **12** 改为 **24**（`_collect_hist_ckpts` 的 `np.linspace(0, N−1, budget)` 逻辑不变）。其余全部不变。
- **判据（跑前写死）**：
  - 支持「段内多样性是瓶颈」：分块 worst 中至少 1 块 **≥0.475**，或 41 点均值 **≥0.680**（现基线 0.570 + 0.11）。
  - 否证：**≥50% 的块 worst 落在 [0.125, 0.250]**（现 min 0.237 所属区间），或 41 点均值位移 **<0.11**。
  - 否定诊断（nil 判据）：若 `kind_counts` 终局 hist 占比偏离现基线 **225/374=60.2%** 超过 ±5pp，则本实验无效（池扫描逻辑被间接改动，非单变量）。
- **成本**：训练 100k 步 ≈ 374 局 + 同上评估 ⇒ **≈2.2 小时**；若先用 20k 协议（`--total-steps 20000`）做前置筛查，则 ≈**25 分钟**（20k 协议下评估占 73% 墙钟，`AGENTS.md` §3）。
- **可能证伪结果**：若最差块被推离 [0.125,0.250] ⇒ 对手分布升级为主因候选；若不动 ⇒ 池换血时间尺度不是约束，M1 权重上升。

### 实验 3：塌缩机制确认探针（区分 M1 死 ReLU vs 其他 critic 塌缩机制）

- **单变量**：**不改训练**。仅在现有 ckpt 上注入一段前向探针，对最近若干真实 rollout 帧（**建议 700 帧，与已验证的解剖窗口同口径**）记录：`relu(pol.value_enc_fc(fused))` 的逐帧存活率、`value_head_mlp[0]` 输出 `mlp0_post` 的跨帧 ‖Δ‖、以及 `value` 输出的唯一值个数。对照点用现成 ckpt：10k/20k/25k/30k/100k。
- **判据（跑前写死）**：
  - 确认 M1：100k 处 **MLP0 ReLU 存活率 ≤1% 且 `mlp0_post` 跨帧 ‖Δ‖ 为 0**（现基线：100k 存活 0.000%、‖Δ‖=0.0000、700 帧 1 个唯一值）。
  - 否证 M1：100k 处存活率 **>30%** 而 **value 输出方差仍为 0** ⇒ 死 ReLU 不是塌缩机制，必须找其他路径（例如输出层被吸收 / 输入常数化）。
  - 附判据：`post_ln` 逐维跨帧 std 若 **>0.05**（现基线 0.0022~0.0072）而 EV 仍 ≈0 ⇒ 「LayerNorm 压动态范围」这一层被否证。
- **成本**：**10 行以内代码改动 + 一次前向**（5 个 ckpt × ~700 帧）⇒ **墙钟 <5 分钟**；不占 GPU 训练预算；材料 = 磁盘上已存在的 41 个 `solo_main_<step>.pt` 与 11 个 `replays/league_*.pkl`（后者仅作对照，**不含 0.237 那 40 局**）。
- **可能证伪结果**：见上「否证 M1」分支；若该分支成立，则主因必须改写，且现有 `relu_ln`/`post_ln` 的 A 级证据需重新解释（是否只是相关性）。

## 六、总体评价

1. **证据链最完整的一段：预算基数。** 99,964 帧 → 780 更新 → 12,480 Adam 步 → 99,840 帧入梯度，四处独立对账（日志行数、`ret_scaler.count`、`gs=16` 全量、`grep gs=1` 为 0）互相闭合，A 级。这一段可直接作为后续所有实验的分母。

2. **最有价值的新事实：`value_head_mlp[0]` 的 ReLU 在 100k 时存活率 0.000%、输出方差精确为 0、40k 后权重逐位冻结。** 这把「critic 输出常数」从现象升级为**机制**（吸收态、不可逆），并且顺带否证了「用 `value_head` 范数做诊断」的整条旧诊断路径（该参数在 `value_independent` 通路下不参与前向）。

3. **最薄弱的一环：主因未定，且缺一环。** M1（死 ReLU）与 M2（对手非平稳）各自有 A 级证据，但「critic 塌缩 → advantage 失真 → 80k 掉到 0.237」的传导链**没有一次测量**。6 份报告之间**没有做交叉裁决**——这是本次归并暴露的最大缺口，不是数据不足，而是**设计缺口**。

4. **两处必须改的文档数字（A 级否证）**：
   - `AGENTS.md:148` / `eval_cadence_c` §5 的「每评估点重打同样 40 局 ⇒ 锚点是权重的确定性函数」与 `env_wrapper.py:349-357` + `train_solo.py:1447,1478` 直接冲突；
   - 「相邻 |Δ|≈0.225 ≈3σ」应为 **2.05σ_diff**。

5. **一处必须降级的判决表述**：P1 在恒定 p=0.5 下期望上轻松 PASS（mean(worst)≈0.382 vs 阈值 0.10），其真实判别边界 ≈「真值整段掉到 0.19 以下」。⇒ **C6 可以引用「区间不重叠的对比」，不可引用「P1 PASS 证明没退化」。**

6. **仪器层的硬约束（任何后续实验都必须先接受）**：
   - 唯一能测绝对强度的仪器是固定随机锚点，且它实际是「固定种子的链式洗牌 + 固定未训练权重」，40 个初始手牌每点都换；
   - 3 run/臂下 80% 功效 MDE ≈ **0.354** ⇒ **0.1 级的上限提升在本设计下不可分辨**；
   - 锚点零点 **0.625** 高于现役工作点均值 **0.570**；
   - 0.237 那 40 局**无逐帧回放**（`save_replays=False`，`train_solo.py:1224,1229`），任何要求「看那 40 局发生了什么」的追问在当前工件下**不可答**。

7. **常量多源的失配风险是潜伏的、不是已发生的**：`elixir_diff_weight` 4 处（含 `action_mask.py:120` 无注入点）、`tower_premium_k`/`king_gate` 同文件各 2 处、`draw_penalty` 仅 1 处且 env 侧缺 key 走兜底；`rl/selftest.py` **从不引用** `_DEFAULT_REWARD` ⇒ 改一处 **97 项全绿**。这与 R7 的要求（单常量源 + 对账 selftest）之间的差距是**可复算的缺口**，不是猜测。

8. **本报告未采信 / 明确标注的三类内容**：外部 Atari 数字（未在仓库内证实）、`corr(winrate,mean_reward)`（子任务 D 复算，本报告作者未独立复核）、极值选择偏差百分比（子任务自标为量级示意、min 自身 sd 未精算）。这三类**不得作为判据**，只能作为实验设计的动机。

9. **被截断而未纳入的段**：critic 报告 §5 第 3 假设（optimizer/尺度）、对手漂移报告 §3.3 末尾、奖励报告 §4.1 日志序列、仪器报告 §3.3 末尾。凡涉及这四处的结论在本报告中**留空**，标为「原报告此处截断」，不作补全。
