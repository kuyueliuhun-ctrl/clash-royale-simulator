## §0 判决

| 判据 | 定义（**同一 α** 配对） | 命中 |
|---|---|---|
| **P-PROJ** | 每个 α 上 `EV(z_enc) ≤ 0.5·EV(fused)` | **26/27 个 α 值**（seed 7 **9/9**、seed 11 **9/9**、seed 13 **8/9**，只 α=100 漏） |
| **P-LN** | 每个 α 上 `EV(z_enc) ≥ 0.5·EV(fused)` **且** `EV(enc) ≤ 0.5·EV(z_enc)` | **1/27**（只在 seed 13 的 α=100 出现，而那里 `z_enc` 已经很低） |
| P-VLN（价值支路 LN 是掉点） | `relu_ln ≥ 0.5·pre_ln` 且 `post_ln ≤ 0.5·relu_ln` | 6/27，**全部落在 α ≥ 1e4 的退化段**（那里所有读数都 ≈0） |
| P-RANDOM | `z_enc ≤ 1.5·z_rand` | 18/27（seed 11 **9/9**） |
| P-VLN-NEUTRAL | `post_ln ≥ 0.9·relu_ln` | 12/27（按"每个 α"太严，见 §3） |

> # 结论
> **掉点处是 `enc_fc`（2731→128 的共享线性投影）本身，不是任何一层 LayerNorm。**
>
> 1. **`z_enc`（投影输出）在 26/27 个 α 值上读不到 `fused` 的一半**；在低 α 上甚至是**负的**
>    （seed 7：`fused` +0.043 ~ +0.053，`z_enc` **−0.018 ~ −0.016**）。
> 2. **`enc_ln` 被洗清**：P-LN 只有 **1/27**。而且 LN **常常是帮忙的**——同 α 下 `enc ≥ z_enc`
>    在大量 α 上成立（seed 7 α=1e4：`z_enc` +0.00871 → `enc` +0.01462）。
> 3. **`value_enc_ln` 也被洗清（真·同张量）**：`post_ln / relu_ln` 在数值有意义处 **≥ 0.78**
>    （低 α 上 0.98~1.08）⇒ **复现第二轮"`value_enc_ln` 不是掉点层"，并升级为真同张量 + 整条 α 曲线证据**。
> 4. **附加发现（与 R14 互为独立证据）**：**训练出来的共享投影 ≈ 随机投影**——
>    `z_enc/z_rand` 在多数 α 上是 **0.9~1.0**（seed 7、seed 13），而 **seed 11 上随机投影更好**
>    （α=0.01：`z_enc` +0.0209 vs `z_rand` **+0.0443**）。
>    ⇒ 这条 2731→128 的投影**没有在为"回报可读性"做事**。

## §2 主结论：掉点发生在**降维**这一步

链：`fused(2731) --enc_fc--> z_enc(128) --ReLU--> r_enc --enc_ln--> enc(128)`。

- 三段里唯一"断崖"的是**第一段**：`fused` 的 0.043~0.158 → `z_enc` 的 −0.018~+0.053。
- **ReLU 与 LN 都没有把它再砸下去**：`r_enc` 相对 `z_enc` 有升有降（seed 13 上 ReLU 把 +0.0531 砍到 +0.0091，
  seed 7 上把 −0.0182 抬到 −0.0116），`enc` 相对 `z_enc` 在多数 α 上**更高**。
- ⇒ **2731→128 的线性投影（`enc_fc`）是这条链上唯一的瓶颈。**

**这条结论比 v3 强在哪**：v3 只能说"`fused → enc` 掉了"，无法区分降维与归一化；
本轮用的是**同一个前向里、逐位可验的父子张量**，且重算链经 G-OFFLINE 对账（max|Δ| = **4.2915e-06**）。

## §3 LN 被洗清（两处）

### §3.1 共享支路 `enc_ln`：P-LN **1/27**
若 LN 是掉点，必须在"`z_enc` 还读得出来"的那些 α 上把 `enc` 砸到一半以下。实测几乎从不发生。
反过来，**LN 常常是帮忙的**（同 α）：
seed 7 α=1e4：+0.00871 → **+0.01462**；α=1000：+0.01039 → **+0.01881**；
seed 13 α=10：+0.03913 → +0.00170（这一处是**有害**的）；seed 11 全区略降。
⇒ **无一致方向 ⇒ LN 不是掉点处**（且注意：这与 C1 的历史一致——`enc_ln` 当年是**修复**饱和的手段，不是病因）。

### §3.2 价值支路 `value_enc_ln`：**真·同张量**的 `relu_ln → post_ln`
第二轮的结论用的是同一网格上的两个单点读数；本轮按 R17 用**整条 α 曲线 + 同 α 配对**复核：

| seed | `post_ln / relu_ln`（α 从 1e-2 到 1e6） |
|---|---|
| 7 | −1.77 / −1.80 / −2.12 / +8.50 / **0.80 / 0.78** / 0.92 / 1.07 / 2.28 |
| 11 | **1.08 / 1.08 / 1.08 / 1.08 / 1.30 / 1.64** / −0.65 / −0.04 / 0.41 |
| 13 | **1.07 / 1.06 / 0.98 / 0.91 / 0.98 / 0.78** / 0.08 / −248.8 / 5.71 |

- 比值在**分母有意义**的地方是 **0.78 ~ 1.64**（≥0.78 ⇒ LN 前后差异 ≤22%），低 α 段 **≥0.98**。
- 那些 −1.77 / −248.8 / 8.50 是**两个 ≈0 的数相除**，不是现象（分子分母都在 ±0.01 内）。
⇒ **复现第二轮「`value_enc_ln` 不是掉点层」，证据等级从"两点同网格"升到"整条 α 曲线 + 真·同张量"。**
⇒ 与 v3 的收尾一致：**两处 LayerNorm 都不是病因**；v1/v2 时代对 LN 的怀疑可以彻底关闭。

## §4 附加发现：训练出来的共享投影 **≈ 随机投影**

`z_rand = R·fused`，`R` 为按行归一化的高斯矩阵（主对照种子 **20260914**；另补 2 个描述性种子，**不参与判据**）。

| seed | `z_enc / z_rand`（α = 1e-2 → 1e6） |
|---|---|
| 7 | **+0.97 +1.00 +0.99 +0.94** −0.88 +2.72 +1.22 **+0.93 +0.90** |
| 11 | +0.47 +0.45 +0.30 +0.44 +0.86 +0.87 +0.81 +0.80 +0.97 |
| 13 | **+0.97 +0.91 +0.87 +0.91 +0.93 +0.98** −7.46 +0.71 **+0.97** |

- 在 **seed 7 与 seed 13** 上，训练出来的投影与**随机**投影的读数**几乎一样**（比值 ≈0.9~1.0）；
- 在 **seed 11** 上，**随机投影更好**（α=0.01：+0.0209 vs **+0.0443**；每一个 α 都更好）。
- 三条 seed 里**没有任何一个** α 上 `z_enc` 明显优于随机（唯一 >1.5 的是 seed 7 的 α=1000 = 2.72，
  那里两者都 ≈+0.004~+0.011，量级极小）。

⇒ **这条投影对"局内回报的线性可读性"没有贡献。** 这是**与【红线 R14】完全独立的一条证据**：
R14 从**权重位移**（`‖ΔW‖/‖W‖` 恰为 0）看到价值侧参数冻结；本轮从**可读性**看到
共享编码器的投影并不比随机好。两者合起来说同一件事：**这条通路没有在为价值做事**。

⚠️ **不要过度外推**：`enc_fc` 在**策略目标**下是被训练的（R14 显示策略侧 27/27 窗口在动）。
本条的准确说法是"**它没有被组织成承载价值信息的表示**"，而不是"它是随机权重"。

## §5 ⚠️ 自披露：我的 G-OFFLINE 有一个**退化层不稳定**的子闸（seed 11 因此判 `V4_INVALID`）

预注册的 G-OFFLINE 要求两件事：
1. **张量侧**：`max|enc_off − X_enc| ≤ 1e-4` —— **三条 seed 全部 PASS（4.2915e-06）**；
2. **EV 侧**：`|EV(enc_off) − EV(enc)| ≤ 0.002` —— **seed 11 FAIL（8.739e-03）**。

**根因（已定位，不是数据问题）**：seed 11 的 `enc` 在**每一个 α** 上 val EV 都是负的
（−0.026 ~ −0.036）⇒ `argmax_val` 是**噪声上取最大**。两个逐位只差 4e-06 的张量选了不同的 α：

```
enc      α*=1e-4   test=−0.01244
enc_off  α*=10     test=−0.00370      ← 差 8.7e-03，全部来自 argmax 翻转
```

⇒ 这是**我的闸门设计缺陷**，与【病理 ⑩】"估计器可控范围不足"同族：
**在退化层（val 曲线全负/全平）上，`argmax` 不是稳定量，因此"两层在同一 α* 上的读数之差"不可比。**

**处置（照预注册 §6 的字面读）**：seed 11 记 **`V4_INVALID`**，它的读数**只作为描述性证据**（§4 里已这样标注）。
主结论（§0/§2/§3）在 **seed 7 与 seed 13（两条 G-OFFLINE 全 PASS 的 seed）**上成立，
且 seed 11 的**张量侧**已验证一致 ⇒ 它的曲线可以看趋势、不能单独支撑判决。

**下一轮该怎么改（写进台账，不在本轮改判据）**：退化层改用
**α 曲线整体比较**（逐 α 比，或比曲线差的中位数）而不是比 argmax 读数；
并在报 `EV(A) vs EV(B)` 时**强制标注两端的 α\* 是否相同**。

## §7 下一步（按证据强度排序）

1. **`enc_fc`（2731→128）是唯一被证实的断崖** ⇒ 这是"价值通路为什么学不到"的**最窄入口**。
   下一步该问的不是"改哪个架构"，而是**它测什么**：
   - **(a) 容量**：2731→128 的随机投影本来就保不住 → 那么"加宽/换保留信号的投影"是候选；
   - **(b) 组织**：`enc_fc` 在策略目标下被训练，但它没有理由保住价值信息 ⇒
     候选是**给价值支路独立的宽通径**（已经不是新想法，E′ 做过，见 X3）或**在损失里显式要求保留**；
   - **(c) 数据**：`fused` 里的可读信号（0.043~0.158）本身**在不同 seed 上量级差 3 倍**（seed 7 低、11/13 高）
     ⇒ 先确认"这条通路该读多少"是跨 seed 稳定的（**这条现在还不知道**）。
   **判据设计要点**：单变量、`--fresh`（R6）、预注册、用**同一 α 配对 + 整条 α 曲线**（R17/闸门 12）、
   并用本轮的 `z_rand` 当**上界对照**（"改造后的投影至少要显著优于随机投影"）。
2. **把 v4 的仪器推广成默认**：以后任何"逐层"问题都走
   `--ladder v3`（抓张量）+ `probe_v4_ln_pair.py`（离线重算 + 对账）+ `judge_probe_v4.py`（同 α 归约）。
3. **v3 判读 §3.3 的那条（`pre_ln` 比 `enc` 好 25/27）** 已被本轮取代：真·同张量下
   **两处 LN 都不是问题**；该条只保留"共享那一路更不可读"的弱版本。
