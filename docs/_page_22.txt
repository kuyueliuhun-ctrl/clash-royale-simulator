Cloned troops are fragile, but pack the same punch as the original! Doesn't affect buildings.\u201d</b></i></div>\n<p>The Clone is an <a href=\"/wiki/Category:Epic_Cards\" title=\"Category:Epic Cards\"><span style=\"color: #FF99FF; font-weight: bold;\">Epic</span></a> <a href=\"/wiki/Cards\" title=\"Cards\">card</a> that is unlocked from the <a href=\"/wiki/Arenas\" title=\"Arenas\">Miner's Mine (Arena 15)</a>. It is an air-targeting <a href=\"/wiki/Category:Spell_Cards\" title=\"Category:Spell Cards\">spell</a> with a medium radius that spawns fragile duplicates of all <a href=\"/wiki/Category:Troop_Cards\" title=\"Category:Troop Cards\">troops</a> within its area of effect behind the originals. It is a translucent, teal-colored liquid encased in a small oblong vial, and appears to be duplicating itself. It is also the same as that spawned by the <a href=\"/wiki/Santa_Hog_Rider\" title=\"Santa Hog Rider\">Santa Hog Rider</a>. A Clone card costs 3 <a href=\"/wiki/Elixir\" title=\"Elixir\">Elixir</a> to deploy.\n</p>\n<h2><span class=\"mw-headline\" id=\"Strategy\">Strategy</span><span class=\"mw-editsection\"><span class=\"mw-editsection-bracket\">[</span><a title=\"Sign in to edit\" class=\"mw-editsection-visualeditor\" data-tracking-label=\"log-in-edit-section\" data-action=\"edit-section\" href=\"https://auth.fandom.com/signin?redirect=https%3A%2F%2Fclashroyale.fandom.com%2Fwiki%2FClone%3Fveaction%3Dedit%26section%3D1&amp;uselang=en&amp;metadata=article-registration-edit-article-section\" data-testid=\"log-in-edit-section\" aria-label=\"Sign in to edit\"><svg class=\"wds-icon wds-icon-tiny\" aria-hidden=\"true\" focusable=\"false\"><use xlink:href=\"#wds-icons-pencil-tiny\"></use></svg></a><span class=\"mw-editsection-bracket\">]</span></span></h2>\n<p><i>For <a href=\"/wiki/Battle_Decks\" title=\"Battle Decks\">Battle Decks</a> with this <a href=\"/wiki/Cards\" title=\"Cards\">card</a>, click <a href=\"/wiki/Category:Battle_Decks_using_the_Clone_Card\" title=\"Category:Battle Decks using the Clone Card\">here</a>.</i>\n</p>\n<ul><li>Unlike the <a href=\"/wiki/Mirror\" title=\"Mirror\">Mirror</a>, Clone duplicates every <a href=\"/wiki/Category:Troop_Cards\" title=\"Category:Troop Cards\">troop</a> that enters its area of effect and can potentially cost less, but each cloned unit has just 1 hitpoint, with <a href=\"/wiki/Category:Building_Cards\" title=\"Category:Building Cards\">buildings</a> and existing clones not subject to the effect. Mass unit spawning <a href=\"/wiki/Cards\" title=\"Cards\">cards</a> may spread out of the Clone's relatively small radius, resulting in the card not being fully cloned.</li>\n<li>Since cloned troops have only 1 hitpoint, any source of damage, such as <a href=\"/wiki/Zap\" title=\"Zap\">Zap</a>, <a href=\"/wiki/The_Log\" title=\"The Log\">The Log</a>, <a href=\"/wiki/Arrows\" title=\"Arrows\">Arrows</a>, <a href=\"/wiki/Giant_Snowball\" title=\"Giant Snowball\">Giant Snowball</a>, <a href=\"/wiki/Earthquake\" title=\"Earthquake\">Earthquake</a>, <a href=\"/wiki/Poison\" title=\"Poison\">Poison</a>, or a <a href=\"/wiki/Tornado\" title=\"Tornado\">Tornado</a> can easily deal with them. This can create an <a href=\"/wiki/Elixir\" title=\"Elixir\">Elixir</a> advantage.</li>\n<li>Aside from most stats (which are dependent on Clone's Level) units also retain most unique effects of their originals:\n<ul><li>Shields can be cloned if they are still on the original unit. They will retain one hitpoint, and can still negate excess damage, therefore allowing the clone to survive one hit.</li>\n<li>Any troop that activates a special mode when they reach a certain hitpoint threshold will npt be able to utilize these special modes. As such, it is inadvisable to use Clone on these troops.</li>\n<li>Cloned units that spawn other troops, whether periodically (like the <a href=\"/wiki/Witch\" title=\"Witch\">Witch</a> and <a href=\"/wiki/Night_Witch\" title=\"Night Witch\">Night Witch</a>) or upon death (like the <a href=\"/wiki/Skeleton_Barrel\" title=\"Skeleton Barrel\">Skeleton Barrel</a>, <a href=\"/wiki/Golem\" title=\"Golem\">Golem</a>, <a href=\"/wiki/Elixir_Golem\" title=\"Elixir Golem\">Elixir Golem</a>, <a href=\"/wiki/Goblin_Giant\" title=\"Goblin Giant\">Goblin Giant</a> and <a href=\"/wiki/Lava_Hound\" title=\"Lava Hound\">Lava Hound</a>) will spawn cloned troops.</li>\n<li>Cloned units can still cause various death effects.\n<ul><li>A cloned <a href=\"/wiki/Lumberjack\" title=\"Lumberjack\">Lumberjack</a> drops a cloned <a href=\"/wiki/Rage\" title=\"Rage\">Rage</a>.</li>\n<li>A cloned <a href=\"/wiki/Elixir_Golem\" title=\"Elixir Golem\">Elixir Golem</a> will still provide Elixir when defeated, at all of its forms.</li>\n<li>A <a href=\"/wiki/Mother_Witch\" title=\"Mother Witch\">Mother Witch</a> will spawn cloned Cursed Hogs if she defeats cloned troops and she will spawn non-cloned Cursed Hogs if she defeats non-cloned troops. This happens regardless of whether the Mother Witch is cloned or not. A similar situation applies to <a href=\"/wiki/Goblin_Curse\" title=\"Goblin Curse\">Goblin Curse</a>.</li>\n<li>However, in the case of items dropped by units such as <a href=\"/wiki/Giant_Skeleton\" title=\"Giant Skeleton\">Giant Skeleton</a> or <a href=\"/wiki/Balloon\" title=\"Balloon\">Balloon</a>, the items cannot be cloned, though their clones will still drop a cloned item.</li></ul></li>\n<li>Units with charging/dashing/jumping/grabbing attacks such as <a href=\"/wiki/Dark_Prince\" title=\"Dark Prince\">Dark Prince</a>/<a href=\"/wiki/Prince\" title=\"Prince\">Prince</a>/<a href=\"/wiki/Battle_Ram\" title=\"Battle Ram\">Battle Ram</a>/<a href=\"/wiki/Ram_Rider\" title=\"Ram Rider\">Ram Rider</a>/<a href=\"/wiki/Royal_Recruits/Evolution\" title=\"Royal Recruits/Evolution\">Evolved Royal Recruits</a>/<a href=\"/wiki/Bandit\" title=\"Bandit\">Bandit</a>/<a href=\"/wiki/Boss_Bandit\" title=\"Boss Bandit\">Boss Bandit</a>/<a href=\"/wiki/Mega_Knight\" title=\"Mega Knight\">Mega Knight</a>/<a href=\"/wiki/Fisherman\" title=\"Fisherman\">Fisherman</a> retain their respective abilities, and cloning them will not interrupt the original troop's actions. However, the cloned unit will not inherit the current status of the troop. The same can be somewhat applied to <a href=\"/wiki/Sparky\" title=\"Sparky\">Sparky</a>.</li>\n<li>A Sparky will be immune to stun effects while on the process of cloning. This can surprise an opponent who tries to stun her with an <a href=\"/wiki/Electro_Wizard\" title=\"Electro Wizard\">Electro Wizard</a> or <a href=\"/wiki/Zap\" title=\"Zap\">Zap</a>. If you notice that the opponent uses both Sparky and Clone in their deck, wait for them to use the Clone on the Sparky before placing the Electro Wizard on top of her.</li>\n<li>Cloning a <a href=\"/wiki/Golem\" title=\"Golem\">Golem</a> during his long deploy process of 3 seconds will produce a cloned Golem that begins moving immediately.</li>\n<li>Cloning a <a href=\"/wiki/Spirit_Empress\" title=\"Spirit Empress\">Spirit Empress</a> will spawn a clone of the form that matches her original form, regardless on how much Elixir the player has.</li>\n<li>Since the troop cloned will have already spawned, cloned <a href=\"/wiki/Ice_Wizard\" title=\"Ice Wizard\">Ice Wizards</a>, Electro Wizards, and Mega Knights do not inflict spawn damage, and a cloned <a href=\"/wiki/Battle_Healer\" title=\"Battle Healer\">Battle Healer</a> will not deal spawn healing.</li></ul></li>\n<li>The Clone works well with the Witch and Night Witch, as it can gradually overwhelm the opponent with another set of spawned <a href=\"/wiki/Skeletons\" title=\"Skeletons\">Skeletons</a> or <a href=\"/wiki/Bats\" title=\"Bats\">Bats</a> if they do not counter it quickly.</li>\n<li>It is beneficial to Clone low-hitpoint units since the drawback of the Clones only having a single hitpoint is usually negligible (e.g., a cloned <a href=\"/wiki/Skeleton_Army\" title=\"Skeleton Army\">Skeleton Army</a> will still be OHKOed by a Zap). Additionally, many low hitpoint units come in larger numbers, exponentially increasing the value of the spell's effect. As such, the Skeleton Army is quite effective to Clone to potentially deal heavy damage. This should be done if counters to those cards are not in rotation.</li>\n<li><a href=\"/wiki/Wall_Breakers\" title=\"Wall Breakers\">Wall Breakers</a> can be cloned for a devastating effect if they are close enough to the <a href=\"/wiki/Category:Tower_Troop_Cards\" title=\"Category:Tower Troop Cards\">Crown Tower</a>. Since the clones are spawned close to it, the Tower would be unlikely to react in time and take massive damage as a result.</li>\n<li>Clone pairs well with the <a href=\"/wiki/Mirror\" title=\"Mirror\">Mirror</a>, as the Mirror duplicates troops and the Clone then clones them, multiplying their numbers exponentially. However, this is a fairly costly and therefore risky move as cloning and mirroring most singular units will not substantially mitigate their weaknesses (i.e., the combined units wouldn't be able to break through most things they couldn't break through before). Keep in mind that mirroring first and then cloning is usually more expensive, though 1/2 of them will have the full hitpoints, while cloning then mirroring is often cheaper, but spawns less units, and only 1/3 of them will have full hitpoints. When using Clone and Mirror, it would be best to mirror a card that costs only 3 Elixir and then clone it. This will now leave you with 4 of the selected troop for 10 Elixir. As stated above, it is best to use this technique with low-hitpoint troops.</li>\n<li>It is a good idea to clone troops attacking the enemy Crown Towers if the Crown Tower has locked onto a high hitpoint unit or a tank.</li>\n<li>The Clone <a href=\"/wiki/Category:Spell_Cards\" title=\"Category:Spell Cards\">spell</a> can create devastating split pushes by cloning a set of <a href=\"/wiki/Three_Musketeers\" title=\"Three Musketeers\">Three Musketeers</a> so that 2 are on 1 side and 4 are on the other.</li>\n<li>It is not recommended to clone a melee troop to fight against a ranged troop if the main troop is about to be defeated. However, a ranged troop can be cloned with less risk against a melee troop because it can offer damage to the enemy before being defeated.</li>\n<li>Cloning the <a href=\"/wiki/Lava_Hound\" title=\"Lava Hound\">Lava Hound</a> is a very effective strategy. If the cloned copy is defeated, the Lava Pups will spring out and whether the Crown Tower was originally targeting the real copy or not, the Crown Tower will instantly transfer its target to the real copy (assuming it was still alive) and the Lava Pups will do heavy damage to the Crown Tower. However, this can be easily countered with <a href=\"/wiki/Zap\" title=\"Zap\">Zap</a>, <a href=\"/wiki/Arrows\" title=\"Arrows\">Arrows</a>, <a href=\"/wiki/Poison\" title=\"Poison\">Poison</a>, and <a href=\"/wiki/Royal_Delivery\" title=\"Royal Delivery\">Royal Delivery</a>.</li>\n<li>In certain situations, cloning a troop with death damage can allow the original troop to break through defending troops easier. For example, a cloned Giant Skeleton could activate his bomb, allowing the original Giant Skeleton to defeat defending troops with much more ease. The defender should make sure that their defending troop can avoid the death damage.</li>\n<li>It is advisable not to clone the Elixir Golem. It can give the opponent a total of 8 extra Elixir. It is also advisable not to clone the <a href=\"/wiki/Electro_Giant\" title=\"Electro Giant\">Electro Giant</a>, because he only counterattacks when he is attacked, which would only happen once due to his 1 hitpoint.</li>\n<li><a href=\"/wiki/Poison\" title=\"Poison\">Poison</a>, Arrows, Vines, and Goblin Curse are extremely effective counters to any clone, as they hit multiple times in their respective areas of effect, effectively eliminating the threat caused by clones of Lava Hounds or shielded troops such as <a href=\"/wiki/Guards\" title=\"Guards\">Guards</a>. <a href=\"/wiki/Earthquake\" title=\"Earthquake\">Earthquake</a> can also be used to a limited extent, though beware that it can't hit air troops.\n<ul><li>However, a Skeleton Barrel has a 0.5 second delay between the Skeletons spawning and the Skeleton Barrel itself being defeated. As such, Arrows is not recommended to be used against a cloned Skeleton Barrel. Poison and Goblin Curse still works however, due to their longer duration.</li></ul></li>\n<li>When a troop is cloned, the original troop will be displaced forward slightly. Cloning a troop in anticipation of a spell can allow the original to be unharmed if the spell's accuracy is somewhat off. This displacement can allow Clone to be used with building-targeting troops to bypass certain defensive building placements, by shoving the original troop so that it is closer to a Crown Tower. This can be devastating with certain troops like a Balloon or Battle Ram. However, this tactic is less reliable when used on ground troops like <a href=\"/wiki/Giant\" title=\"Giant\">Giants</a> or <a href=\"/wiki/Golem\" title=\"Golem\">Golems</a>.</li>\n<li>The <a href=\"/wiki/Ice_Golem\" title=\"Ice Golem\">Ice Golem</a> is a reliable way to defeat cloned troops. Simply sacrificing the Ice Golem to the cloned troops will trigger his death damage, wiping all the clones out.</li>\n<li>When using Clone in a <a href=\"/wiki/Battle_Decks\" title=\"Battle Decks\">deck</a>, the player should be careful. Because the Clone can appear in the starting hand, it may result in taking a card slot, only allowing the opponent to choose to start between 3 functioning cards, which may be better to be saved for a response to the opponent. However, this is less risky in the <a href=\"/wiki/2v2\" title=\"2v2\">2v2</a> and <a href=\"/wiki/Troop_Rush\" title=\"Troop Rush\">Troop Rush</a> <a href=\"/wiki/Category:Modes\" title=\"Category:Modes\">modes</a>, as the Clone can be casted on the allies troops and on the troops generated by the <a href=\"/wiki/Arenas\" title=\"Arenas\">Arena</a> respectively.</li>\n<li><a href=\"/wiki/Category:Champion_Cards\" title=\"Category:Champion Cards\"><span class=\"text-champion\" style=\"font-weight: bold;\">Champion</span></a> cards can be cloned, but when you use its ability, only the non-cloned one will activate its ability.\n<ul><li>The <a href=\"/wiki/Skeleton_King\" title=\"Skeleton King\">Skeleton King</a>'s Skeletons spawned by his Soul Summoning ability cannot be cloned as they are considered cloned troops themselves.</li>\n<li>If <a href=\"/wiki/Goblinstein\" title=\"Goblinstein\">Goblinstein</a> is cloned, Lightning Link will always target the non-cloned Monster, and if destroyed, it will not retarget to the cloned Monster.</li></ul></li>\n<li>Similarly, any heroic troop can be cloned, but only the non-cloned one will activate its ability.</li>\n<li>Evolved troops can be cloned but most of the time will produce their unevolved counterparts. For example, using Clone on the <a href=\"/wiki/Archers/Evolution\" title=\"Archers/Evolution\">Evolved Archers</a> will produce cloned versions of regular <a href=\"/wiki/Archers\" title=\"Archers\">Archers</a>. Regular troops spawned by evolved ones, such as the <a href=\"/wiki/Mortar/Evolution\" title=\"Mortar/Evolution\">Evolved Mortar</a>'s <a href=\"/wiki/Goblins\" title=\"Goblins\">Goblins</a> can still be cloned.\n<ul><li>One of the only exceptions to this \"cloned evolution = regular troop\" rule is General Gerry from the <a href=\"/wiki/Skeleton_Army/Evolution\" title=\"Skeleton Army/Evolution\">Evolved Skeleton Army</a>. While the cloned skeletons will not have the special effect of not being able to die until General Gerry is defeated, he will still remain cloned.</li>\n<li>Another exception to this rule is the Decoy Goblins from the <a href=\"/wiki/Goblin_Barrel/Evolution\" title=\"Goblin Barrel/Evolution\">Evolved Goblin Barrel</a>. They will look identical to the Decoy Goblins but will practically function the same as they both have low health.</li>\n<li>If the first barrel of the <a href=\"/wiki/Skeleton_Barrel/Evolution\" title=\"Skeleton Barrel/Evolution\">Evolved Skeleton Barrel</a> has been dropped, cloning the second barrel will create a normal Skeleton Barrel, affectively creating 3 Skeleton Barrels for the cost of one.</li>\n<li>If the <a href=\"/wiki/Royal_Ghost/Evolution\" title=\"Royal Ghost/Evolution\">Evolved Royal Ghost</a> and its Souldiers are cloned, it will produce a regular <a href=\"/wiki/Royal_Ghost\" title=\"Royal Ghost\">Royal Ghost</a> but clone the Souldiers like normal.</li>\n<li><a href=\"/wiki/Wall_Breakers/Evolution\" title=\"Wall Breakers/Evolution\">Evolved Wall Breakers</a> cannot be cloned, but the Runners can be cloned. However, it is more advisable to clone the Evolved Wall Breakers instead of the Runners, as the resulted cloned Wall Breakers deal more damage than Runners.</li></ul></li></ul>\n<center>\n<div branch.</li>\n<li>The Clone is 1 of 7 <a href=\"/wiki/Category:Spell_Cards\" title=\"Category:Spell Cards\">spells</a> which first existed in Clash of Clans, the others being <a href=\"/wiki/Earthquake\" title=\"Earthquake\">Earthquake</a>, <a href=\"/wiki/Heal\" title=\"Heal\">Heal</a>, <a href=\"/wiki/Lightning\" title=\"Lightning\">Lightning</a>, <a href=\"/wiki/Freeze\" title=\"Freeze\">Freeze</a>, <a href=\"/wiki/Poison\" title=\"Poison\">Poison</a>, and <a href=\"/wiki/Rage\" title=\"Rage\">Rage</a>.\n<ul><li>In Clash of Clans, the container for Clone resemble spells that take up 2 housing space (although the Clone takes up 3 housing space), whereas in Clash Royale, the container for the Clone resemble spells that take up only 1 housing space.</li>\n<li>Unlike its <a target=\"_blank\" rel=\"noreferrer noopener\" class=\"text\" href=\"https://clashofclans.fandom.com/wiki/Clone_Spell\">Clash of Clans counterpart</a>, the Clone only produces one clone of a <a href=\"/wiki/Category:Troop_Cards\" title=\"Category:Troop Cards\">troop</a> regardless of its size with an indefinite lifespan while in Clash of Clans, a single troop may produce multiple clones that are just as strong as the original, but is limited by a certain amount of housing space and they despawn after some time.</li></ul></li>\n<li>In the French, Italian, and Arabic language settings of the game, the Clone's name translates to \"Cloning\". In the German and Chinese language settings of the game, the Clone's name translates to \"Clone Spell\". In the Korean, Persian, and Vietnamese language settings of the game, the Clone's name translates to \"Cloning Magic\", \"Simulation\", and \"Replication\" respectively.</li>\n<li>The Clone is 1 of 7 spells which have team-colored rings on their radius, the others are Earthquake, Freeze, Poison, Rage, <a href=\"/wiki/Tornado\" title=\"Tornado\">Tornado</a>, and <a href=\"/wiki/Graveyard\" title=\"Graveyard\">Graveyard</a>.</li>\n<li>A <a href=\"/wiki/Barbarians\" title=\"Barbarians\">Barbarian</a> is featured on the Clone's card render.</li>\n<li>The upgrades work like that of a <a href=\"/wiki/Mirror\" title=\"Mirror\">Mirror</a>. When leveling up the Clone, the cloned cards' Level will be increased. Along with the Mirror, Clone is the only card, which has a stat that does not increase at all levels. In its case, it is the Cloned <a href=\"/wiki/Category:Legendary_Cards\" title=\"Category:Legendary Cards\"><span class=\"text-legendary\" style=\"font-weight: bold;\">Legendary</span></a> Level and Cloned <a href=\"/wiki/Category:Champion_Cards\" title=\"Category:Champion Cards\"><span class=\"text-champion\" style=\"font-weight: bold;\">Champion</span></a> Level stats.</li>\n<li>The Clone has been featured in multiple <a href=\"/wiki/Tournament/Special_Event_Challenges\" title=\"Tournament/Special Event Challenges\">special game modes</a> outside of the card. More specifically:\n<ul><li>The Clone is 1 of 3 spells that has been featured in the <a href=\"/wiki/Troop_Rush\" title=\"Troop Rush\">Troop Rush</a> game <a href=\"/wiki/Category:Modes\" title=\"Category:Modes\">mode</a>, the others being <a href=\"/wiki/Giant_Snowball\" title=\"Giant Snowball\">Giant Snowball</a> and <a href=\"/wiki/Royal_Delivery\" title=\"Royal Delivery\">Royal Delivery</a>.</li>\n<li>The Clone is 1 of 3 spells that has been featured in the Boost Fields game <a href=\"/wiki/Category:Modes\" title=\"Category:Modes\">mode</a>, the others being Heal and Rage.</li>\n<li>The Clone is 1 of 5 spells that have been featured in the <a href=\"/wiki/Treasure_Hunt#Spell_Cauldron\" title=\"Treasure Hunt\">Spell Cauldron</a> sub-mode of the <a href=\"/wiki/Treasure_Hunt\" title=\"Treasure Hunt\">Treasure Hunt</a> game <a href=\"/wiki/Category:Modes\" title=\"Category:Modes\">mode</a>, the others being Heal, Lightning, Freeze, and Rage.</li></ul></li>\n<li>The Clone is unavailable in multiple special game modes. More specifically:\n<ul><li>It is 1 of 2 cards that is unavailable in Draft, the other being Mirror.</li>\n<li>It is 1 of 20 cards that is unavailable in Mirror <a href=\"/wiki/Tournament/Special_Event_Challenges\" title=\"Tournament/Special Event Challenges\">mode</a>, the others being <a href=\"/wiki/Minions\" title=\"Minions\">Minions</a>, <a href=\"/wiki/Cannon\" title=\"Cannon\">Cannon</a>, <a href=\"/wiki/Mortar\" title=\"Mortar\">Mortar</a>, <a href=\"/wiki/Tesla\" title=\"Tesla\">Tesla</a>, <a href=\"/wiki/Goblin_Hut\" title=\"Goblin Hut\">Goblin Hut</a>, <a href=\"/wiki/Tombstone\" title=\"Tombstone\">Tombstone</a>, <a href=\"/wiki/Bomb_Tower\" title=\"Bomb Tower\">Bomb Tower</a>, <a href=\"/wiki/Inferno_Tower\" title=\"Inferno Tower\">Inferno Tower</a>, <a href=\"/wiki/Barbarian_Hut\" title=\"Barbarian Hut\">Barbarian Hut</a>, <a href=\"/wiki/Furnace\" title=\"Furnace\">Furnace</a>, <a href=\"/wiki/Elixir_Collector\" title=\"Elixir Collector\">Elixir Collector</a>, Freeze, <a href=\"/wiki/X-Bow\" title=\"X-Bow\">X-Bow</a>, <a href=\"/wiki/Golden_Knight\" title=\"Golden Knight\">Golden Knight</a>, <a href=\"/wiki/Skeleton_King\" title=\"Skeleton King\">Skeleton King</a>, <a href=\"/wiki/Archer_Queen\" title=\"Archer Queen\">Archer Queen</a>, <a href=\"/wiki/Mighty_Miner\" title=\"Mighty Miner\">Mighty Miner</a>, <a href=\"/wiki/Little_Prince\" title=\"Little Prince\">Little Prince</a>, and the <a href=\"/wiki/Monk\" title=\"Monk\">Monk</a>.</li>\n<li>It is 1 of 4 cards that is unavailable in Triple Draft, the others being <a href=\"/wiki/Three_Musketeers\" title=\"Three Musketeers\">Three Musketeers</a>, Giant Skeleton, and Mirror.</li>\n<li>It is 1 of 2 cards that is unavailable in Mega Draft, the other being Mirror.</li>\n<li>It is 1 of 3 cards that cannot be set on Defense Towers in <a href=\"/wiki/Clan_Wars\" title=\"Clan Wars\">Clan Wars</a>, the others being Elixir Collector and Mirror.</li></ul></li>\n<li>The Clone creates a \"popping\" sound when casted. However, due to a glitch, if an opposing Clone is placed, no sound is played.</li>\n<li>Clone is the only spell that cannot affect <a href=\"/wiki/Category:Building_Cards\" title=\"Category:Building Cards\">buildings</a>. However, you can have a cloned building via a <a href=\"/wiki/Cannon_Cart\" title=\"Cannon Cart\">Cannon Cart</a>.</li>\n<li>Troops that fall from the sky when spawning do not fall from the sky when
