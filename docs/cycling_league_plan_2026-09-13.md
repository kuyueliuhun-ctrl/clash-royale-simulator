## 0. 为什么要打 cycling（证据链，全部已有实测）

1. **A′ 取证（`scripts/_forensics_cycling.py`，v3 §3.8.4）**：自对弈出现确凿的 RPS 三角——
   `main 打冻结副本 0.85` / `打训练起点 0.13` / `打全新随机 0.505`，即"只赢近亲、
   输给外部基准"。
2. **E2（v3 §3.9.3）**：把固定随机锚点放进训练分布（`rand_anchor=0.1`）**无效**——
   末点 `vs baseline_rand=0.050`、`vs baseline0=0.075`，绝对强度照样崩。
   ⇒ **10% 剂量压不住锁步**。
3. **本轮 F′ 复跑（`docs/fprime_rerun_20k_verdict_2026-09-13.md` §7）**：锚点曲线
   F′ 复跑 @12500-17500 = 0.000/0.000/0.000、G'-fix 崩在 @20000、F′ 首跑崩在 5000-10000
   ⇒ **"崩塌"是 cycling 相位，不是某个架构改动的锅**。
4. **结构缺陷（本轮代码侦察发现）**：`_OpponentPool.hist_paths` 只在 `__init__` 扫一次；
   `--fresh` 启动时本 run 目录为空 ⇒ 整个 20k run 里 `hist` 槽 = **12 个外部旧架构 ckpt
   （economy_9k_ft / economy_9j，pre-v3，缺 `enc_ln`/`grid_ln`，以默认 LN 出场）**，
   **本 run 自己的历史快照从未进池**。也就是说当前所谓"历史联赛"并没有包含
   "历史自身"，而 `frozen`（每 2000 步与 main 同步）是唯一与当前策略锁步的对手。
5. **PFSP 在当前规模下几乎是均匀采样**：`alpha=0.05`、20k run ≈ 64 局、hist 占 0.3
   ⇒ 每 ckpt 约 1.5 局；EMA 基本没动 ⇒ "难样本优先"名义存在、实际未生效。
6. **§8 的可复现性发现**：同 seed 同代码的两次 run 从第一个评估点就分叉，锚点滚动均值
   在两次同配置重复间差 **0.21** ⇒ **单跑 A/B 只能判"相位级"的大效应**，
   判据必须选对相位鲁棒的量（见 §2）。

## 1. 干预 D1（一个机制：**对手分布**）

三处**耦合改动**，同属"训练时打谁"这一个机制（因此算一次干预；单变量纪律在本项目
的可复现性现实下让位于"相位级判据 + 明确不判项"）：

| # | 改动 | 现状 | D1 | 理由 |
|---|---|---|---|---|
| i | `opp_mix` | frozen 0.4 / hist 0.3 / defend 0.2 / rand_anchor 0.1 | **frozen 0.1 / hist 0.6** / defend 0.2 / rand_anchor 0.1 | `frozen` 是唯一与当前策略同步演化的对手 = RPS 锁步载体；把质量让给慢变的历史分布 |
| ii | hist 池 | 只在 `__init__` 扫一次（`--fresh` ⇒ 全是外部旧 ckpt） | **每 `solo_copy_every` 步重扫本 run 目录**（cron 同冻结副本同步），PFSP 统计按**稳定 id**（文件名）保留 | 让"历史自身"真正进池；这是"历史自身联赛"的字面要求 |
| iii | PFSP 门禁 | `alpha=0.05`（几乎不动）、无门禁 | `alpha=0.20` + **易胜对手降权**（EMA 胜率 > 0.85 的 ckpt 权重 ×0.2） | 保证梯度来自有信息量的对手，不被"能碾压的旧自己"占据 |

- `rand_anchor` **剂量刻意保持 0.1 不变**：E2 已经测过这个剂量（无效），
  若 D1 失败，D2 的预注册下一步就是把它加到 0.3（剂量-反应），不混在一起。
- `defend` 保持 0.2。
- 兼容红线：`rl/pfsp.py` 的**默认参数保持旧行为**（`alpha=0.05`、`gate_hi=1.0`、
  `gate_penalty=1.0`），新参数只由 `train_solo` 显式传入；`opp_mix` 缺 `rand_anchor`
  键的旧式三槽 dict 仍然合法。

**为什么打包而不是逐个单变量**：§8 证明单跑 A/B 的分辨率 ≈0.2（同配置重复），
逐个单变量各跑一次只会得到三个"判不了"。这里用一个**相位级判据**换一次可判读的结论；
每个子改动都会在判读里单独报告其可观测指纹（对手分布直方图、hist ckpt 组成、PFSP 权重）。

## 2. 预注册判据（跑之前钉死）

**主判据 P1（绝对强度）**：`vs baseline_rand`（固定随机锚点，40 局/点）**末 4 个评估点的
滚动均值 ≥ 0.35**（E1 门槛线）。
历史基线（同协议同 8 点网格，末 4 点 = 12500/15000/17500/20000）：
F′ 复跑 **0.019**、G'-fix **0.356**、F′ 首跑 **0.400**。

**主判据 P2（相位，真正能区分的那条）**：**末 4 个评估点中不存在 ≤0.10 的锚点胜率**。
历史基线：三次 run 的最后 4 点里**都至少有一个 ≤0.075**（F′ 复跑三个 0.000；
G'-fix 一个 0.025；F′ 首跑一个 0.000）⇒ 这条能区分"真的摆脱了可被随机策略利用的相位"，
而不是靠相位运气。

**次判据（旁证，不作结论）**：
- 末 4 点镜像胜率不出现整段 ≥0.85（另一面的锁步指纹）；
- `elixir_avg` 末点 ≥ 1.2（换对手不得导致摆烂）；
- `ghost_rate` 不超起点 2 倍（沿用 gates.json 相对门禁）。

**明确不判**：
- **不判 EV / critic**（critic 侧已证据闭合：`docs/fprime_rerun_20k_verdict_2026-09-13.md`）；
- **不判单点胜率**（40 局 1σ≈0.078，且 cycling 相位主导）；
- **不判 P1 的边缘差值**（§8：同配置重复就差 0.21）；P1 只在"≥0.35 vs <0.35"上读。

**判定分支（先写死）**：

| P2 | P1 | 判定 | 下一步 |
|---|---|---|---|
| 过（无 ≤0.10 点） | ≥0.35 | **保留**：对手分布改造有效，D1 进主线，继续加长跑量 | 100k 长跑验证 |
| 过 | <0.35 | **部分有效**：相位被打破但绝对强度仍不足 ⇒ 保留 D1，D2 = `rand_anchor` 0.1→0.3（剂量-反应） |
| 不过 | 任意 | **无效**：对手分布不是 cycling 的主因 ⇒ 回滚 D1 的 mix（保留代码开关），转奖励侧（组波/凹形定价）或动作侧 |

## 3. 运行协议（与全部 20k 基线逐字一致，唯一变量 = D1）

```bash
python rl/run_league.py --mode solo --config economy --config-name d1_league_20k --fresh \
  --total-steps 20000 --steps-per-eval 2500 --n-eval-games 40 --eval-workers 12 --device cuda \
  --value-norm running --adv-norm scale --diagnose-every 10 \
  --hist-seed-dir runs/economy_9k_ft --hist-seed-dir runs/economy_9j \
  --ppo-epochs 4 --ppo-minibatch 32 --ppo-shuffle
```

日志 `docs/train_d1_league_20k.log`，产物 `src/clasher_new/runs/d1_league_20k/`。
预期墙钟 ≈45 min（F′ 复跑 2499.8s + eval@0 225s）。
`eval@0` 三对照必须与历史逐位相同（0.600/0.463/0.400/0.625）——这是协议对齐的证据。

**可观测指纹（判读时必须报）**：
- 启动日志的 `opp_mix` + PFSP 参数；
- `hist ckpts=` 数量随时间变化（刷新生效 ⇒ 本 run 快照逐渐进池）；
- 每局对手类型直方图（从 replay meta 或 pool 计数统计）。
