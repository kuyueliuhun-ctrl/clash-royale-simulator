## 一、问题陈述

**「在 `d1_long_100k` 上，100,000 步训练（= 99,964 决策帧 / 374 局 / 780 次 PPO 更新 / 12,480 次 Adam 更新）足以让 main 在固定随机锚点上**每一阶段**胜率 ≥ 0.5，即稳定不输给该锚点」为假。**

可否证形式：只要出现「5 个区块 worst 全部 ≥ 0.5」，或「脚本复算证明 20k→100k 的最差锚点统计量被推出 20k 组区间 [0.125, 0.250]」，本命题即被否证。

## 三、因果链

### 3.1 主因：**未定**（两条互斥候选并存，现有取证不能定向裁决）

**M1 —— 价值通路结构性强直（死 ReLU 吸收态）**

- 证据（全 A）：逐层跨帧变化链 `fused` 20~41 → `pre_ln` 6.5~20.7 → `relu_ln`（85~95% 维度恒零）→ `post_ln` **0.11~0.25** → `mlp0_post` **0→0.043→0**；MLP0 ReLU 存活率 100k = **0.000%**；输出方差精确 0（700 帧仅 1 个唯一 value）；40k 后 `value_head_mlp[0].weight/.bias` 与 `[2].weight` 逐位冻结，仅 `[2].bias` 在动。出处：`follower.py:303-314`；子任务 B §3 逐层测量。
- 时序闭合：塌缩与 `vstd/rstd` 30k 后 ≈ 0.001 同期（`docs/d1_long_100k_verdict_2026-09-13.md` §4）。
- **不能单独判主因的理由**：它说明「critic 为什么输出常数」，不说明「策略为什么在 80k 掉到 0.237」——缺「塌缩 → advantage 失真 → 退化」的直接证据（传导链**没有一次测量**）。

**M2 —— 对手分布非平稳（hist 池 = 全历史均匀骨架 + 自对弈 cycling）**

- 证据：hist 池成员平均年龄 ≈ t/2（100k 时 ≈ 50,000 帧，`train_solo.py:187-221`）；50% 池换血仅 2500 帧；RPS 三角确凿（`docs/rl_training_fix_plan_v3.md:364-369,376-377`）；对照曲线相邻摆幅 0.538（`docs/diag_d1_long_100k.md:26-38`）。
- 与 M1 的接口：`R = adv + values`（`ppo.py:188`）**自引用**（critic 报告 §4 表格明列 `values` 是 R 的原料且漂移）——A 级结构事实，但**定量传导未测**。
- **不能单独判主因的理由**：RPS 循环在池配比几乎不非平稳（§2.6）的背景下，无法解释 80k 单点崩塌幅度。

> **判定：未定。** 两条各有 A 级证据、各自不能解释对方现象；6 份报告之间**未做**交叉裁决实验。

- 甲（任务表述 / 文档惯性）：锚点是「mask 随机策略」，对应 `ScriptedPolicy(mode="heuristic")`（`opponents.py:76-122`，`play()` 从掩码随机取样）。
- 乙（仪器报告 / 行为病理报告）：**不是**脚本随机，而是未训练 `FollowerPolicy`（权重 seed `RAND_ANCHOR_SEED=99999`、`deterministic=True` 走 argmax、STOP logit 初始偏置 −1.0）。出处：`train_solo.py:67,80-107`、`train_follower.py:60-98`、`follower.py:156,253-255,458-461,476-479`。
- **事实在乙一侧（A 级）。** 后果：「锚点强度」是**一次任意随机权重抽签**；`v3` §3.8.5 亦承认「胜率高度依赖抽到哪个随机权重」。结论措辞应改为「不输给该固定抽签的未训练策略」。

**分歧 2：锚点是否「每次重打同样 40 局」。**
- 甲：`AGENTS.md:148` + `docs/eval_cadence_c_2026-09-13.md` §5 —— 「每评估点重打同样 40 局 ⇒ 锚点是权重的确定性函数」。
- 乙（仪器报告，A 级反证）：种子固定（90000，全仓仅 `train_solo.py:68/1345/1413` 三处），**对局不固定**——`reset` 洗牌输入 = 上一次洗牌结果（`env_wrapper.py:349-357`：`:351-352` shuffle `list(self.deck0)`/`list(self.deck1)`，`:356-357` 原地覆盖），训练 reset 不带 seed（`train_solo.py:1447,1478`）；仓库自证注释 `selftest.py:2635`「eval 会原地 shuffle deck 并覆盖 env.deck1，串行在前会污染并行快照」。
- **文档同时使用两个互斥前提**：若 40 局真冻结，固定权重下读数应逐位相同（SE = 0），「1σ = 0.078」即无意义；反之若刺激每点重抽，0.078 才是合理噪声地板。
- 连带纠正：「相邻 \|Δ\| ≈ 0.225 ≈ 3σ」应改为 **2.05σ_diff**（相邻点是两个独立读数，差分 SE = √2 × 0.078 = 0.110）。
- **结论方向（C7 谷底 1 点宽）不受伤，但「3σ」这个数必须改。**

**分歧 3：「预算够不够」三层判决并存（不合拢）。**
- L1（预算报告 §5 第 1 层 / verdict §0/§1）：**够** —— 本 run min(worst) = 0.237 vs 无干预组区间 [0.000, 0.025]，**区间不重叠**（Welch t ≈ 4.9）。
- L2（预算报告 §5 第 2 层 / 本报告命题）：**不够** —— 5 块中 4 块 worst < 0.5，最低 0.237（= 3.37σ）。
- L3（仪器报告 §0/§3.3）：**不可判 / 弱证据** —— 3.37σ 是「换一批种子会怎么动」的假想抽样误差；0.237 过半是极值伪影；3 run/臂 MDE ≈ 0.354。
- **不合拢的理由**：L1 与 L2 是**不同判据**（存在性「脱离归零相位」vs 每阶段「≥0.5」），两者都成立；L3 只削「0.1 级差异」的分辨力，**不推翻 L2**（0.237 vs 0.5 的落差远超 MDE）。

**分歧 4：P1 判据的区分力 vs C6 判决。**

## 五、判别性实验

### 实验 1：`edw` 后期权重消融（问「Φ 每帧密度是否伤害策略」）

- **单变量**：`config.py` economy 预设 `elixir_diff_late`：**0.1 → 0.5**（与前期一致）；其余全部不变（`ppo-epochs 4 / ppo-minibatch 32 / ppo-shuffle / value-norm running / adv-norm scale / anchor-every 2500 / n-eval-games 40 / eval-workers 12 / total-steps 100000`）。
- **已知多源声明**：`env_wrapper.py:53`、`config.py:52`、`mcts.py:56`、`action_mask.py:120 SPELL_EV_EDW = 0.5`（无注入点）。本实验**只改奖励侧**，闸门保持 0.5 ⇒ **实验本身制造「闸门 vs 奖励」失配**，须写进预注册作为混淆项。
- **判据（跑前写死）**：支持「Φ 是瓶颈」= 分块 worst 至少 1 块 **≥ 0.475**（现基线第 2 块实测值，`judge_anchor_blocks.py` 复算），或末点锚点与现 0.625 之差 **≥ 0.11**（= √2 × 0.078，相邻独立读数差分 1σ）；否证 = 分块 worst 全部落回 **[0.125, 0.250]**，或 41 点均值相对 0.570 位移 **< 0.11**。
- **成本**：训练 100k ≈ 374 局（按 26 步/s ≈ 64 min）+ 评估（全点 11 × ≈ 210 s + 轻点 41 × ≈ 53 s ≈ 64.8 min）⇒ **≈ 2.2 h**（不含重跑轮次）。
- **可能证伪结果**：worst / 末点都改善 ⇒ M2（对手分布）升级为主因候选；**毫无移动** ⇒ 排除奖励塑形路径，M1（死 ReLU）权重上升。

### 实验 2：`_HIST_POOL_MAX` 12 → 24（问「池换血时间尺度 / 自对弈扰动是否约束」）

- **单变量**：`train_solo.py:148 _HIST_POOL_MAX` **12 → 24**；`_collect_hist_ckpts` 的 linspace 逻辑不变；其余全部不变。
- **判据（跑前写死）**：支持 = 分块 worst 至少 1 块 **≥ 0.475**，或 41 点均值 **≥ 0.680**（0.570 + 0.11）；否证 = **≥ 50% 的块 worst 落在 [0.125, 0.250]**，或 41 点均值位移 **< 0.11**；nil 判据 = 终局 hist 占比偏离 **225/374 = 60.2%** 超 **±5pp** 则本实验无效（非单变量）。
- **成本**：100k ≈ 374 局 + 同评估 ⇒ **≈ 2.2 h**；前置筛查用 20k 协议（评估占 73% 墙钟）⇒ **≈ 25 min**。
- **可能证伪结果**：最差块被推离区间 ⇒ 对手分布升级为主因候选；**不动** ⇒ 池换血尺度不是约束，M1 权重上升。

### 实验 3：塌缩机制确认探针（区分 M1 死 ReLU vs 其他 critic 塌缩机制）

- **单变量**：**不改训练**。在现有 ckpt 上注入前向探针，对最近 **700 帧真实 rollout**（与已验证解剖窗口同口径）记录：`relu(pol.value_enc_fc(fused))` 逐帧存活率、`mlp0_post` 跨帧 ‖Δ‖、value 输出唯一值个数；对照点 10k / 20k / 25k / 30k / 100k。
- **判据（跑前写死）**：确认 M1 = 100k 处 **存活率 ≤ 1% 且 `mlp0_post` 跨帧 ‖Δ‖ = 0**（现基线 0.000% / 0.0000 / 1 个唯一值）；否证 M1 = 100k 处存活率 **> 30%** 而 value 方差仍 0 ⇒ 死 ReLU 非机制，须另找路径；附判据 = `post_ln` 逐维跨帧 std **> 0.05**（现基线 0.0022~0.0072）而 EV 仍 ≈ 0 ⇒ 「LayerNorm 压动态范围」被否证。
- **成本**：**10 行以内改动 + 一次前向**（5 ckpt × ~700 帧）⇒ **墙钟 < 5 min**，不占训练预算；材料 = 磁盘已有 41 个 `solo_main_<step>.pt` 与 11 个 `replays/league_*.pkl`（后者**不含 0.237 那 40 局**）。
- **可能证伪结果**：若走「否证 M1」分支，主因须改写，且现有 `relu_ln` / `post_ln` 证据需重判为相关性。
