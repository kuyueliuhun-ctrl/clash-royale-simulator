## 0. 判决

# 判定 = **P0（灰区，不判决）**

**理由一句话**：三个估计器变体给出**两个互相矛盾的结论**（V1 = P2，V2 = P2，V3 = **P3**），
按我在**跑之前**写下的 G6（修订 4 §8.2）——"主判据的判决必须在 V1/V2/V3 上一致，
分歧 ⇒ P0，不判决"——**只能判 P0**。

**这不是"结果不好看所以不判"**，恰恰相反：分歧本身就是**本次最重要的结果**，
它说明**"这个 POMDP 的信息够不够"这个问题的答案取决于你怎么训练那个估计器**，
而在弄清"哪个估计器在回答 §2 定义的那个量"之前，任何 P1/P2/P3 都是自欺。

**同时必须记下**：三道独立对照**全部支持 V3**——G5 阳性对照**通过**
（同一条流水线在"必然含局内信号"的靶子上拿到 MLP **+0.2804**）、
时钟基线 **≈0**（只用"局内第几帧"的基线 test **+0.0127**，profile 方差仅占局内方差 **2.47%**）、
**V5 状态打散对照证伪失败**（打散状态、保留时钟后 `EV_within` 塌到 **+0.0001 / +0.0047**）
⇒ **V3 的阳性读数既不是估计器无能、也不是时间假象、也不是与状态无关的公共结构。**
但 V3 与 V1 估计的是**不同的模型**，预注册没有授权我在两者之间事后挑一个 ⇒ **不能据此宣布 P3**。
（证据状态与形式判决的分开陈述见 **§7**；这是本判读最需要读者注意的一节。）

### 2.1 V1/V2 为什么不可读（这是判决的核心依据）

`EV_within` 的**平凡基线恰好是 0**：任何"局内为常数"的预测器（例如"预测全局均值"）
在局内中心化后预测恒为 0 ⇒ `EV_within ≡ 0`。于是：

- **V1：六个模型在留出验证集上的 `val_EV_within` 全为负**（MLP −0.7822 / −0.6986 / −0.7478；
  Ridge −0.2874 / −0.3337 / −0.2497）⇒ **全部劣于"什么都不预测"**。
- **V2：Ridge 被推到 α=1e7（网格内的平凡解），`val_EV_within` = +0.0025（≈0 的数值噪声）；
  MLP 仍为负（−0.4243 / −0.4847 / −0.4320）**。

⇒ **V1/V2 的 `EV_within` 读数是"估计器在自己的留出集上打不过平凡解"的读数**，
不能用来断言"局内回报不可由状态解释"。这就是修订 3 的 G4 想挡的病（数值发散）
在**另一个层面上**的复发：不是预测爆炸，而是**拟合目标与判据口径失配**
（目标 `R` 的方差有 **82% 在局间**，最小化池化 MSE 的模型会把容量全部投给"每局水平"，
局内分量被当作噪声压掉）。

### 2.2 V3 为什么不能直接采纳

V3 把**训练目标**换成局内中心化回报 ⇒ 拟合目标与主判据同口径。它的读数
（MLP `EV_within(B)=+0.1966 ≥ 0.15`，且 `EV_within(C)=+0.1855 ≥ 0.15`、ΔB−C=+0.0111 < 0.08）
照 §3 表正好落在 **P3（H-LEARN）**：**信息已经在现有输入里（含 belief token），
oracle 隐藏量没有额外增量** ⇒ 该方向的结论是"**不是 POMDP 的信息缺口，是 critic 没学**"。

**但 V1 与 V3 估计的不是同一个模型**（一个是"预测整局回报的模型"、一个是"预测局内偏差的模型"），
预注册里**没有授权**我在两者之间事后挑一个。**照单只能判 P0。**

## 4. 时钟基线：**≈0**（排除"时间剖面"这个替代解释）

V3 的阳性读数有一个最明显的替代解释：**模型可能只是在用"这一帧在局内的第几帧"**
（局内中心化回报有共同的随时间的形状），而**不是**在用状态。
零成本复核（直接读落盘的 `runs/_probe_cache_ceiling_stoch.npz`）：

```
只用『帧内位置 k』一个特征的基线（训练局上拟合 profile，测试局上评估）：
  EV_within  train=+0.0274   val=−0.0279   test=+0.0127
  profile 自身方差 / 局内方差 = 1.435 / 58.174 = 2.47%
```

⇒ **时钟基线 ≈ 0**（测试集 +0.0127，验证集甚至为负），时钟能解释的局内方差只占 **2.5%**。
⇒ **V3 的 +0.18 ~ +0.20 不是时间剖面假象**，它来自**与局内位置无关的特征信息**。

> ⚠️ 这条复核是**在 V3 结果之后**做的，属于**诊断**而不是判据；
> 它不改变"P0"（G6 的分歧照旧存在），但它显著缩小了"V3 是假象"的可能空间。

## 6. 对照 V5（修订 5）：**证伪失败 ⇒ V3 的读数来自状态**

**问题**：V3 的阳性读数是不是"状态级"信息，还是某种与状态无关的公共结构？

**判据（在跑之前写在预注册里）**：把每个特征集的行按**"局内位置 k 相同、但来自不同局"**
置换（`--scramble-x`）⇒ **时钟完全保留、状态被打散**，再用**完全相同的 V3 流水线**：

- `EV_within(打散) ≤ 0.05` ⇒ V3 读数**可信**（用的是状态）；
- `≥ 0.15` ⇒ V3 读数**作废**；
- (0.05, 0.15) ⇒ 仍为灰区。

**结果（`docs/pomdp_ceiling_within_center_scrambled.log`，三集都跑）**：

| 集 | Ridge `val_EV_within` | Ridge `EV_within`(test) | MLP `val_EV_within` | MLP `EV_within`(test) |
|---|---|---|---|---|
| A | −0.0000 | **+0.0001** | −0.0055 | **+0.0047** |
| C | −0.0000 | **+0.0001** | −0.0068 | **+0.0073** |
| B | −0.0000 | **+0.0001** | −0.0063 | **+0.0061** |

**V5 判定：六个模型全部塌到 ≈0（最大 +0.0073，远低于 0.05 门槛）⇒ 证伪失败
⇒ V3 的 +0.18 ~ +0.30 来自状态。**

> **⚠️ 读这份日志时不要误读它的 `VERDICT` 字段**：脚本在打散模式下输出 `INVALID_ESTIMATOR`，
> 因为 G4（"至少一个模型 `val_EV > 0`"）在**打散后的输入上必然失败**——打散之后
> **确实没有信号可学**，模型正确地退化为平凡解。**这是阴性对照该有的行为，不是故障。**
> V5 的判据是上表的 `EV_within` 与 0.05 的比较（预注册 §9 判据表），**不是**脚本的 verdict 字段。
> 同一条 G4 在**真实目标**上"通过"、在**打散对照**上"不通过"，恰恰说明 G4 区分得开两者。

⇒ **三道独立对照（G5 阳性对照通过 / 时钟基线 ≈0 / V5 状态打散塌陷）
一致支持"V3 这个估计器是有效的、它的估计是真的"**。
V3 估的是**同一个已经预注册好的量**（§2 的 `EV_within`），只是换了拟合目标。

## 7. 结论的证据状态（与 §0 的形式判决分开写）

**形式判决照预注册读 = P0**（因为 G6 要求 V1/V2/V3 三个变体一致，而它们不一致）。
**但必须把证据状态写清楚，否则读者会把"P0"误读成"什么都没查到"：**

| 估计器 | 是否可读 | 依据 |
|---|---|---|
| V1（目标=回报，池化选择） | **不可读** | 六个模型在留出验证集上的 `val_EV_within` **全为负**，即**劣于平凡解**——这正是**修订 4 §8.1 在跑 V2/V3 之前就登记**的判废原理（"在 within 口径上连平凡解都打不过的估计器，其 within 读数不能用来断言信息不存在"） |
| V2（目标=回报，within 选择） | **不可读** | Ridge 被推到 α=1e7（网格内平凡解，`val_EV_within=+0.0025`）；MLP 仍为负（−0.42~−0.48）。同上原理 |
| **V3（目标=局内中心化回报）** | **可读** | 通过 G5（阳性对照 +0.2804）、时钟基线（+0.0127 ≈ 0）、**V5（状态打散后塌到 +0.0001/+0.0047）** 三道独立对照 |

⇒ **在唯一通过全部对照的估计器上，判决是 P3（H-LEARN）**：
`EV_within(C) = +0.1855 ≥ 0.15` 且 `EV_within(B) − EV_within(C) = +0.0111 < 0.08`
⇒ **信息已经在现有输入（含 belief token）里，oracle 隐藏量没有实质增量**
⇒ 惰性**不是 POMDP 的信息缺口**，是 critic 没学。

**但我**不单方面宣布 P3**，理由是**：这正是 G6 要防的事——在多个估计器之间**事后**
挑一个合意的赢家。§8.1 的判废原理虽然是**跑 V2/V3 之前**登记的，但"V1/V2 不可读"
这个**具体判定**是在看到它们的数字之后才做出的。两条都成立时，诚实的处置是
**如实并列，并把裁判权交给下一轮预注册**：

> **下一个实验（必须先把估计器写死再跑）**：
> ① 主估计器 = V3 的（目标 = 局内中心化回报、`--select within`）；
> ② 预注册三道对照：G5 阳性（已通过）、时钟基线（已 ≈0）、V5 状态打散（已塌陷）；
> ③ **再加一个阴性对照**（把目标换成与状态无关、但同方差/同自相关的序列，要求 ≈0）；
> ④ 判据与阈值照抄 §3，不再新增变体。
> 只有这一轮跑完，P1/P2/P3 才算真正落地。

**在这条落定之前，关于"POMDP 是不是瓶颈"的任何结论都不应写进 AGENTS/论文。**

   但事实是 **V2 只换了"选择口径"、没换"拟合目标"**，而 V1/V3 换的是**模型本身**。

   G5 是对同一原则（"估计器必须先被证明有能力"）的补齐。
3. **V5 的阈值没有写回预注册**（流程瑕疵）：`--scramble-x` 的**方向**判据写在脚本
   help/注释里（跑前产物），但**数值阈值 0.05/0.15** 是我在 job **启动之后**、
   读到任何 V5 输出**之前**写进本判读 §6 的，**没有先写回预注册**。
   按 R3 这是瑕疵，已在预注册 §9 末段如实记录，后续同类对照一律先写进预注册再跑。

## 9. 结论对项目决策的含义

- **"挂起 bf（belief/prophet/plan）通道再跑"这个动作，现在既没有被支持、也没有被否证。**
  V3 指向"信息不是瓶颈"（P3），V1/V2 指向"信息不足"（P2）——
  **两边的读数都建立在尚未判定合格性的估计器上**。⇒ **先做 V5（§6），再决定**。
- **不受影响、可以照旧推进的结论**（它们的证据链与本实验无关）：
  critic 实际是常数（R14 / §0.1 ④）、池化 EV 不是状态级指标、D1 防崩有效（C5/C6）、
  cycling 存在（C4）、绝对强度 374 局无增长（O1）。
- **本实验已经交付的两条方法学产物**（可直接进论文/台账）：
  ① **G5 阳性对照**这个闸门形态（"构造一个按构造必然含信号的靶子，同一条流水线必须能打中"）
  在这次**真的用上了**——它把"估计器无能"与"信息不存在"分开了；
  ② **口径失配**这一类病理的第 ⑪ 个实例：**拟合目标与评价口径不一致时，
  读数会被系统性压到平凡基线以下**，且**唯一可靠的指纹是"在该口径的留出集上劣于平凡解"**。
