## §2 方法（同源配对 + 修掉上一轮的两个口径缺陷）

**单 ckpt / 单 rollout / 同一次前向**同时抓：

| 标签 | 内容 | 角色 |
|---|---|---|
| `raw_obs` | `feat_obs(obs)`（原始 obs 展平，与第二轮 A 集**同一构造**） | **参考集**（不进阶梯） |
| `L0_fused` | 共享感知前端输出（价值编码器输入） | 阶梯 |
| `L1_pre_ln` | `value_enc_fc(fused)` | 阶梯 |
| `L2_relu_ln` | `relu(L1)` | 阶梯 |
| `L3_post_ln` | `value_enc_ln(L2)` ← 被指控层 | 阶梯 |
| `L4_mlp0_post` | `relu(value_head_mlp[0](L3))` | 阶梯 |
| `L5_value` | 最终输出 | 阶梯 |

- **同一批帧、同一目标（GAE 回报按局中心化）、同一局分组切分（seed 7 / test .25 / val .15）**
  ⇒ `raw_obs` 与 `fused` 是**同源配对**比较，这是修上一轮缺陷 #3 的地方。
- **估计器与上一轮逐位相同**（Ridge + 输出裁剪 + `select=within`）。
- **c kpt 与 seed 与上两轮相同**（`runs/critic_inert_probe_20k/solo_main_20000.pt`，seed 7，30000 帧）。

### §2.1 修缺陷：α 网格下界扩到 1e-6（**主网格 = v2**）

上一轮 `post_ln` 选中的 α = **1e-1 = 网格下边界**（按台账 §2 病理 ⑩，"落在边界就是网格不够宽"）。
本轮主网格：

```
v2 = (1e-6, 1e-4, 1e-3, 1e-2, 1e-1, 1e0, 1e1, 1e2, 1e3, 1e4, 1e5, 1e6, 1e7, 1e8)
v1 = (1e-1, 1e0, 1e1, 1e2, 1e3, 1e4, 1e5, 1e6, 1e7, 1e8)          # 上一轮用的
```

- **所有层主读数 = v2 网格**。
- **诊断重拟合（不参与判决）**：`raw_obs` 与 `post_ln` 同时用 **v1 网格**再拟合一次，
  用来回答两件事：①`raw_obs` 在 v1 网格下能否复现第二轮的 **+0.2999**（**估计器可比性检查**）；
  ②`post_ln` 的读数是否被 α 下界压住（v2 − v1 的差）。
- **边界告警**：若某层 v2 网格下选中的 α 仍落在 **1e-6（下边界）**，该层读数标注
  `ALPHA_AT_BOUNDARY`，**不得**用来下"该层无信号"的结论。

## §3 闸门（跑前写死；按【红线 R15】**在本实验自己的量纲上标定**）

| 闸门 | 要求 | 标定依据（R15） |
|---|---|---|
| **G-RAW** 参考集可读 | `EV_within(raw_obs) ≥ 0.15` | **本实验自己的**参考集（与第二轮 A 集**同构造**、同 ckpt、同 seed）⇒ **同量纲**；0.15 取第二轮实测 +0.2999 的一半，作为"估计器明显在工作"的下限 |
| **G-PC** 阳性对照 | `≥ 0.15` | 阳性靶的**局内方差被构造成固定 58**（与特征无关）⇒ 阈值在**目标方差单位**上，天然跨量纲 |
| **G-CLK** 时钟基线 | `≤ 0.05` | 同上（目标单位） |
| **G-SCR** 状态打散（`fused` + `post_ln` + `raw_obs` 各一次） | `≤ 0.05` | 同上 |
| **G-VAR** 目标非退化 | `Var(R)_within > 1` | 防"目标被中心化成 0"的平凡情形 |

**任一不过 ⇒ `V2_INVALID`，不判决。**

## §4 判决（跑前写死；四个分支**互不排斥**，逐条报命中与否）

设 `R0 = EV_within(raw_obs)`、`E1..E3 = EV_within(pre_ln / relu_ln / post_ln)`：

| 分支 | 条件 | 含义 |
|---|---|---|
| **V-LOSS-FRONT** | `R0 ≥ 2 × EV_within(fused)` | **信号在共享感知前端损失 ≥一半** ⇒ 修价值头/拆价值编码器都无效，该动的是**感知前端** |
| **V-LOSS-RELU** | `E1 ≥ 0.05` 且 `E2 < 0.05` | 掉点在 **ReLU** |
| **V-LOSS-LN** | `E2 ≥ 0.05` 且 `E3 < 0.05` | 掉点在 **LayerNorm**（上一轮**未**支持） |
| **V-NO-LOSS-IN-BRANCH** | `E3 ≥ 0.05` | 表示层保有可读信号 ⇒ 掉点在 **MLP 头/训练动力学** |
| **V-NO-LOSS-AT-ALL** | `R0 ≥ 2 × EV_within(fused)` **不成立** 且 `E3 ≥ 0.05` | 感知前端没丢、价值分支也没丢 ⇒ 问题完全在**头的训练** |

- **必须同时报**"命中"与"未命中"，**不许**只报想要的那条。
- 若 `post_ln` 被标 `ALPHA_AT_BOUNDARY` ⇒ **`V-LOSS-LN` 的判决作废**（描述性报告）。
- **反预注册声明**：读数落在以上五行之外 ⇒ `NOT_PREREGISTERED`，只作描述。

## §6 局限（预先声明）

1. **单 ckpt / 单 seed / 单一对手**（【红线 R5】）。层间与集合间是**配对**比较，绝对数不跨 run 比。
2. 线性探针是**下界**：读不出只能证明"线性读不出"。
3. `EV_within` 是**窗口池化**口径下的形状指标；它**不**等于"critic 应该能拟合整局回报"。
4. `raw_obs` 里**不含** plan/belief token（`fused` 含）⇒ 两者不是同一特征集的粗细版本，
   而是"观测原始 vs 编码融合"。`V-LOSS-FRONT` 因此读作"**编码过程**损失"，**不**读作"信息被丢掉"。
5. **α 网格扩界会改变所有层的历史可比性**：本轮的 `fused`/`pre_ln` 数值与上一轮
   （v1 网格）**不可逐位比**；只有 `raw_obs`/`post_ln` 的 v1-vs-v2 诊断重拟合是**受控**比较。
