# `run100k` 启动记录（2026-09-18）

> **用户指令**：「跑一个10万步测试，沿用大小评估」。
> **性质**：`run` 模式 **100k 步**基线跑，**沿用 `long1m` 的两级评估**（小点 8000 步 × 10 局/对；
> 大点 100000 步 × 20 局/对；`--only-vs-main`）。
> ⚠️ **本 run 不含新方案**（局面圣水交换信用分配）——该奖励项**尚未实现**。
> 本 run 的用途：① **恢复主线基线**（`long1m` 只跑到 12.8%）；② 产出 **14 个 schema-4 录像**，
> 供新方案 S2 的离线仪器直接消费。

→ 14 个评估点：大 2 / 小 12；5 对/点（only_vs_main）⇒ 预计总对局 800 局

## 3. 启动命令（原文）

```bash
cd src/clasher_new && PYTHONIOENCODING=utf-8 ../../.venv/Scripts/python.exe -u rl/run_league.py \
  --mode run --config economy --config-name run100k --fresh \
  --total-steps 100000 --steps-per-eval 8000 --big-eval-every 100000 \
  --n-eval-games 10 --n-eval-games-big 20 --only-vs-main \
  --eval-workers 12 --device cuda --diagnose-every 10 \
  --ppo-epochs 4 --ppo-minibatch 32 --ppo-shuffle > ../../docs/train_run100k.log 2>&1
```
