## §3 三条描述性发现（**不参与判决**，但值得记）

### 3.1 `edw` 项是一个"谁在这一帧花钱"的振荡器

| 帧类型 | n | `edw` 项均值 |
|---|---|---|
| **有动作的帧**（bundle 非空） | 276 | **−0.111685** |
| **空帧**（bundle 为空） | 2692 | **+0.015685** |

> 口径核对（脚本复算，非推断）：本 run 的 440 局共 **100860 帧**里 **9278 帧 bundle 非空（9.2%）**，
> 且 **bundle 的子动作 kind 只有 `deploy` 一种**（10157 个，无 `stop`）⇒ 本探针的
> "bundle 非空"**就是**"部署帧"，与 §1 表里的 9.3%（276/2968）一致。

配合 `Σ(带符号) edw = +11.40` 与 `Σ|edw| = 383.67`：

> **资源账项贡献了训练信号量级的 29.8%，但它的净效应只有 +11.4（= 绝对值的 3.0%）。**
> 它几乎全部是"我花钱的那一帧为负、对手花钱的那一帧为正"的**同相振荡**。

这是**potential-based shaping 的预期行为**（势能差在同一条轨迹上望远镜求和），所以它**不是 bug**；
但它是一个**测量事实**：**约 30% 的逐帧奖励量级来自一个净效应近零的振荡项**，
而逐帧优势估计正建立在这些逐帧奖励上。要不要把它当作"占用了 30% 的信噪预算"，需要单独的实验才能说。

### 3.2 每局的奖励，一半来自终局项

- 13 局：`terminal` Σ = **+30.00**（**+2.31 / 局**）；
- 非终局 shaping Σ = `59.96 − 30.00` = **+29.96**（**+2.30 / 局**）。

⇒ **按带符号计，非终局塑形与终局胜负各贡献约一半的每局回报**（+2.30 vs +2.31）。
（含符号的口径下"稀疏奖励被淹没"的说法不成立；按绝对量级则相反。**两个口径必须同时报**，
这正是台账 §2 病理 ⑨"跨相位/跨口径池化"的同类问题。）

### 3.3 ⚠️ 塑形项**不满足** potential-based shaping 的 policy-invariance 条件（理论层面）

`rl/env_wrapper.py:252`：

```python
reward += edw * ((me_a - op_a) - (me_b - op_b))        # = edw · [Φ(s') − Φ(s)]
```

Ng, Harada & Russell (1999) 的 policy-invariance 定理要求塑形形如 **`γΦ(s') − Φ(s)`**。
我们的实现缺 `γ`，因此：

```
edw·[Φ(s') − Φ(s)] = edw·[γΦ(s') − Φ(s)] + edw·(1−γ)·Φ(s')
                                             ^^^^^^^^^^^^^^^^^^ 多出来的项
```

多出来的项 = `edw·(1−γ)·Φ(s')`，其中 `Φ = Φ_me − Φ_opp`：

- `edw = 0.5`（t<120s）、`1−γ = 0.003`、本样本 `mean(Φ_me − Φ_opp) = +0.812`
- ⇒ **额外偏置 ≈ 0.5 × 0.003 × 0.812 = +0.00122 / 帧**
- 相对**每帧平均奖励 +0.0202** 是 **6.0%**；相对**每帧奖励绝对量级 0.3989** 是 **0.31%**

⇒ **量级很小**，且它是一个**近状态常数**的偏移（在同局长度的轨迹上近似等量叠加，
在优势里大部分抵消）。**因此本条不是本轮的主结论**，只作为**唯一一条"能一行修好"的理论缺陷**记录：

> 若要恢复 policy invariance，塑形应写成 `edw·(γΦ(s') − Φ(s))`。
> **但这是训练语义改动**（【红线 R2】：新能力必须落在 `TrainConfig` 显式开关后，默认逐位回旧），
> 而且**改之前必须先有单变量预注册实验**证明它值得改（【红线 R11】：不在取证之前改奖励）。

## §4 这一轮**排除**了什么 / **留下**了什么

| 假设 | 状态 |
|---|---|
| "逐帧奖励被资源账（edw）主导 ⇒ 策略在优化对账而非赢" | **被排除**（29.8% < 50%） |
| "逐帧奖励被塔伤主导" | **被排除**（21.5% < 50%） |
| "终局胜负被塑形淹没" | **不成立也不被否证**（10.11%，临界，且口径对终局项不公平） |
| "行为病理（只打便宜牌 / 从不攒费）是奖励直接买来的" | **未被支持**；`edw` 对**非法术部署** ΔΦ=0（读源码得到的先验），读数也一致 |
| "塑形项违反 potential-based shaping 的 policy-invariance 条件" | **成立（理论）**，但偏差量级 +0.0012/帧（6%），**不足以解释上限不动** |

⇒ **行为病理的因果仍然开放**，但候选集被削掉了一层：**不是"奖励被某一项主导"**。
下一步应该问的是**优化/探索侧**（例如 `adv_norm="scale"`、优势形状、动作分布坍缩），
以及**手写专家对照**（`replay_behavior_forensics_2026-09-14.md` §9 第 1 项）。

## §5 局限（与预注册 §5 一致，此处再确认）

1. **单 ckpt / 单 seed / 13 局（2968 帧）**。只描述**该策略在该段**的分量结构，**不跨 run 比**（【红线 R5】）。
2. 分解是**权重线性**意义上的**精确项**，但项之间存在**行为耦合** ⇒ **只能证明"信号结构的量级归属"，
   不能证明因果**。要证因果必须做单变量消融（改 `elixir_diff_weight` 重训）。
3. **CPU rollout**（22.9 f/s），与 GPU 上并行跑的另一只读探针无争用。
4. `unit` 项由 `step_reward − full` 的差值得到；本样本无异常符号（`Σ = −3.72`，与
   "单位交换净亏"一致），未触发预注册 §5 的 `NOT_PREREGISTERED` 出口。
5. **W3 的 10% 阈值是我定的**，`10.11%` 与它没有实质差别——**不要把这一条当成结论**。
