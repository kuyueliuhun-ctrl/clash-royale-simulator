## 0. 问题（可否证形式）

**Q**：在当前实际使用的**逐帧输入**下，状态能否解释**局内（intra-episode）回报的变化**？
把**oracle 隐藏量**（对手手牌/循环/圣水，引擎真值）加进去，解释力能提升多少？

- **H-POMDP**：局内回报变化主要由**看不到的量**驱动 ⇒ 即使最优 critic 也只能是平的
  ⇒ 挂起/替换推理通道**有可能**改变惰性（值得投一跑）。
- **H-STRUCT**：即使给出 oracle 隐藏量，局内回报变化仍不可由状态解释 ⇒ 惰性**不是信息问题**
  ⇒ 挂起 bf 通道不会改变惰性（省一次 80 min 的消融）。
- **H-LEARN**：现有输入（含 belief token）**已经**含局内信息，只是 critic 没用上
  ⇒ critic 修复有空间，但**与 POMDP 无关**。

三者互斥、可判。

## 1. 设计（只读探针，不改训练语义 ⇒ R2 无关）

**脚本**：`scripts/pomdp_ceiling_probe.py`（新增，只读；rollout + 监督拟合都在探针内完成，
**不碰** `train_solo.py` / `ppo.py` 的训练路径）。

**数据生成**：镜像卡组 `solo_env` + 目标 ckpt 的冻结副本作对手，逐帧记录
`(obs 特征, belief token, oracle hidden 标签, 奖励, critic 输出 V)`；局末用
**与训练完全相同的 `PPOTrainer.compute_gae`**（γ=0.997、λ=0.99、truncation 用 `last_value` 自举）
算出每帧回报 `R` —— 即 critic 真正被训练去拟合的那个目标。

**精度锚**：`--ckpt runs/critic_inert_probe_20k/solo_main_20000.pt`
（**就是惰性检验那个 run 的末点**，这样"当前 critic 的局内 EV"与"监督天花板"在同一批帧上可比）。

**两种采样模式**（各跑一次，互为稳健性）：
- `--mode stoch`（**主判据用这个**）：两侧 `deterministic=False`，贴近训练分布；
- `--mode det`：两侧确定性（沿用既有探针 `_probe_value_path.py` 的设定），
  可预测性的**上界**（未来更可预测 ⇒ 偏向 H-POMDP，故它对 H-POMDP 有利、对否证保守）。

**特征集（同一批帧，三个嵌套集）**：

| 集 | 内容 | 语义 |
|---|---|---|
| **A** | `obs` 原样展平（grid 32×18×C + 手牌 5 + 圣水 + 进手 + 时间） | **跟随者实际看到的** |
| **C** | `A` + `belief_token`（563 维） | **critic 实际拿到的**（含历史/后验推断） |
| **B** | `A` + oracle 隐藏量 = 每张牌在对手循环中的位置(8) + 对手手牌占用(8) + 对手进手(8) + 对手圣水(1) | **MDP 视角**（POMDP 缺口被填满） |

> B 只加**引擎真值**中**不体现在 A 里**的量（对手循环序/手牌/圣水）。对手塔血/皇冠/
> 时间/我方手牌圣水本就在 A（`observation.py:87-144`），不重复加。

**模型**：Ridge（标准化后闭式解，α 由训练集内部 20% 局留出选）与 MLP（2×128，ReLU，
Adam 1e-3，早停按内部留出）各拟合一次；**主判据用 MLP**（容量更接近"天花板"），Ridge 作线性对照。

**留出**：**按局分组留出**（R9④）——固定种子随机抽 25% 的局做测试集，
其余 75% 训练、其中 20% 作内部验证。逐帧随机留出会时间泄漏（`corr(R_t,R_{t+1})≈0.99`），禁止。

## 2. 指标（跑前定义，主判据用 `EV_within`）

| 指标 | 定义 |
|---|---|
| `EV_pooled` | `1 − MSE(v,R)/Var(R)`（全网池化） |
| **`EV_within`（主）** | **局内中心化口径**：`1 − MSE(v−v̄_ep, R−R̄_ep) / Var(R−R̄_ep)`。它正是优势算子关心的量：`A=GAE(δ)`，`δ_t=r_t+γV_{t+1}−V_t` ⇒ 只有 V 的**局内变化**能进入优势（常数部分在差值里抵消） |
| `EV_within_raw` | `1 − MSE(v,R)/Var(R−R̄_ep)`（不中心化，含每局的水平偏置；描述性） |
| `EV_win128_med` | 每局切成连续 128 帧窗，逐窗算 EV 后取**中位**（描述性；分母可能很小，只作对照） |
| `V_critic` 的 `EV_within` | 同一批帧上**被训练 critic** 的读数（锚点/成立性闸门） |
| 方差分解 | `Var_between`（局均值方差）/ `Var_within`（局内方差）/ 占比（复核代码注释里"批内 Var(R) 仅为全局 0.32 倍"的说法） |

## 4. 已知局限（跑前登记，判读时必须写进结论）

1. **对手是自身冻结副本**，比训练期的混合对手池（frozen/hist/defend/rand_anchor）**窄**；
   `V_critic` 与模型的绝对数不跨分布外推，只作**同帧对照**。
2. 监督探针**没有 RNN**（逐帧 Markov）。A 因此可能**低估**"可观测量"的天花板；
   这正是同时跑 **C（含 belief token，历史信息的压缩）** 的原因——若 `C ≫ A`，
   说明历史/推断重要，而 B 与 C 的差才是"engine 真值 vs 现有通道"的净缺口。
3. oracle 集 B 只包含 replay/label 里有的隐藏量；**对手未来的决策随机性不可消除**，
   它构成 `EV_within` 的**不可约上界损失**——P2 的"连 oracle 都 ≤0.05"因此同时意味着
   "局内回报变化主要由未来随机性驱动"，这一点会照实写。
4. 单 ckpt、单 seed；判据是**机制量级**判据（0.05 / 0.15 的宽区间），不是精密估计。

## 7. ⚠️ 修订 3（2026-09-13 夜，**发生在重跑之前**）：估计器发散闸 + 数值参数放宽

**发生了什么（首跑，已作废）**：`docs/pomdp_ceiling_probe_stoch.log`。
rollout **正常**（32,969 帧 / 147 局 / 1738 s / 19.0 帧·s⁻¹ ⇒ 闸门 G1 过；
方差分解 `Var(R)=206.09`、局间 174.22、局内 58.32 ⇒ **局内占比 0.283**，独立复现了
`train_solo.py:1286-1287` 注释里"批内 `Var(R)` 仅为全局 0.32 倍"的量级），
但**监督拟合在整局留出上发散**：`EV_within` = **−62.8**（A-ridge）/ **−94.1**（A-mlp）/
**−56.5**（C-ridge）/ **−57.4**（C-mlp）。`EV_within = −60` 意味着预测误差 ≈ **8×** 回报 std
⇒ **这是估计器故障，不是科学结果**；该 run 在 A/C 两集后被终止，**未产出 verdict JSON**。
（若照单读，`EV_within(B) ≤ 0.05` 会直接触发 **P2**＝"信息不是瓶颈"——一个由发散模型
制造的假结论。这就是本次修订要挡的东西。）

**根因（两处，均属估计器、不属问题）**：
1. `fit_ridge` 的 alpha 网格上限只有 **10**，而 d=**8648**、n≈2×10⁴ ⇒ 相对正则强度
   10/19850 ≈ **0.05%**，几乎等于 OLS ⇒ 在**分布外**的留出局上外推爆炸
   （三个集**都选中了网格上限 10**，即"网格太窄"的直接指纹）；
2. 无输出裁剪；MLP 无 weight decay。

**修订内容**：
- alpha 网格放宽为 **1e-1 … 1e8**（每 10 倍一个点，共 10 个）；
  `alpha→∞` 即"预测训练均值"，是 `EV=0` 的下界解 ⇒ 该网格**必然包含一个不发散的解**；
- **所有模型输出裁剪到训练目标区间** `[min(y_tr), max(y_tr)]`；
- MLP 加 `weight_decay = 1e-4`（并保留原有 early-stop）；
- **新增闸门 G4（估计器闸）**：若**所有**模型在留出验证集上 `val_EV ≤ 0` ⇒
  `verdict = INVALID_ESTIMATOR`，**实验作废、不判 H**（已同步写进 §3 的闸门表）；
- 新增 `--save-npz`：把逐帧 `(X_A, X_C, X_B, y, v, ep)` 落盘 ⇒
  **后续拟合迭代不再需要重跑 ~29 分钟的 rollout**；
- 判读输出增加 **val 口径**（`val_EV` / `val_EV_within`），用于把"估计器好坏"与"信息上限"
  分开看。

**为什么不算事后调参**：本修订只动**估计器的数值稳定性**（正则范围、输出范围、权重衰减），
**不动问题、不动特征集、不动判据阈值**（P1/P2/P3 的 0.05 / 0.15 / 0.08 一字不改），
且发生在**任何可读结果产生之前**（首跑无 verdict）。这是一次**设计缺陷的修复**，
按 R10 记录在此，而不是静默重跑。

## 8. ⚠️ 修订 4（2026-09-13 深夜，**发生在看到主跑结果之后**）：估计器必须与主判据同口径 + 阳性对照闸

**先说清楚时序**：本修订是**事后追加**的，触发它的是主跑（修订 3 修复后）的结果本身。
按 R3 的纪律，事后改动必须显式披露，因此单列一节，并且**只在让结论更难得出的方向上改**。

### 8.1 主跑结果与它为什么不可读

日志 `docs/pomdp_ceiling_probe_stoch.log`（rollout 32,982 帧 / 149 局 / 1874.7 s / 17.6 帧·s⁻¹
⇒ G1 过；`Var(R)=203.20`、局间 166.75、局内 58.17 ⇒ **局内占比 0.2863**，与首跑 0.283、
与 `train_solo.py:1286-1287` 注释量级一致）。脚本照单读出 **`P2_H_STRUCT_FALSIFIED_POMDP`**：

| 集 | 模型 | `val_EV`（池化） | **`val_EV_within`** | `EV_within`（测试） |
|---|---|---|---|---|
| A | ridge (α=1e4) | +0.2675 | **−0.2874** | −0.1116 |
| A | mlp | +0.1457 | **−0.7822** | −0.5027 |
| C | ridge (α=1e3) | +0.2834 | **−0.3337** | −0.2375 |
| C | mlp | +0.1606 | **−0.6986** | −0.5803 |
| B | ridge (α=1e4) | +0.2331 | **−0.2497** | −0.0891 |
| B | mlp | +0.1046 | **−0.7478** | −0.5432 |

**为什么不能读**：`EV_within` 的**平凡基线是 0**——"预测每局均值"在局内中心化后预测恒为 0，
`MSE = Var(R−R̄_ep)` ⇒ `EV_within ≡ 0`。上表**六个模型在留出验证集上全部小于 0**，
即**全部劣于"什么都不预测"**。一个在 within 口径上连平凡解都打不过的估计器，
其 within 读数**不能**用来断言"局内回报不可由状态解释"——这与修订 3 要挡的是同一种病，
只是深了一层：修订 3 挡的是**数值发散**（`EV_within ≈ −60`），这里挡的是**口径失配导致的
系统性压低**（−0.25 ~ −0.78）。

**根因（估计器侧，与问题无关）**：
1. **模型选择口径与主判据口径不一致**：`fit_ridge` 的 α 与 `fit_mlp` 的早停都用**池化** `val_EV`
   选择，而主判据是 `EV_within`。本数据的方差 **82% 在局间**（166.75/203.20），
   于是选择器把容量全部投给"每局水平"，局内分量被当作噪声压掉——这是设计缺陷，不是数据性质。
2. **没有阳性对照**：原设计无法区分"信息不存在"（真结论）与"估计器无能"（假结论）。
   G4 只查了池化层（`val_EV > 0`，上表全过），**查错了层**。

### 8.2 修订内容（三条，全部只让结论更难得出）

| # | 内容 | 作用方向 |
|---|---|---|
| **G5 阳性对照闸** | 构造一个**按构造必然含局内信号**的目标：取方差最大的 64 个真实特征列中的 8 列，合成非线性函数作为局内信号，按**真实回报的局内/局间方差配平**（within 58.17 / between 166.75）后叠加局间偏移。**同一条流水线**在它上面必须达到 `EV_within ≥ 0.15`（与 P1 同一门槛） | 做不到 ⇒ `INVALID_ESTIMATOR`，**实验作废**。只会把 P1/P2 变成"不判"，不会把 P2 变成 P1 |
| **口径变体 V2** | `--select within`：α 与早停改用 `val_EV_within`（与主判据同口径） | 给 within 一个**公平**的估计器；对 P2 **保守**（更容易发现信号） |
| **口径变体 V3** | `--select within --center-target`：目标直接换成局内中心化回报 `y−ȳ_ep`，即**免费**给估计器每局的均值 | 同上；最有利于发现局内信号 ⇒ 对 P2 最保守 |
| **G6 口径一致性（判读时施加）** | 主判据的判决必须在 **V1（原口径）/ V2 / V3** 三者上**一致**；出现分歧 ⇒ 判 **P0 灰区，不判决**，并把分歧本身作为结果报告 | 让 P2/P1 **更难**成立（三倍的机会出现分歧而落入"不判"） |

**阈值 0.05 / 0.15 / 0.08 一字不改**；特征集 A/C/B 不改；主判据 `EV_within` 不改；问题不改。
V2/V3 都只是**同一个量的不同估计器**（`EV_within` 的定义不变），不是新指标。

### 8.3 为什么这不算"朝着想要的结论改判据"

1. **方向单侧**：三条修订都只能把结论推向"作废/灰区"，没有任何一条能把 P2 推向 P1。
   若 V2/V3 与 V1 一致给出 `EV_within(B) ≤ 0.05`，**P2 反而被加固**（三个估计器都同意）。
2. **触发现象客观且与假设无关**：六个模型在**自己的留出集**上输给平凡基线，
   这是估计器质量的事实陈述，不是对 POMDP 假设的判断。
3. **G4 的登记理由本来就覆盖这一条**：预注册 §3 写 G4 的动机是"**估计器必须先被证明有能力，
   再读它的天花板**"；G4 的疏漏只是**查了池化层**。G5 是对同一原则的补齐，不是新原则。

### 8.4 主跑已记入台账的两条附带结果（与判据无关，独立有效）
