## 3. 这几张表说的是什么（描述性，【R3】非判据）

1. **全过程随机这个 agent 是"几乎不出牌"的**：90.4% 的帧交空 bundle —— 但**不是它选择不出**，
   而是**88–91% 的帧根本买不起任何手牌**（与 `pass_prob_2026-09-18.md` 的既有读数一致）。
   真正"有牌可出却不出"的帧（A ∩ 圣水≥6）**= 0**。
2. **全过程随机**同样**到不了 6 费**，而且比「到不了」更极端：**圣水峰值 5.357 = 开局 5.0 + 2 帧回费**（逐帧复核：该峰值只出现在**每局第 3 帧**，即首次出牌之前）⇒ **100 局 31,491 帧里圣水从未超过开局水平**；
   `≥6` 帧 **0.000%**、A 段最长 **24 帧 < 34 帧**（攒到 Xbow 所需）⇒ **Xbow 一次都没打出去**（3,062 次部署里 0 次）。
   这与前几轮的解析预测和 probe 的 `uniform` 臂（2,084 帧、峰值 5.36、≥6 占比 0.000%）**逐项吻合**
   （那 5.36 也是同一个「开局 + 两帧回费」的值）
   ⇒ 在**更大样本（31,491 帧）**上再次确认「等概率随机不可能产出攒费轨迹」。
3. **掩码修复的端到端复核（更大样本）**：`B 整包被拒 = 0.0%`（31,491 帧，此前修复验证是 3,413 帧）
   ⇒ 那台**当初发现 B 类病理的仪器**在修复后的新录像上读 0。
4. **"位置随机"到底改了什么（量化）**：随机臂用到 **484/576 格、熵 8.47 bits ≈356 有效格**；
   对比同卡组训练策略的真实落点（两臂 100 万步 **84/90 格、4.5/4.2 bits ≈20 有效格、top10 占 73%/78%**，
   见 [`exploration_randomization_analysis_2026-09-18.md`](exploration_randomization_analysis_2026-09-18.md) §5）
   ⇒ 均匀落点是**把 ~20 个有效格摊成 ~356 个**的剧烈改动，不是"加一点随机"。
5. **胜率 58% 怎么读（重要限定）**：这是一场**"未训练模型 vs 未训练模型"**的对局
   —— p1 是同一个 `solo_main_0.pt` 的**确定性副本**，p0 是完全随机。
   ⇒ 只能说「**在本分辨率下，均匀随机 agent 对初始模型的胜率没有低于 50%**」，
   **不得**读成"随机策略很强"或"初始模型很弱"的绝对结论（自引用性质：双方同源、都没有训练）。
   ⚠️ 也要注意这**不是**面板默认建议读的那条曲线（面板把胜率归入「自引用（禁读）」分组）。

## 4. 纪律与局限（照抄，别省）

* 【R5】n=1 ckpt、单 seed、100 局 ⇒ 一律**描述性**；胜率 SE ±4.9% ⇒ **58% 与 50% 在本分辨率下不可分辨**。
* 【R3】本测试**未预注册**，**不是判据**，**不得**并入任何判据集。
* 【R10】已知局限（必须写）：
  1. **p0 是随机 actor，不是策略**：它的动作没有 `logprob` 意义 ⇒ **这份录像不能用于训练/BC**，
     只能作行为观测与回放演示；
  2. **对手与 p0 同源**（同一个初始 ckpt）⇒ 胜率不含绝对强度信息；
  3. **`step` = 累计决策帧**（【R9】的口径），不是"评估轮数"；`history` 的 10 个点 = 逐 10 局的分块，
     与生产 run 的"逐评估点"语义**不同**，不要跨 run 比；
  4. 面板行为指标列（接敌率/单边堆牌/平均圣水/EV/熵…）**本 runner 没有填** ⇒ 显示 `–`（**不伪造**）；
  5. 中途落盘的 9 个中间录像已删除，只保留最终 100 局那份（否则既有仪器按 `league_*.pkl` 通配
     **会把同一批局重复计数**）。
