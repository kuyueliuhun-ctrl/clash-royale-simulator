### S:normalize_query  [L408-422]
- 类型: function
- 签名: `def normalize_query(q: str) -> str:`
- 作用: 把任意查询串归一化成索引键：中文只保留汉字流，英文/数字转小写并剥掉所有非字母数字字符；同时含中文与拉丁字符时输出 `中文|英文` 复合键。
- 参数:
  - `q` (`str`): 待归一化的原始查询串（可能是 None/非字符串，见实现 L410、L412）。
- 返回: `str`。空/假值输入返回 `""`；含中文且无拉丁字符时只返回汉字串；含中文且含拉丁字符时返回 `f"{zh}|{en}"`；纯英文/数字返回小写字母数字串（L410-422）。
- 实现: L410-411 若 `not q` 直接返回空串；L412 用 `str(q).strip()` 转字符串并去首尾空白（因此 None→"None" 之前先被 `not q` 拦住）。L414 用 `re.sub(r"^the\s+", "", s, flags=re.IGNORECASE)` 剥掉开头冠词 `the `（注释 L18 口径）。L416 用 `re.sub(r"[^\u4e00-\u9fff]+", "", s)` 抽取汉字流得到 `zh`。L417-420 若 `zh` 非空：对 `s.lower()` 再做 `re.sub(r"[^a-z0-9]+", "", ...)` 得 `en`，`en` 非空则返回 `f"{zh}|{en}"`，否则只返回 `zh`。注意注释 L418 举例「x弩 → x弩/xbow」，而按代码实际输出为 `弩|x`（汉字在前、拉丁在后，且不做 x→xbow 的语义扩展）。L422 无中文时返回 `re.sub(r"[^a-z0-9]+", "", s.lower())`。
- 调用: 被本模块 `_build_index._add`（L451）与 `search_card`（L492）、`search_card_candidates`（L514）调用。它本身只调用 `re.sub`/`str.strip`/`str.lower`。全仓 `.py` 检索未见其他模块直接调用 `normalize_query`。
- 置信度: 已确认
