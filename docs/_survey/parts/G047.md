### S:f  [L45-47]
- 类型: function
- 签名: `def f(lam):`（原文无类型注解、无返回注解）
- 作用: 计算对偶侧目标值 —— 给定权重向量 `λ`（长度 64），返回 `R * ||x − mean(x)|| + c·λ`，其中 `x = rᵀ λ`；`x` 去均值后取 L2 范数即「以半径 R 的零和方向」对偶化后的那一项。
- 参数:
  - `lam` (无默认值，torch 张量，长度 64): 对偶变量，被用来线性组合 `r` 的各行（`r.t() @ lam`）并与 `c` 做内积
- 返回: Python `float`（`float(...)` 在 L47 显式转换）
- 实现: L46 先算 `x = r.t() @ lam`，得到长度为权重行数（`W.shape[0]`，即单元数）的向量；L47 把 `x` 减自身均值 `x.mean()` 后取 `.norm()`（L2 范数）乘以常数 `R`，再加内积 `c @ lam`，最后 `float(...)` 返回。整个函数无分支、无循环、无边界检查；不读全局以外的状态（闭包引用模块级 `r`、`c`、`R`）。
- 调用: 被 L48 用均匀 λ 调用一次；被 L49 的列表推导对 64 个标准基向量 `torch.eye(64)[i]` 各调用一次；被 L53 对 20000 个 Dirichlet 随机 λ 逐个调用（共 20064 次）。它自身只调用 torch 张量运算，不调用仓内其他函数。
