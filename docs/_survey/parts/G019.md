  1. L76-78：取 `name = char_def.get('name')`；无名或**已在 `card_data` 中**则直接返回（幂等保护）。

### S:_value_at_level  [L196-207]
- 类型: function
- 签名: `_value_at_level(arr, rarity, level, base)`
- 作用: 按稀有度等级轴取 per-level 数组值；索引越界按实测曲线 ×1.1 延续，数组为空则按 `base`（lv1 基准）×1.1^(level-1) 推导（L197-201 docstring）。
- 参数:
  - `arr` (list|None): per-level 数组（如 `hitpoints_per_level`）。
  - `rarity` (str): 传给 `_rarity_level_index` 定轴。
  - `level` (int): 目标等级。
  - `base` (number): 数组为空时的 lv1 基准值。
- 返回: 数值（数组元素或 `round` 后的推导值；`base` 为 0/None 时返回 `0`，L207）。
- 实现: L202 求 `li`；L203-204 在 `0 <= li < len(arr)` 时直接返回 `arr[li]`；L205-206 越界时以**数组末元素**为基准按 `1.1 ** (li - len(arr) + 1)` 外推并四舍五入；L207 空数组时 `round(base * 1.1**(level-1))`。注意空数组分支用的是 `level` 而非常规轴的 `li`——即空数组一律按 Common 轴折算（docstring 亦如此写）。
- 调用: `Card.set_level` L356/L366/L374/L376/L394/L396；外部 `battle.py:1764/2462/2790`、`card_mechanics.py:542`、`scripts/test_m2.py:438/440`。
