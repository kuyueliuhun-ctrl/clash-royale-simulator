### S:_curve  [L29-33]
- 类型: function
- 签名: `_curve(value, src_level, length=17)`
- 作用: 以「官方统一 ×1.1/级」曲线，从 `src_level` 基准值生成一条长度为 `length` 的按级数值数组（index = level-1）。
- 参数:
  - `value` (数值): `src_level` 等级下的基准值。
  - `src_level` (数值): 基准等级（1-based）。
  - `length` (默认 `17`): 生成数组长度（17 = Common 轴等级数）。
- 返回: `list`，长度 `length`，元素为 `round()` 后的整数。
- 实现: L32 先把基准值反推回 lv1：`base = value / (1.1 ** (src_level - 1))`；L33 用列表推导生成 `[round(base * (1.1 ** i)) for i in range(length)]`，即第 i 项对应等级 i+1。无边界检查（`src_level=0` 或非整数不报错但语义不明）。仅用于注册派生角色，注释明确「引擎 set_level 消费」。
- 调用: 本文件内被 `apply()` 调用（L275 `hitpoints_per_level`、L276 `damage_per_level`）。全仓 `from elite17_data import` 语句只出现 `HERO_BASE_STATS`/`hval`/`HERO_ABILITIES`（battle.py L2415/L2459、card_mechanics.py L864），故 `_curve` 无跨模块调用者。
