  1. **规则层手牌后验**（真实贝叶斯部分，实现在 `rl/bayes_filter.py`）。粒子 = 8 卡 cycle 的一个
     排列 π（L50）；先验 = 均匀（`_resample_uniform`，L89-100）；观测到出牌 c 后做**一致性筛选**
     （硬 0/1 似然）：只保留满足 `c ∈ π[:4]` 的粒子并推进状态 π ← [x for x in π if x≠c] + [c]
     （`_consistent` L108-114、`_play` L71-74），新权重 `w_i = 1/|P'|`（L139）。
     查询：`hand_probs[c] = (1/|P|)·#{π : c ∈ π[:4]}`（L160-165）、
     `next_probs[c] = (1/|P|)·#{π : π[4] = c}`（L167-176），按 `deck` 顺序返回，
     形状均为 **`(len(deck),)` = (8,)` float32**。**锁定流是精确推理而非粒子近似**：
     连续 4 张互异且属卡组内的一致出牌后 `_lock_from_tail` 重建规范 cycle
     （L76-87、L143-147），此后 hand_probs / next_probs 为 **0/1 精确值**（L157-159、L170-171）。
  2. **无归一化除零**：`Card` 概率不显式归一化——粒子相下一致解全量保留（L137-139 注释），
     故 Σ hand_probs = 4、Σ next_probs = 1 自动成立。
  3. **统计层不是贝叶斯**（`StatisticalBelief` L130-164）：维护**确定性计数**
     `tendency_counts ∈ R^{5}`（初始 0）与 `side_counts ∈ R^{2}`（左/右，初始 0，L134-135）；
     每次观测按规则给对应类目 +1（L145-158）；`probs()` 用 **Laplace 加 1 平滑**
     `p = (tendency_counts + 1) / Σ(tendency_counts + 1)`（L163-164），
     输出形状 **(5,)** float32；`total == 0` 时返回均匀 1/5（L161-162）。
  4. **神经层**（`NeuralBeliefEncoder` L167-229）：`self.gru = nn.GRU(in_dim, hidden, batch_first=True)`，
     默认 hidden=64（L173、L183）；输入序列形状 **(1, T, D)**，T ≤ `max_len=32`（L200-201，deque
     `maxlen=max_len` L187）；输出 `belief_proj(h[-1])` → **(1, hidden)=(1,64)**，`squeeze(0)` 后
     `token` 形状 **(64,) float32**（L211-213）。`encode()` 是**有状态**的：先 `push_frame(feat)` 再编码
     全历史（L207-208），调用一次即把当前帧追加进历史。
  5. **`belief_token` 维度恒等式**（L344-362 拼装顺序）：
     `[hand_probs(8) | next_probs(8) | [elixir_mean, uncertainty](2) | tendency_probs(5) |
     opp_event_token(3×180=540)]` ⇒ **563 维**（两段 8 维长度由 `len(deck)` 决定，
     本组调用点默认卡组为 8 张）。若传 `neural` 且 `obs is not None`，再追加神经 token
     64 维 ⇒ **627 维**。563 与 `belief_token_dim(deck8)=2*8+2+5+540`（L36-38）一致；
     该式**只刻画无神经编码的情形**（函数体内不含 `hidden` 项，L37-38），
     实机复算得 563，与 `rl/follower.py:34 BELIEF_DIM` 的取值口径一致。
  6. **圣水估计**（标量，非分布）：`_elixir_est` 初值 5.0（L268），
     `_tick_elixir` 按观测时间差线性回复 `e ← min(10, e + max(0, t−t_last)/2.8)`（L292-298），
     `update` 中每张已归一化的出牌扣 `Card(card).elixir` 后 `clip(0,10)`（L313-315）。
     注意**先回费后扣费**的顺序（L302 在 L313 之前）。`BeliefState.elixir_std` 不是统计方差，
     而是启发式 `max(0.5, |e−5|/5)`（L327）。
  7. **`uncertainty`** = 归一化规则熵 `clip(entropy()/log(8), 0, 1)`（L323）；
     `entropy()` 在锁定流恒为 0.0，粒子相为 `−Σ p log p`（`bayes_filter.py` L178-184）。
     log(8) 的分母与卡组 8 张的满熵对应。
