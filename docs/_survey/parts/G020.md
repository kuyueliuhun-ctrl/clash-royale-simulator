### S:check  [L22-25]
- 类型: function
- 签名: `def check(name, cond, extra='')`
- 作用: 断言记录器：条件为真则 `PASS += 1` 并打印 `  OK <name>`，否则 `FAIL += 1` 并打印 `  FAIL <name>`；`extra` 非空时追加方括号附注。**不抛异常**，全部测试跑完才由退出码体现失败。
- 参数:
  - `name` (str): 断言名称，直接进打印。

  - `extra` (str, 默认 `''`): 附注（多为实测值格式化串），空串则不打印方括号段。
- 返回: 无
- 实现: `global PASS, FAIL`（L23）后单行分支（L24-25）：真值分支与假值分支各自自增并 `print(f'  OK {name}' + (f'  [{extra}]' if extra else ''))`；两分支区别仅在前缀 `OK`/`FAIL`。因为是 `print` 而非 assert，**单条失败不打断后续断言**，这是"一次跑完看总数"的设计。
- 调用: 被本文件全部 19 个 test 函数调用；不调用其它模块。全局 `PASS`/`FAIL` 在 `__main__` L520 汇总打印。
