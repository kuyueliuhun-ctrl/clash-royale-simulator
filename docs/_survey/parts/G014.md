### S:_play_one  [L252-357]
- 类型: function
- 签名: `_play_one(env, pol_a, pol_b, deckA, deckB, cfg, seed, max_steps, buf_a, buf_b, bp, prophet, rng, rw_a, rw_b)`
- 作用: 让 `deckA→pol_a`（player-0）、`deckB→pol_b`（player-1）打 1 局且不换边，双侧都收集探索轨迹，返回 `winner`（0/1/None）。
- 参数:
  - `env` (RLEnv): 复用同一个环境实例，函数内直接改 `deck0`/`deck1`/`opponent`。
  - `pol_a` / `pol_b` (FollowerPolicy): player-0 / player-1 策略。
  - `deckA` / `deckB` (dict 或 list): 卡组，dict 时取 `["cards"]`。
  - `cfg` (TrainConfig): 使用 `cfg.gamma`/`cfg.gae_lambda`（经 `_flush_episode`）。
  - `seed` (int): 派生两侧 `BeliefInference` 的种子（B 侧用 `seed + 1`）。
  - `max_steps` (int): 每局最大决策步数。
  - `buf_a` / `buf_b` (list): 双侧输出缓冲。
  - `bp` (BeliefPlanner) / `prophet` (ProphetPlanner): 规划器。
  - `rng` (random.Random): 决定是否使用 prophet（`< _PROPHET_PROB`）。
  - `rw_a` / `rw_b` (dict): A/B 各自的 reward_weights；reward0 用 rw_a，reward1 用 rw_b 镜像计算。
- 返回: `winner`，值为 `env.battle.winner`（0/1）或未结束时 `None`（L303、L357）。
- 实现:
  1. 设置牌组：`env.deck0/deck1 = list(deckX["cards"]) if isinstance(deckX, dict) else list(deckX)`，并把 `deck0_factory`/`deck1_factory` 置 `None`（L261-264）。
  2. 建 A 侧 `BeliefInference(opp_deck=env.deck1, n_particles=128, seed=seed)`（L265）；建 `FollowerOpponent(pol_b, env, belief=BeliefInference(opp_deck=env.deck0, n_particles=128, seed=seed+1), deterministic=False)` 并挂到 `env.opponent`（L266-270）——即 player-1 由 `FollowerOpponent` 驱动、且非确定性采样。
  3. `obs, _ = env.reset()`、`belief_a.reset(env.deck1)`、`hidden_a = None`、`ep_a/ep_b = new_ep_buf()`，初始化 `last_tr1/last_belief_tok/last_plan_tok = None`、`done = False`、`steps = 0`（L271-280）。
  4. 主循环条件：`while not done and (steps < max_steps or overtime_open(env.battle))`（L281）——加时赛期间即使超过 max_steps 也继续。
  5. 每步：按 `rng.random() < _PROPHET_PROB` 决定用 `prophet.plan(env.get_prophet_state())` 否则 `bp.plan(env.battle, belief_a.state(), obs)`（L282-284）；`plan_tok = plan.to_vector()`、`belief_tok = belief_a.encode(obs, None)`（L285-286）；`pol_a.act(obs, belief_tok, plan_tok, env.get_action_mask, hidden=hidden_a, deterministic=False)` 返回 `(bundle, lp, val, hidden_a, masks)`（L287-289）。
