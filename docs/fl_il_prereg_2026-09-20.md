## 0. 一句话目标

把 FL 的人类回放（**动作侧**）**灌进我们引擎**，产出 `(obs, masks, bundle)` 训练对，训一个行为克隆（BC）策略，
并如实报告「**像不像人类**」与「**接 PPO 后有没有变化**」两件事。

**这不是**「证明 IL 有效」的实验；这是**管线可行性 + 模仿质量**的第一轮读数（n=1/臂）。

## 1. 范围与口径（跑前定死）

| 项 | 取值 | 理由 / 出处 |
|---|---|---|
| 数据 | `IL_Replay` 的 **`replays/part-000000.parquet` 一分片**（5000 局 / 384,275 事件） | 只下 17.4 MB；与官方声明字节数一致（17,432,059 B） |
| 为何不用 `actions/` | `payload_json` **已含全部 events**；实测 5,000 局里 4,997 局逐局 `len(payload.events)` **==** actions 行数 | 本仓新仪器 `scripts/_fl_il_extract.py` 的 `cross_check_events_vs_actions` |
| 卡等 `card_level` | **11** | 与我们的 RL 训练/评估口径一致（`rl/config.py:181` `card_level: int = 11`）；⚠️ **偏差**：人类局卡牌 **71,839/80,000 是 lv16**（普查）⇒ 我方把双方等比降到 lv11 |
| 训练侧 | **只 train `team` 侧**（`requested_player_tag` 那一边） | 避免对手侧镜像/坐标翻转引入额外 bug；记为**范围限制**，不是能力上限 |
| 决策帧 | 我们的 **0.5 s 帧**；人类事件按 `replay_tick_20hz` 落帧，**每帧每侧只取「恰好 1 个 play_card」的帧**为样本 | 多事件帧（同帧 ≥2 张）**丢弃并计数**；保证 label = 单步 bundle，与我们 `K_MAX=4` 的展开口径不混 |
| 坐标 | 回放 `native_x/native_y`（世界坐标，`/1000` 后即我们的 `Position`） | 前次实测已定：**不需要翻转**（raw 40.5%/42.6%/53.0% vs flip_y 2.3%/2.3%/0%），见 `scripts/replay_feasibility_probe.py:18-24` |
| 手牌 | **强制**：若人类出的牌不在 `cycle[:4]`，与手牌位**交换**（保持 8 张与循环语义） | 人类手牌顺序回放里**不可观测**（FL 自己也是「生成相容牌序」） |
| 圣水 | **强制**：`elixir = max(elixir, cost)`，并**逐事件记录是否被迫抬** | 逐事件圣水**不可观测**（`il_human_data_survey` §：只有聚合量） |
| 模型 / 超参 | 与既有 BC 通路**逐位相同**（`rl/train_bc.py` 的损失 = `-lp` = slot CE + cell CE + STOP CE） | **R11：不扩参**；本实验唯一变量 = 「标签来自人类回放」 |
| 训练/留出切分 | **按 `replay_tag` 80/20**，切分种子写死 `seed=0` | 防同局泄漏（R9：探针按局分组留出） |

## 2. 判据（**跑前写死**，含失败分支）

### J1 · 管线可行性（结构性闸门）

1. **卡牌经济对账（外部真值，脚本复算，R4）**：对每一局每一侧，
   `Σ_{play_card 事件} Card(card_key).elixir` **必须等于** 回放自带的
   `payload.replay.aggregate_stats[side].total[1]`（人类真实总花费）。
   —— 这条**不需要引擎**，只检验「事件集合 + 我们的费用表」。
   **判据：逐局双侧一致率 ≥ 90%（容差 ±1 圣水）**。
2. **标签量**：过滤（见 §3）后**可用 IL 样本 ≥ 20,000 条**。

### J2 · 重建保真度（我们自己引擎上的结构性读数）

1. **位置拒绝率**（强制手牌+圣水之后仍然 `deploy_card == False` 的比例）：**≤ 5%**。
   超了 ⇒ 坐标/合法性口径错，**停止转换**，先做坐标 A/B。
2. **手牌强制率**、**圣水强制率**：**报告值**（不设闸门，因为人类手牌/圣水本就不可观测）。
3. **零非法位置**：`--coord raw` 与 `--coord flip_y` 并列报数（R17：不调和两种约定，只并排呈现）。

### J3 · 模仿质量（**主判据**）

留出（hold-out，按局分组）上的 **人类动作 top-1 一致率**：

- 主指标：`option 一致率`（6 类：4 槽 + ABILITY + STOP 里的前 4 槽；本实验样本**全是出牌帧**，
  ⇒ 随机基线 = 1/6 = **16.7%**）。
- 次指标：`落点格一致率`（576 格里 flat index 完全一致）。
- 报告值：留出 NLL。

**判据（阈值在本实验自己的量纲上标定，R15；不跨实验照抄）**：

| 读数 | 结论 |
|---|---|
| option 一致率 **≥ 40%** | **通过**：IL 确实学到了人类出牌选择 |
| 25% ≤ option 一致率 < 40% | **弱信号**：如实写「有信号但弱」，**不得**作下游疗效结论 |
| option 一致率 < 25% | **F4 失败分支**：写「IL 未学到」，不得粉饰 |

门槛对照基线必须**同时**给出：uniform(1/6) 与「常数预测最高频牌」两个基线（脚本复算）。

### J4 · 下游效应（**预注册为「不下结论」**）

IL ckpt → `train_follower.py --init-from` 短跑 + 标准评估：
**n=1/臂、无阳性对照 ⇒ 按 R5 不得判疗效**，只作**描述性**读数（与 `et_solo100k` 判读纪律一致）。
允许写法：「观察到 / 不可分辨」，**禁止**写「IL 初始化有效」或「无效」。

## 3. 过滤规则（跑前写死）

一局进入转换，当且仅当：

1. `game_mode ∈ {Ranked, Ladder, 1v1 Battle, 1v1, Grand Challenge, Classic Challenge}`；
   **排除** `1v1 Showdown`（选牌模式）、`Normal Battle`（规则未定）；
2. 两侧卡组**各 8 张**且**全部**能被 `card_aliases.resolve_card` 解析（`void` 等未知键 ⇒ 弃局）；
3. 局时长 `payload.replay.duration.timeline_seconds ≤ 300.0`（我们引擎的加时硬上限）；
4. 我方（team）侧 `play_card` 事件数 ≥ 4（太少的局对 IL 无信息）。

分片普查（`docs/fl_il_2026-09-20/census_part000000.json`）：5000 局、180 个不同卡键、
`void` 出现 501 次、时长中位 **218.55 s**、**1009/5000 局长于 300 s**。

## 7. 已知的事前不确定（写下来，不许事后补）

- **U1**：人类手牌顺序 / 逐事件圣水**不可观测** ⇒ 我们的「强制」是**假设**，不是重建。IL 学到的可能是「在被我方强制过的状态下的人类选择」。
- **U2**：人类局多数 lv16，我们用 lv11 ⇒ 单位存活/交换节奏与我方训练分布一致、但与人类局不一致。
- **U3**：我们的引擎与真实游戏**不是同一个引擎**（上游增量核查 P1–P4 未修）；重建的第 N 帧状态与真实局必然发散。
- **U4**：`activate_ability` 事件（本分片 18,913 条）本轮**不转成标签**（只计数）。
- **U5**：BC 只训 `team` 侧 ⇒ 样本量约为全部人类动作的一半。

### 8.1 仪器修正（三处，全部是「仪器错、不是数据错」）

| # | 症状 | 真因 | 修正 | 实测证据 |
|---|---|---|---|---|
| a | 引擎侧 100% 事件「无坐标」，0 条标签 | payload 的 event **没有** 扁平 `native_x/native_y`，坐标在 `coordinates.native_world_units`；第一版照 `actions/*.parquet` 的列名写 | 从 `coordinates` 取，并（回退）取 `grid_cell_floor` | 与 `actions` 表逐值对账 **6,530 / 6,530 相等** |
| b | J1.1 卡牌经济对账 24/3528 侧有差 | 用了**卡面费** `Card('Mirror').elixir`(=1)；实际费 = **上一张牌费用 + 1**（`rl/action_mask.py:30-36`），且 `Mirror` **不覆盖** `last_card`（`player.py:47`） | 按引擎语义走事件序列复算 | 修正后 **99.32% → 99.72%**；残差 **10/3528 = 0.28%**（仍全含 Mirror，方向混合，成因**未定**【R10】）——**引擎实现是对的** |
| c | 普查里 `duration_s.n = 0` | `replay.duration` 是 dict `{display_label, display_seconds, timeline_seconds}` | 取 `timeline_seconds` | 5000 局：中位 **218.55 s**、最大 314.05、**1009 局 > 300 s** |

### 8.2 新增读数 A：**掩码拒绝率**（人类动作「引擎合法但掩码非法」）

- 事实：`legal_cells` 比引擎严（法术空砸 / 砸塔 EV / 后排几何 / 「不裸下」整槽门，`action_mask.py:397-436`、
  `env_wrapper.py:352-357`）⇒ 真人动作**可能被掩码判非法**，从而无法在我们的动作空间里被评分。
- **处置（写死）**：该帧**不产标签**，但仍把这一手**打进战局**（否则后续状态发散）+ 计数 + 报率。
- 定位：**新增报告项**，不设闸门；若 > 20% 必须在判读里点名（它直接决定可用标签量）。

### 8.3 新增读数 B：**重建局提前终局**（本轮最重要的保真度限制）

- 事实（3 局 smoke 实测）：我们引擎的加时/三冠终局点 **148.5 / 146.4 / 180.0 s**，而真实局
  **164.1 / 272.6 / 227.6 s** ⇒ 重建局**普遍更早结束**，该局后半段的标签**全丢**。
- 成因（**未定**【R10】，结构性候选）：我们的引擎 ≠ 真实引擎（上游增量核查 P1–P4 未修）+ 卡等 lv16→lv11 +
  手牌/圣水强制 ⇒ 累积发散后某座王塔先倒。
- **处置（写死）**：`term/trunc` 即停，**不伪造续局**；逐局记 `end_time` 与真实 `dur`，判读里报
  `end_time / dur` 的中位数；J1.2 的「每局标签量」预期由 ~32 下调到 **~22**（若因此 < 20,000，走 **F1** 扩数据）。
- **必须写进判读的限制**：本批标签的**时间分布偏早期**（我们只覆盖真实局的前半段）。

### 8.4 圣水模型是**上界**（判读纪律）

我们的模拟圣水按同一回费速率、扣同一批费用，但**不模拟人类在 10 费上限处的泄漏**（
`elixir_leaked` 只有全场聚合值、无时间分布）⇒ 我们的估计 **≥ 真实值**。
因此 `elixir_force ≈ 0` 是「**模型宽裕**」，**不是**「人类圣水充足」——判读不得写成后者。

### 8.5 手牌强制 = **假设**（不是重建）

交换只改 `cycle` 顺序（长度恒 8、牌集合不变），但 `next_card`（`cycle[4]`）会变，
且交换后的状态在正常出牌下**不可达**（`runs/_probe_il/probe_sample_api.py` PART 3 / Q5a 实测）。

### 8.6 留出切分的实现

`md5("fl_il|" + replay_tag) % 5 == 0` ⇒ 留出 20%，**按局**切分（同局样本全在同一侧，防泄漏）。

`scripts/fl_il_to_bc.py --mode samples --games 2200 --workers 10 --level 11 --coord raw`，
数据源 = `replays/part-000000.parquet` 过滤后前 2200 局；产物在 `runs/_fl_il_bc/{train,holdout}/bc_*.pkl`
