## 0. ★ 不构成判决声明（预注册 §11.13.3，逐条）

1. **缺阳性对照**（§5.2 的 `C_pos = elixir_diff_weight 0.5→0`）⇒ 按 §5.2 **无法判 `VALID`**。
2. **n = 1 seed/臂**（§8 原本要求 2 seed/臂）⇒ 按【R5】**只能看大效应**；跨 run 数字不可直接比。
3. ⇒ 本轮**只出「观察 + 机制层读数」**；**不得**写成「修好了」或「确认无效」；
   只允许三种写法：**观察到什么 / 未达行为可见阈值 / 不可分辨**。
4. ★ **§11.13.11 实测标定**：同 seed 同配置、仅差一个测量开关的运行之间 `eval@8000` 可相差 **0.60**（0.800 vs 0.200），而既有**同配置三连跑**末点胜率极差已达 **0.313**⇒ **胜率/奖励层的 A vs B 差异在 n=1/臂 下一律不可归因**；失败分支 1、2 **只能读方向**。
