## 2. 顺带纠正两处既有文档错误（都属 R4 类）

### 错误 1：`vstd/rstd` 的 20k 基线数字错了 ~100×

`docs/d1_long_100k_verdict_2026-09-13.md` §4 与【确证 C3】写
「`vstd/rstd` 30k 后长期 ≈0.001（**比 20k 的 0.0035~0.0225 更差**）」。
**脚本复算 3 个 20k 基线的末点实测：0.2473 / 0.0041 / 0.1648**（见上表），
而非 0.0035~0.0225。全点序列见附录 A。
⇒ **C3 的结论方向不变**（100k 的 ≈0.001 确实比 20k 低一个数量级以上），
但**引用的 20k 基线数字作废**，不得再被后续会话手抄。

### 错误 2：「critic 塌缩」不是步数的确定性函数，而是**双稳态**

`_r2` 的价值头**在 20k 之内就死了**：12500→0.0084、15000→0.0016、17500→0.0007、20000→0.0041；
而 `d1_league_20k`（0.2473）与 `_r3`（0.1648）**到 20k 都还活着**，本次探针 run 也活着（0.5323）。
⇒ 价值头的 ReLU 死亡是**吸收态 + 双稳态**：不同 run 落在不同吸引域，
"多少步之后 critic 必死"这种说法不成立（100k 那次死在 30k 之前，但那是该 run 的实现，不是定律）。

## 3. 惰性是**分布性**的，不是逐点成立（必须一起报）

| 分位 | `grad_cos` |
|---|---|
| 中位 | **+0.99728** |
| `grad_cos < 0.99` | **50/145（34%）** |
| `< 0.95` | 30/145（21%） |
| `< 0.90` | 21/145（14%） |
| `< 0.50` | 6/145（4%） |
| `< 0`（**方向反转**） | 4/145（3%），最低 **−1.000** |

按 2500 步分箱的中位（**无漂移趋势**）：

| 区间 | 0–2.5k | 2.5–5k | 5–7.5k | 7.5–10k | 10–12.5k | 12.5–15k | 15–17.5k | 17.5–20k |
|---|---|---|---|---|---|---|---|---|
| 中位 `grad_cos` | +0.9995 | +1.0000 | +0.9716 | +0.9982 | +0.9970 | +0.9909 | +0.9976 | +0.9996 |
| 最小 | +0.809 | +0.846 | **−1.000** | +0.601 | +0.217 | **−0.843** | +0.862 | +0.844 |

离群点两种形态（都逐字列在日志里）：
- **退化型**：`grad_cos = ±1.000` 精确值（step 5054、5522）—— 该 minibatch 内"归一化后的替代优势"退化为常数
  （`resid_norm` 小但余弦恰好 ±1，与单测里常数向量的行为一致）；
- **真实形状差**：如 step 6012 `corr=−0.425 / resid_norm=1.688`、step 12121 `grad_cos=+0.217`。

⇒ 表述纪律：**"critic 惰性"应写成"中位意义上惰性"**，不能写成"逐点与 critic 无关"。

## 4. 这条结果**加强**了什么、**削弱**了什么

- **加强**（比 `docs/d1_long_100k_cause_analysis_2026-09-13.md` §5.3 更强）：
  原来只能说"塌成常数后 critic 不提供信用分配"；现在实测到
  **一个在拟合的 critic（EV +0.30）对策略更新方向的改变也只有 ~1–4%**，
  且**模长几乎不变**（`grad_norm_ratio` 中位 0.994）。机理：GAE 里 V 只通过**相邻帧差分**
  `γV_{t+1} − V_t` 进入优势，优势的形状主要由奖励序列决定 ⇒ V 的贡献被结构性地压小；
  再叠加 `adv_norm="scale"`（按批 std 归一化，把"好基线应该缩小优势幅度"这条通道直接归一化掉）
  ⇒ **在当前配置下，修好 critic 的预期收益上界 ≈ 让更新方向偏移几个百分点**。
- **削弱**：`docs/d1_long_100k_cause_analysis_2026-09-13.md` §7 实验 2（"修 critic = 恢复信用分配，
  是唯一能提高样本信息量的杠杆"）这句话的**收益预期要下调**；它仍是"唯一能提高每帧信息量"的部件，
  但实测该部件对本配置的更新方向影响很小。
- **不改变**：§5.3 的"60% 对手是自身历史 + 绝对参照只 7.8% ⇒ 目标无绝对方向"这一半独立成立。

## 6. Layer 2 未跑，及为什么不建议现在跑

预注册把 Layer 2（`--critic-baseline const` 干预跑，3 repeat，锚点对比）定为**次级描述性**。
现在 Layer 1 已给出机制层答案，而 Layer 2 要回答的问题是"干预后 20k 曲线是否变化"：
- 期望效应量 ≈ `resid_norm` ~4% 量级，而 3 跑/臂 下 20k 的 MDE ≈ 0.35（R5）⇒ **原理上判不出来**；
- 且 P1′ 已提示 `level_shift_norm` 中位 0.255 > 0.10 ⇒ 干预同时改掉了"水平"，归因更弱。

⇒ **结论：Layer 2 的信息量不足以支撑 75 min 计算**；若仍要做，建议把判据改成机制量
（"干预跑里 `adv_real` 与 `adv_const` 同值 ⇒ 探针应报告 `resid_norm ≡ 0`"）作为**接线正确性**检查，
而不是判"训练结果有没有变"。**该取舍留给用户拍板（Layer 2 属已预注册实验，改动需明示）。**

## 7. 限制（照预注册 §4，逐条兑现）

1. **`grad_cos` 是有偏样本**：只在每个诊断更新的**第一轮第一个 minibatch（32/128 帧）**上测，
   测的是"首步方向差"。⇒ 用于判量级，不用于精确归因。（本 run `--diagnose-every 1` ⇒ 145 点/154 更新。）
2. **常数水平混淆**：已按 P1′ 量化（`level_shift_norm` 中位 0.2551、`level_gap` 中位 3.66，c≈3）。
3. **评估节奏不变性**：本 run 用 C 式节奏（1 全点 + 8 轻点）而非基线的 9 全点。
   ⇒ **已用 `vstd/rstd`/`EV` 对账**：本 run 末点 0.5323 / +0.3003 落在 3 个基线末点的**同一区间内**
   （0.0041~0.2473 / −0.183~+0.018…… 注：EV 高于基线，但 `vstd/rstd` 同族），
   **未见系统性偏离**；但这只是间接对账，不是轨迹逐位比较。
4. **R5/【X10】**：次级锚点未配对，只作描述。
5. **探针开销**：每诊断更新 +1 前向 +1 反传（实测训练 12.1 步/s；无法与 26 步/s 直接比，因外部占用不同）。
6. **单 run**：本判读是 1 个 run 的 145 个更新内测量（同一 run 内配对，比跨 run 对比强），
   但"惰性 4%"这个数值本身是否随 run 波动，未测。
