## 0.1 ⚠️ 同日复核更正（2026-09-13 晚，三条，其中 ① 削弱本文档最强的推论）

**① `grad_cos` 不能承担"修 critic 收益上界"这个推论（方法论，R4/R10 类）。**
两个臂（真 critic / V≡常数）都是**同一条策略梯度的无偏估计**——任意**状态函数**基线都不改变
期望更新方向（`E[b(s)∇logπ]=E[b(s)·E_a∇logπ]=0`；`adv_norm="scale"` 只乘一个正的批常数，
且该常数不参与反传）。⇒ **任意两个基线之间的 cos≈1 是期望零假设**，不是"critic 无用"的证据。
真正能区分基线好坏的是**方差/梯度模长通道**；而本 run 的 `adv_norm="scale"` 把两臂各自
除以自身 std ⇒ **模长通道被归一化掉**（`grad_norm_ratio` 中位 0.994 是这个归一化的结果，
不是独立证据）。⇒ 本文档与 `AGENTS.md` O2 里"**修 critic 的收益上界 = 让更新方向偏移几个百分点**"
**只在"`adv_norm="scale"` + 本 critic"这一组合下成立**，不得推广为"修 critic 无用"。
仍然成立的部分：**在本配置下**，critic 对优势**形状**的贡献是中位 4.15%。

**② "池化 EV +0.3003" 与 "逐批 EVb 为负" 并不矛盾；两者合起来给出第二条惰性指纹。**
脚本复算 145 个诊断更新的 `EVb`（= `stats['explained_variance']`，128 连续帧批内、更新前池化）：
**145/145 为负，中位 −3.149，最大 −0.05**；而同一权重在**整段训练窗口池化**的
`explained_variance` = +0.3003（`train_solo.py:1289-1294`）。
机制：**批内近似常数的预测器数学上必然 `EVb ≤ 0`**（`EV = 1 − [Var(R)+(R̄−c)²]/Var(R) = −(R̄−c)²/Var(R)`）。
实测最大 `EVb = −0.05 ≈ 0` ⇒ critic 在 128 帧批内**几乎不随状态变化**，而它的池化 EV 来自
**批间（局/相位）水平差**；代码注释早已记录「批内 `Var(R)` 仅为全局 **0.32 倍**」（`train_solo.py:1286-1287`），
与"批间占大头"一致。⇒ 惰性有了**与形状残差 4% 互相独立的第二条指纹**：
`V` 在优势所在的时间窗口内近似常数 ⇒ `γV_{t+1}−V_t≈0` ⇒ `A_real≈A_alt`。

**③ 顺带的口径纪律（建议升格为 R9 的一条）**：**窗口池化 EV 不是"状态级价值质量"的指标**，
它主要度量跨批/跨相位的水平跟踪；对"critic 有没有在做状态级信用分配"应当看
**批内 EV（或优势形状残差）**。历史 run 的 `EV≈0` 与 `EV≈+0.3` 都可能在批内为负，
两者不能混读。（本文档 §1 的"这次 critic 并没有塌"应读作"**池化口径下没塌**"。）

**④ ⚠️ 决定性的一条：本 run 末点的 critic 就是常数 ⇒ §1 的"这次 critic 并没有塌"是错的，
P1 的读法必须再降一级。**
独立复核（`scripts/_probe_value_path.py`，600 帧，**独立实现**；另有
`scripts/pomdp_ceiling_probe.py` 的 1293 帧噪声 rollout 给出同一结论）：

| 读数 | 值 |
|---|---|
| `value` 的唯一值个数 | **1 / 600**（= `value_head_mlp[2].bias` = **+0.1425485**，`std = 0.000e+00`） |
| `value_head_mlp[0]` 的 ReLU **逐帧存活率** | **0.000000**（全零帧占比 **1.000**，64 个单元对所有帧都不激活） |
| 噪声 rollout 的 `std(V)/std(R)` | **0.0000** |

⇒ **V ≡ 常数**，即 R14"ReLU 逐个死亡锁死"吸收态的**完全体**（不是"部分活力"）。
于是有恒等式：**V ≡ 常数 ⇒ `adv_real` 与 `adv_const` 只差一个常数 ⇒ `resid_frac_norm` 应 ≈ 0、
`grad_cos` ≈ 1**。Layer 1 测到的正是这个退化情形；它读到的 4.15% 来自**更早（未全死）**的那些更新，
**不能**读成"拟合良好的 critic 也只有 4%"。

**与 §1 的表如何共存**（三处口径合起来才自洽）：`explained_variance = +0.3003` 是
**整个训练窗口池化**（该 run 只有 2 个评估点，`_probe["ev_pairs"]` 从 ~step128 累积到 20000，
`train_solo.py:1289-1294`）⇒ 它把**早期活着的相位**与**晚期死掉的相位**平均在一起；
而**逐批** `EVb` 全程 ≤0（中位 −3.149、**最大 −0.05**）⇒ 即使早期，critic 在
128 帧批内也没有状态级信号（**批内常数预测器数学上必然 `EVb ≤ 0`**，见 ②）。
一个"批内常数、批间水平跟踪"的预测器同时给出"逐批 EVb<0"与"池化 EV>0"，两者不矛盾。

⇒ **结论修正**：**"P1 成立"只说明"一个批内近乎常数的 critic 对优势没有贡献"（近乎同义反复），
不说明"修好 critic 也没有用"。** `AGENTS.md` O2 中"建议 ⑤ 不再修 critic / 关闭 critic 线"的处置
**失去依据**；真正未知的仍是"一个真能拟合的 critic 会不会有用"——
这正是 `docs/pomdp_ceiling_prereg_2026-09-13.md` 从**信息侧**回答的问题
（并附一条：`train_solo.py` 的"池化 EV"在**只有 1~2 个评估点**的 run 上会跨相位平均，
不能当作末点状态；`--steps-per-eval 20000` 那种节奏会让这条读数失去判读力）。

但**引用的 20k 基线数字作废**，不得再被后续会话手抄。

### 错误 2：「critic 塌缩」不是步数的确定性函数，而是**双稳态**

`_r2` 的价值头**在 20k 之内就死了**：12500→0.0084、15000→0.0016、17500→0.0007、20000→0.0041；
而 `d1_league_20k`（0.2473）与 `_r3`（0.1648）**到 20k 都还活着**，本次探针 run 也活着（0.5323）。
⇒ 价值头的 ReLU 死亡是**吸收态 + 双稳态**：不同 run 落在不同吸引域，
"多少步之后 critic 必死"这种说法不成立（100k 那次死在 30k 之前，但那是该 run 的实现，不是定律）。

## 3. 惰性是**分布性**的，不是逐点成立（必须一起报）

| 分位 | `grad_cos` |
|---|---|
| 中位 | **+0.99728** |
| `grad_cos < 0.99` | **50/145（34%）** |
| `< 0.95` | 30/145（21%） |
| `< 0.90` | 21/145（14%） |
| `< 0.50` | 6/145（4%） |
| `< 0`（**方向反转**） | 4/145（3%），最低 **−1.000** |

按 2500 步分箱的中位（**无漂移趋势**）：

| 区间 | 0–2.5k | 2.5–5k | 5–7.5k | 7.5–10k | 10–12.5k | 12.5–15k | 15–17.5k | 17.5–20k |
|---|---|---|---|---|---|---|---|---|
| 中位 `grad_cos` | +0.9995 | +1.0000 | +0.9716 | +0.9982 | +0.9970 | +0.9909 | +0.9976 | +0.9996 |
| 最小 | +0.809 | +0.846 | **−1.000** | +0.601 | +0.217 | **−0.843** | +0.862 | +0.844 |

- **退化型**：`grad_cos = ±1.000` 精确值（step 5054、5522）—— 该 minibatch 内"归一化后的替代优势"退化为常数

⇒ 表述纪律：**"critic 惰性"应写成"中位意义上惰性"**，不能写成"逐点与 critic 无关"。

## 4. 这条结果**加强**了什么、**削弱**了什么

- **加强**（比 `docs/d1_long_100k_cause_analysis_2026-09-13.md` §5.3 更强）：
  原来只能说"塌成常数后 critic 不提供信用分配"；现在实测到
  **一个在拟合的 critic（EV +0.30）对策略更新方向的改变也只有 ~1–4%**，
  且**模长几乎不变**（`grad_norm_ratio` 中位 0.994）。机理：GAE 里 V 只通过**相邻帧差分**
  `γV_{t+1} − V_t` 进入优势，优势的形状主要由奖励序列决定 ⇒ V 的贡献被结构性地压小；
  再叠加 `adv_norm="scale"`（按批 std 归一化，把"好基线应该缩小优势幅度"这条通道直接归一化掉）
  ⇒ **在当前配置下，修好 critic 的预期收益上界 ≈ 让更新方向偏移几个百分点**。
- **削弱**：`docs/d1_long_100k_cause_analysis_2026-09-13.md` §7 实验 2（"修 critic = 恢复信用分配，
  是唯一能提高样本信息量的杠杆"）这句话的**收益预期要下调**；它仍是"唯一能提高每帧信息量"的部件，
  但实测该部件对本配置的更新方向影响很小。
- **不改变**：§5.3 的"60% 对手是自身历史 + 绝对参照只 7.8% ⇒ 目标无绝对方向"这一半独立成立。

## 6. Layer 2 未跑，及为什么不建议现在跑

预注册把 Layer 2（`--critic-baseline const` 干预跑，3 repeat，锚点对比）定为**次级描述性**。
现在 Layer 1 已给出机制层答案，而 Layer 2 要回答的问题是"干预后 20k 曲线是否变化"：
- 期望效应量 ≈ `resid_norm` ~4% 量级，而 3 跑/臂 下 20k 的 MDE ≈ 0.35（R5）⇒ **原理上判不出来**；
- 且 P1′ 已提示 `level_shift_norm` 中位 0.255 > 0.10 ⇒ 干预同时改掉了"水平"，归因更弱。

⇒ **结论：Layer 2 的信息量不足以支撑 75 min 计算**；若仍要做，建议把判据改成机制量
（"干预跑里 `adv_real` 与 `adv_const` 同值 ⇒ 探针应报告 `resid_norm ≡ 0`"）作为**接线正确性**检查，
而不是判"训练结果有没有变"。**该取舍留给用户拍板（Layer 2 属已预注册实验，改动需明示）。**

## 7. 限制（照预注册 §4，逐条兑现）

1. **`grad_cos` 是有偏样本**：只在每个诊断更新的**第一轮第一个 minibatch（32/128 帧）**上测，
   测的是"首步方向差"。⇒ 用于判量级，不用于精确归因。（本 run `--diagnose-every 1` ⇒ 145 点/154 更新。）
2. **常数水平混淆**：已按 P1′ 量化（`level_shift_norm` 中位 0.2551、`level_gap` 中位 3.66，c≈3）。
3. **评估节奏不变性**：本 run 用 C 式节奏（1 全点 + 8 轻点）而非基线的 9 全点。
   ⇒ **已用 `vstd/rstd`/`EV` 对账**：本 run 末点 0.5323 / +0.3003 落在 3 个基线末点的**同一区间内**
   （0.0041~0.2473 / −0.183~+0.018…… 注：EV 高于基线，但 `vstd/rstd` 同族），
