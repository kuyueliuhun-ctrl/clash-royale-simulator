## 0. 判决

# **P3 — H-LEARN**

**照预注册 §3 逐条读**：`EV_within(C) = +0.1855 ≥ 0.15` **且**
`EV_within(B) − EV_within(C) = +0.0111 < 0.08`。

**含义**：**局内回报的变化在现有输入里就是可预测的**（含 belief token；`EV_within = +0.19`），
**oracle 隐藏量（对手循环/手牌/圣水）只再加 1.1 个百分点**
⇒ **惰性不是我们的 POMDP 造成的信息缺口**，是 critic 没把已有的信息学进去。

## 3. 子判据 P3′：**belief 通道没有增量**（直接回答"挂起 bf 会不会改变惰性"）

| 量 | 值 |
|---|---|
| `EV_within(A)`（原始观测） | +0.1816 |
| `EV_within(C)`（A + belief token 563 维） | +0.1855 |
| **`EV_within(C) − EV_within(A)`** | **+0.0039** |
| 预注册门槛 | `< 0.05` ⇒ belief 无增量 |

# ⇒ **belief/prophet/plan 通道对"局内回报可预测性"的净增量 = 0.4 个百分点**

**这条直接回答了你最初的问题**（"挂起 bf 等模块再测，看看惰性是不是我们的 POMDP 导致的"）：
**惰性不是 POMDP 的信息缺口，挂起 bf 不会改变惰性。**
- 信息**已经**在跟随者自己的观测里（A 集，`EV_within = +0.18`；线性模型 +0.30）；
- belief token 再往上加 **+0.004**；oracle 引擎真值再往上加 **+0.011**（相对 C）。
- ⇒ 在这条轴上，**继续给网络喂更多"关于对手隐藏状态"的信息，收益上限约 1 个百分点。**

**推论（要写进 AGENTS 的实操结论）**：
- 不该做"挂起 bf 再跑一遍"这次消融——**它的期望收益已被量化封顶在 ~1pp**；
- 该做的是问"**为什么现成的、线性的、EV≈0.30 的信号，critic 一个都没学到**"，
  即回到 R14 的锁死机制（`LN(ReLU(·))` 之后梯度真空 + 末端无 squash）与
  `adv_norm="scale"` / GAE γλ 的通道问题。

## 4. 判读必须附带的三条限定

1. **G2 是退化通过**：本 run 的 critic 是常数（`std(V)/std(R)=0.0000`）⇒ `critic EV_within ≡ 0`
   是**恒等式**，不是"探针复现了训练条件"。
2. **本估计器是为"局内形状"这个量定制的**（预注册 §1/§5.5）：它把"每局水平"作为代价，
   换来"局内形状"的拟合能力。⇒ 它的读数**只回答"局内回报变化可否由状态解释"**，
   **不能**读成"critic 本来应该能拟合整局回报"。
3. **单 ckpt、单 seed、单一对手**（自身冻结副本，比训练期混合对手池窄）；
   判据是**机制量级**判据，不是精密估计。MLP 的 `val_EV_within`（+0.07~+0.11）低于
   test 读数（+0.18~+0.20），存在乐观偏差——所以**主结论靠的是"三集一致 + 四个对照"
   这个结构性证据，不是单点数值的绝对值**。

## 6. 结论对项目决策的含义

| 之前的状态 | 现在 |
|---|---|
| O2："关闭 critic 线的依据作废；信息侧上限由 POMDP 探针回答" | **已回答：信息不是缺口（P3）** |
| "挂起 bf 通道再跑一次" 是候选动作 | **该动作可以取消**：期望收益被量化封顶在 **~1pp**（P3′） |
| critic 修复的优先级 | **上升**：这是**唯一**剩下的解释——同样的特征上，Ridge 拿到 +0.30、我们的 critic 拿到 0 |

**下一步（按信息量排序）**：
1. **取证"为什么学不到"**：既然可预测部分是**线性**的，先量 `value_enc_fc → ReLU → value_enc_ln`
   是否把这个线性分量**压掉了**（`value_enc_ln` 把近常数输入归一化 ⇒ 可表达方差 ≈0.14，
   而目标 std≈12.11）——这正是 `cause_analysis §3` 提的"实验 2：给价值通路去归一化"。
2. 单变量消融：`LN(ReLU(·))` 的 LN 改为恒等（或改位置）后重跑 20k，判据用
   **批内 EV / 优势形状残差**（不许用池化 EV —— O2 ③）。
3. 若 1/2 仍为负，再考虑 `adv_norm="scale"` → `none/batch` 的单变量对照（O2 ①）。

## 7. 追记（2026-09-14）：本文的**绝对阈值**被一条方法学发现削弱；**结构判据不受影响**

**发现（【否证 X-16】/ 病理 ⑪ 部分播种）**：本轮 §3 的主判据里有一条**绝对条件**

> `EV_within(C) ≥ 0.15`（读作 `+0.1855`，余量 0.036）

复核时发现：**随机 rollout 探针的 `EV_within` 绝对值跨 rollout 不可复现**——
同 ckpt、同 seed 7、同一 `feat_obs` 特征构造，两次 rollout 给出
**+0.2999**（32982 帧 / 149 局）与 **+0.1629**（29654 帧 / 135 局），**差 1.84×**。
**机制已定位**：`pol.act` 用 `slot_dist.sample()`（**全局 torch RNG**），而探针脚本
**从未 `torch.manual_seed`**（`pomdp_ceiling_probe` 里唯一的 `manual_seed` 在 `fit_mlp` 内）
⇒ 每个进程一条**全新轨迹**。实测互证：两个 cache 的 `y` **第 0 帧起就不同、100% 帧不同**
（是轨迹差异，不是切分差异）。

**对本轮判决的影响（逐条）**：

| 判据 | 类型 | 是否受影响 |
|---|---|---|
| `EV_within(C) ≥ 0.15`（绝对值） | **绝对阈值** | **⚠️ 余量 0.036 小于观测到的跨 rollout 波动（1.84× / 绝对 0.137）⇒ 该条不再有区分力** |
| `EV_within(B) − EV_within(C) = +0.011 < 0.08` | **同 run 内配对** | ✅ 不受影响（A/B/C 在**同一批帧**上拟合） |
| 四道对照电池（阳性/时钟/状态打散/目标打散） | **同 run 内对照** | ✅ 不受影响 |
| C5 可复现性（主估计器重跑 `diff` 为空） | **同 run 内** | ✅ 不受影响（同一 cache 离线重拟合） |

⇒ **P3（H-LEARN）的结论保留**：它靠的是 **`ΔB−C` 配对比较 + 四道对照**，
**不是**那条绝对条件。但**"C 的绝对值 0.186"不得再被引用为"信号强度"**——
它是一条轨迹上的读数，换个 rollout 可能是 0.16 或 0.30。
（另：`EV_within(C) − EV_within(A) = +0.0039 < 0.05` 的 P3′ 也是**同 run 配对**，同样不受影响。）

**已立的纪律**：新增**第 10 道闸门「复现闸」**——固定种子跑两次、`y`/`ep` 前缀必须逐位一致；
不一致 ⇒ 该读数只能用于**同一次 rollout 内的配对比较**。
修法：探针跑前 `torch.manual_seed(seed)`（并在日志里记录 RNG 状态）。
