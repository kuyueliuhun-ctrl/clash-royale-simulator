## §0 背景：为什么问这一层

第二轮信息侧天花板检验（`docs/pomdp_ceiling_v2_verdict_2026-09-13.md`）已经判决 **P3 / H-LEARN**：

| 事实 | 数字 |
|---|---|
| 局内回报变化，用**原始 obs 特征**线性可预测 | Ridge `EV_within = +0.2999` |
| 同一批帧，**我们的 critic 自己**给出 | `EV_within = +0.0000` |
| 再加 `belief` token / oracle 隐藏量 | `+0.1855 / +0.1966`（相对 A 只 +0.4pp / +1.1pp） |

⇒ 「信息不够」被关掉，只剩「**信息在，critic 学不到**」。

第一性候选机制（`docs/d1_long_100k_cause_analysis_2026-09-13.md` §3）说：价值编码器末端
`value_enc_ln`（`nn.LayerNorm(128)`）把**近常数输入**归一化 ⇒ 价值头可表达的跨帧方差远小于
目标的跨帧方差 ⇒ 自举失败 ⇒ ReLU 逐个死亡、锁死成常数（【红线 R14】吸收态）。

**但这个机制到目前为止只是推断，没有直接测过。** 已有的 `scripts/_probe_value_path.py`
只测了「每层跨帧 std / 恒定分量 / ReLU 存活率」这类**幅度**统计，没有测**可预测性**：
一层可以"变化很小"却"变化方向完全对得上回报"，也可以"变化很大"却"全是噪声"。

## §1 本轮唯一问题

> **Q：从 `fused` 到 `value` 的逐层阶梯上，局内可预测性（`EV_within`）在第几层掉到 ≈0？**

对应"病灶在哪一层"：

```
fused(2731) --Linear--> pre_ln(128) --ReLU--> relu_ln(128) --LayerNorm--> post_ln(128)
             --Linear--> mlp0_pre(64) --ReLU--> mlp0_post(64) --Linear--> value(1)
```

---

## §2 方法（单 ckpt / 单 rollout / 逐层配对）

1. **单 ckpt、单 rollout**：`--mode stoch --frames 30000 --seed 7`，与第二轮主跑**同 ckpt、同 seed、
   同帧数**（主 ckpt = `runs/critic_inert_probe_20k/solo_main_20000.pt`）。收尾丢弃最后一局不完整的帧
   （与 `pomdp_ceiling_probe.py` 一致）。
2. **逐帧抓 6 层激活**（`torch.no_grad()`，只前向）：

   | 层 | 名称 | 维度 | 含义 |
   |---|---|---|---|
   | L0 | `fused` | 2731 | 感知融合特征（价值编码器的输入） |
   | L1 | `pre_ln` | 128 | `value_enc_fc(fused)` 线性输出（LN 之前） |
   | L2 | `relu_ln` | 128 | `relu(pre_ln)` |
   | L3 | `post_ln` | 128 | `value_enc_ln(relu_ln)` ← **被指控的那一层** |
   | L4 | `mlp0_post` | 64 | `relu(value_head_mlp[0](post_ln))` |
   | L5 | `value` | 1 | 最终价值输出 |

3. **每层用第二轮主估计器**拟**同一个目标**（GAE 回报 R，先按局中心化）：
   Ridge、`alpha ∈ {1e-1 … 1e8}`、输出裁剪到训练目标区间、`select = within`
   （= `EV_within` 选模型，与判据同口径；见第一轮预注册 §8 修订 4）。
4. **同一局分组切分**（【红线 R9④】）：`seed=7`、`test_frac=0.25`、`val_frac=0.15`，
   切分在**所有层之间逐位相同** ⇒ 层与层是**配对比较**，层间差不含切分噪声。
   特征标准化只用**训练集**统计量；训练集零方差列丢弃。
5. 主指标 = **test 集 `EV_within`**。

> **为什么这是强设计**：目标、切分、估计器、帧全部相同，唯一变的是"从哪一层取特征"。
> 任何"估计器不够好"的解释都会**同时**压低所有层，因此**层间落差**是可信的。

## §3 判据（跑前写死）

### §3.1 闸门（任一不过 ⇒ **`L0_INVALID`，不判决**）

| 闸门 | 要求 | 理由 |
|---|---|---|
| **G-PC** 阳性对照 | 在 `fused` 上按第二轮同构构造的已知信号靶，`EV_within ≥ 0.15` | 估计器必须能读出**已知存在**的信号 |
| **G-CLK** 时钟基线 | 单特征"局内第几帧"，`EV_within ≤ 0.05` | 排除"只靠时间就能拿分" |
| **G-SCR** 状态打散 | `fused` 与 `post_ln` 各做一次「局内位置相同、跨局置换」，`≤ 0.05` | 排除用与配对无关的公共结构 |
| **G-UP** 上游有信号 | `EV_within(fused) ≥ 0.15` | 若连输入层都读不出，本轮的"掉点层"无从谈起 |
| **G-ALLZERO** 退化自明 | 若某层训练集零方差列 = 全部 ⇒ 该层 `EV_within` 记 **0.0**（平凡均值预测），标注"退化" | `post_ln` 在塌缩 ckpt 上可能几乎全零；这是**读数**不是**发现** |

### §3.2 判决：沿阶梯取**首个** `EV_within < 0.05` 的层（记 `k*`）

| 分支 | 条件 | 判决 | 处置含义 |
|---|---|---|---|
| **L4_INVALID** | `k* = 0` | 输入层即无信号 | 与 G-UP 冲突 ⇒ 记不判决 |
| **L5** | `k* = 1` | 掉在 `value_enc_fc`（**线性投影**） | 掉点不在 LN/ReLU，而在"首个线性层把 2731 维压到 128 维" |
| **L3** | `k* = 2` | 掉在 **ReLU** | ReLU 死亡是止步点（已知 `relu_ln` 零变化维占比极高） |
| **L1** | `k* = 3` | 掉在 **LayerNorm** | **被指控的那一层被坐实** ⇒ 单变量消融 LN→identity 有依据 |
| **L2b** | `k* = 4` | 掉在 `MLP0` 的 ReLU | R14 吸收态在价值头上的复现 ⇒ 消融 LN **不足以**解决 |
| **L2** | `k* = 5` | 掉在输出线性层 | 表示侧全程可读，问题在最后一层 |
| **L2** | `k*` 不存在 | **全程** `EV_within ≥ 0.05`（且 `post_ln ≥ 0.15`） | **LN 不是止步点**：表示层保有线性可读信号 ⇒ 病灶在 MLP 头的**训练动力学**，消融 LN 无依据 |
| **L1'** | `k*` 不存在但 `0.05 ≤ post_ln < 0.15` | 弱可读 | 描述为"信号在 LN 处被显著削弱但未归零"，**不判决**，转 §4 的 `gain_needed` 读 |

> 分支**互斥且穷尽**（`k*` 是唯一确定的整数）。三个"不判决"出口（闸门不过 / L4 / L1'）必须在日志里显式打印。

## §4 次要描述量（**不参与判决**，只用于解释与设计下一个单变量实验）

1. **`gain_needed(L)`** = `within_std(R) ÷ ‖每维局内 std 向量‖₂(L)`
   —— 说明"要把该层的局内变化放大到目标的局内变化，需要多少倍增益"。
2. **`max_gain_head`** = `σ_max(value_head_mlp[0].weight) × σ_max(value_head_mlp[2].weight)`
   —— **当前权重下**价值头从 `post_ln` 到输出的最大放大倍数（`‖relu(W₁x)−relu(W₁x′)‖ ≤ σ_max(W₁)‖x−x′‖` 逐级相乘）。
   `gain_needed / max_gain_head` = **缺口倍数**。这一条能把"表示没信号"与"头放大不动"分开：
   后者在数学上是**任何梯度修正都救不了**的当前权重事实（只能靠权重增长，而 R14 说它精确不增长）。
3. **LN 几何**：`value_enc_ln.weight/bias` 的均值/‖·‖；`post_ln` 的逐维局内 std。
4. **ReLU 存活率**：`relu_ln` 零变化维占比、`mlp0_post` 逐帧存活率 / 全零帧占比。
5. **幅度阶梯**：每层 `‖恒定分量‖`、`‖跨帧变化‖`、相对变化（沿用 `_probe_value_path.py` 口径）。
6. **模型自身**：`value` 的 `EV_within` / 唯一值数 / `std(V)/std(R)`（应复现第二轮的 0.0000）。

## §6 已知局限（预先声明，防止事后找借口）

1. **单 ckpt / 单 seed / 单一对手**；层间差靠**配对设计**成立，**绝对数不跨 run 比**（【红线 R5】）。
2. 线性探针是**下界**：读不出 ⇒ 只能证明"线性读不出"，**不能**证明"信息不存在"。
3. 探针会**标准化**特征 ⇒ 会消掉 LN 的**尺度压缩**。所以 `post_ln` 的 `EV_within` 高
   **不能**排除"头需要几百倍增益"这条机制 —— 必须同时读 §4 的 `gain_needed / max_gain_head`。
   这是本轮最容易犯的读错，写在这里。
4. **掉点层 ≠ 因果层**：表示层与头是**联合训练**的，掉点是"共因"在该层的投影；本脚本测的是**症状定位**，
   因果只能靠随后的**单变量消融**。
5. `relu_ln` 的零变化维会被丢弃 ⇒ 其 `dim` 可能远小于 128，读数要在该 `dim` 下解释。
6. 本轮的 `fused` 是**编码后**特征（2731 维），**不是**第二轮 A 集的原始 obs（8648 维）；
   两者的 Ridge 数字**不可直接比**。
